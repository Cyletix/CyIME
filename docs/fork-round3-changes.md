# 第三轮输入体验修正（2026-09-23）

版本：2.8.6，versionCode 20260923。保留前两轮已验收改动，源码未提交 Git。

后续手写笔迹残留与重复返回修复见 [手写修复记录](fork-handwriting-fix.md)；下文安装包校验值为第三轮初次交付记录。

## 操作变化

- 手写工具使用真正的手写识别面板，保持当前键盘高度。图标持续高亮；再点图标或面板左上的圆形返回键，恢复进入前的输入模式。ABC 明确进入英文模式。
- 手写默认停笔 **1 秒**才识别和淡出笔迹，继续落笔会取消旧请求、重新计时并保留笔迹。设置 → 布局与显示 → 基础输入可调为 **0.5～2.5 秒**。按功能键时先完成待识别笔画，再执行空格、回车等动作。
- 英文是永久启用的并列输入模式，出现在长按语言菜单和方案列表中，设置中不可关闭。显式选中文或日语方案时同时清除 ASCII 状态和旧布局记忆，避免只提示成功却仍显示英文。
- 语言键长按 0.3 秒打开菜单，滑动松手选择；取消上滑动作。每次打开重置手指位置，只在触及列表边缘时自动滚动。
- 日语九宫格改为中间三列假名、左右辅助键和统一的符号/数字/语言入口，去掉重叠的小字。滑动回到中央可以恢复该行首个假名，最终以松手位置提交。
- 日语26键点击 Shift 后保持大写，连续罗马音输入片假名，例如 KATAKANA → カタカナ；再次点击 Shift 返回平假名输入。保留原 jaroomaji 方案与词典兼容性。后台按键遇到引擎锁会等待处理，避免短暂繁忙时直接漏出英文字母。
- 语音按钮点击开始，再点击结束并完成转录；工具栏仍可使用，空格保留输入与光标功能。录音图标使用主题色动态光圈，转录时显示进度环，并新增开始/结束提示音，遵循声音设置。
- 长按空格调整光标时，整块键盘变暗，中央显示“光标调整”；松手恢复。
- 悬浮拖条限制在系统导航栏上方；进入、拖动和恢复均按实际导航栏 inset 限制位置。调节面板的重置、悬浮开关、确认位于同一底行，透明度滑条在其上方。
- 编辑、手写、表情、剪贴板使用同一圆形返回组件。编辑面板左下额外保留按键样式的返回；四个方向键使用主题色，四角键缩小约12%，仍保持方形及九宫格中心对齐。每个编辑按键都是独立无障碍节点，避免被面板点击屏障合并。
- 工具栏图标长按 **2 秒**后拖动排序，移动到边缘可滚动查看更多项目，松手保存；取消手势恢复原顺序。保持普通点击与插件工具兼容。
- 候选词左侧增加圆形返回箭头，取消本次输入、恢复工具栏；候选词从其右侧排列。剪贴板预览使用相同返回样式。

## 模型与数据兼容

继续使用原市场 ochwpro 手写模型和 zipformer-zh-int8 语音模型，未更换模型格式或下载接口。本轮在专用 API36 模拟器实际下载、校验、安装两模型，并运行原手写模型推理与停顿测试。工具栏排序沿用现有按钮 ID 和设置存储；内置英文入口不会写成伪 Rime schema。
