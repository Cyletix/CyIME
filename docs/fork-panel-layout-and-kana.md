# 面板布局、贴底恢复与日语滑动预览（2026-09-23）

## 问题与修正

- **方案卡片重叠**：菜单虽已修复，方案选择仍用按宽度强制正方形的旧网格。现共用按实际高度分行、分页的网格；窄悬浮窗口不再套用横屏八列。五个模式在低高度下可翻页访问，排序功能保留。
- **悬浮恢复**：仅底部边缘参与恢复判定，左右和顶部均不能触发。停留0.5秒扩展预览后松手确认；移开或取消不恢复。恢复框和提示的底边按导航栏高度上移。
- **编辑侧键**：中央九宫格继续保持正方形及原功能；全选、剪切贴左边，回格贴右上、回车贴右下，保留按键反馈与长按重复。
- **复制预览只显示开头**：服务更新时把内容截成8字，组件又限制230dp并省略。现传递全文，用满胶囊可用宽度，左右滑动查看，滑动不触发粘贴。显示时合并换行，粘贴保留原文换行。
- **重复复制**：历史同文再次复制会解除已消费标记，保持同一历史记录，不生成重复条目。粘贴通过输入连接完成，不再回写系统剪贴板而错误触发新复制预览。
- **日语滑动预览**：参照用户提供的Gboard截图，按住显示中心及四方向假名；滑动时气泡移动、缩放并显示待输入字符，键面显示主题色方向箭头。回中心恢复本行假名，松手才输入，取消不输入。左侧标点也有五方向提示及浮层，窄键盘自适应标签间距。

- **表情插件入口**：最近使用页加入后，分页索引仍减去旧内置分类数，导致滑到插件第一页时跳页；现按实际显示分类数计算。插件标签栏支持横向滚动，窄窗口可访问末尾插件。

未改模型、词典和插件接口；保持原市场手写和Zipformer模型格式。
