## 手写规则

| 状态或操作 | 行为 |
| --- | --- |
| 点击手写图标 | 保持高度进入空白手写面板，图标持续高亮 |
| 再次点击图标 | 返回之前的输入模式，保留已输入文字，结束旧手写会话 |
| 书写区按下/移动 | 记录笔画，单点也可作为点画；功能键区域不接收笔画 |
| 按钮上轻微移动 | 仍按普通按钮规则处理，不转换为手写 |
| 从按钮拖入画布 | 取消按钮点击，不产生笔画 |
| 从画布拖到按钮 | 仍属于原书写手势，不能触发按钮；笔迹裁剪在画布内 |
| 停笔未满1秒 | 保留笔迹，继续落笔取消旧等待并重新计时，不提前上屏 |
| 识别完成 | 显示候选并上屏首选，清空画布；下一字独立识别并追加 |
| 删除，有未识别笔迹 | 清除整轮笔迹和待处理识别，不删输入框文字 |
| 删除，无笔迹 | 删除当前候选对应文字或正常退格 |
| 数字/符号/英文 | 立即执行面板/模式切换，取消未完成识别，旧结果不可迟到上屏 |
| 空格/回车/标点 | 无笔迹时正常输入；有笔迹时先识别，再执行该功能键 |
| 重新进入手写 | 空白画布、无旧候选，不继承旧的文本替换位置 |

采用独立 `HandwritingInputSession` 管理笔画和异步结果；每次取消、切换或新笔画都会使旧推理结果失效。保持原市场 ochwpro 模型、默认1秒及0.5～2.5秒设置兼容。

## 语音

恢复收到部分结果就实时更新输入框，分句结果立即定稿；点击麦克风结束时只收尾，不重复追加整段。识别修订只替换仍在光标前且完全匹配的本句尾部。用户期间插入的文字及主动选区不会被语音修订回删覆盖。麦克风开始/结束切换、主题动画和提示音保持；模型和插件接口不变。
