# CyIME 1.14.72 / 1.14.73

本次提供两个 ARM64 安装包，源码相同（以 1.14.63 为基础，加上日语手写、首页语音开关和键盘调节透明度条三处修正），只是带不带离线模型：

- **轻量版** `CyIME-1.14.72-arm64-v8a.apk`：不内置语音、手写、联想模型，需要时在应用内「扩展商店 › 模型」下载；九键词组模型同样在应用内下载。
- **完整版** `CyIME-1.14.73-full-arm64-v8a.apk`：内置 Paraformer 流式语音、SenseVoice 校正、声纹、手写（含公式）、联想 base/small 模型和公开九键词组模型，装上即可离线使用，体积较大。

两个包都可以直接覆盖安装 1.7.1，保留原有配置和已下载模型；从旧包名 `com.kingzcheung.xime` 迁移的说明见 README。

## 自 1.7.1 以来的更新

**打字与选词**

- 26 键整句按聊天语料重新排序：「被嫌弃了」不再出「被掀起了」，句尾「吧 / 呗」不再出「把 / 被」，「哥你好」不再出「个你好」，「下个月吧」不再出「下个月把」；「的 / 地 / 得」按用法分权，「xx 地」可以直接打 di。
- 九键改用词组模型逐键选词，长句首选更稳，少见读音会扣分（momodi 出「默默地」）；拂动选字母、侧栏符号照旧。
- 14 键、双拼、五笔、笔画、日语假名照旧；雾凇拼音词库和腾讯扩展词库都按公开语料重算了词频。
- 候选可显示英文释义；按住 Shift 点候选或 Shift + 空格直接上屏英文，不再多补空格。
- 英文：整词联想不再出一串单字母，中英切换直接换字不闪。
- 字母键长按大小写气泡改为可选项，默认关；空格旁逗号、句号默认都开，只开一侧时角标换成缺的那个符号。

**语音、手写、字幕、拍照**

- 语音输入可把键盘收成一条悬浮条，边说边出字，麦克风音量光圈，删除键长按连删。
- 字幕模式：把周围的话实时转成中文字幕，自动分说话人并可命名，支持通话字幕；桌面有单独的「字幕」图标，颜色跟随主题。
- 手写：中文、英文、日语和数学公式，S Pen 压感笔迹与笔擦；日语手写内置假名模板，装上「公式手写模型」后就能直接写假名（完整版自带，轻量版在模型页下载）；公式按钮只在英文手写里出现；手写样本可备份、导入。
- 拍照识别：离线文档 OCR，相机面板与结果编辑。
- 模型管理：下载镜像、失败重试、安装包自带的九键模型可直接换掉；模型存到数据目录，不再被系统当作缓存清掉。

**键盘与外观**

- 键盘调节重做：外框贴合键盘轮廓、深色遮罩、实心按钮、顶边「拖动移动」胶囊、圆形透明度滑块；固定高度规则改回稳定版本，首次启动自动修正越界的旧高度；悬浮键盘拖动不再掉帧。
- 新主题与玻璃材质、背景图；主题预览和实际键盘一致；桌面图标可跟随主题色。
- 候选栏两端的返回、展开按钮改为胶囊；设置首页分五组，扩展商店三页可左右滑动；输入手势整套预设（滑动 / 长按 / 英文滑行），冲突项置灰并说明被谁锁定。
- 按键震动改为满强度，抬起和光标反馈八成；按键炫光改回七彩。
- 实体键盘：候选、工具栏和光标行为与桌面一致，快捷键切语言。

**剪贴板与同步**

- 剪贴板固定、折叠、图片来源、快捷发送；刚截的图会在候选栏提示「粘贴」；固定内容不再对插件开放。
- 与 CyIME Windows 扫码或局域网配对，加密传输，多台电脑与设备直连同步。
- 本地备份与恢复取代旧的云同步残留；升级时只备份用户改过的词库文件。

**性能与杂项**

- 更新后立即在后台准备词库，首次弹出键盘不再等待；输入延迟看门狗与性能档位（高配 / 中配 / 低配）。
- 一键打包器、存储门禁与交付脚本（开发用）。
