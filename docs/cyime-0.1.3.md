# CyIME 0.1.3：文本、符号、数字一步互通

## 行为

26 键（中、英、日语、小鹤）、14 键、中文九键、笔画及手写使用两个固定入口。26 键压缩空格以保留逗号和独立语言键；手动分体布局的入口也放在最左侧。

| 当前界面 | 左一 | 左二 |
| --- | --- | --- |
| 文本 | !@# → 符号 | 123 → 数字 |
| 符号 | 中文 / ABC / あいう → 原文本模式 | 123 → 数字 |
| 数字 | !@# → 符号 | 中文 / ABC / あいう → 原文本模式 |

每个入口保留相同的触摸坐标、字号、主题色和视觉间距。符号与数字不再互相堆叠返回历史，连续互切后点击文字标签仍直接回到最初的文字布局。地球键只切换语言；数字返回键长按也不会打开语言菜单。

日语九宫格按用户确认保留「123」和「記号」的原位置，以及转换、光标、变音和拂动标点键。「記号」直接进入统一符号页，移除先到混合面板、再点“符号”的默认路径。

符号首屏固定为对应中、英、日语的 32 个常用符号；最近使用和完整分类仍可在同页选择。日语首行包含「、。？！ー〜・…」。列数根据面板实际宽度决定，悬浮窗口不再照搬整台设备的横屏列数。
