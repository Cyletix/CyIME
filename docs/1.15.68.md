# CyIME 1.15.68

## 贡献样本

- 「贡献手写样本」里写好后点右上角「更多 → 上传」。旧版保存在手机上的样本也可由本人主动分享或上传。上传前可阅读 CC0 1.0，旧版的用途确认需要重新同意。
- 26 键和九键的「滑行练习与贡献」可以自愿上传练习轨迹。每次练习单独开启，关闭或退出会丢弃待传轨迹。日常输入保持本地处理。
- 「贡献词库」允许逐词勾选、核对后上传。词库沿用汇总改进用途，手写和滑行的 CC0 协议仅适用于本人明确同意贡献的样本。[CC0 1.0 中文说明](https://creativecommons.org/publicdomain/zero/1.0/deed.zh-hans)

## 在线语音与手写

- 在「语音转文本 → 在线语音」选服务商并粘贴密钥，点「检测连接」。预设支持 OpenAI、Groq、硅基流动、小米 MiMo、阿里百炼、腾讯 TokenHub 和火山引擎。可展开修改地址、模型，也可为 HTTP 接口填写 JSON 请求体和返回文字的路径。
- 「候选栏 → 候选注释」新增「手写候选显示五笔编码」。开启后，使用五笔方案时写字可查看当前方案的编码；拼音方案继续显示读音。

## 输入与布局

- 修复编辑框在移动光标时丢失组词标记后拼音重复，以及 14 键在拼音中间移光标时显示大写原码。已用平板编辑框和输入引擎重放，两位反馈者的原机微信、小米备忘录仍待验证。
- 修复 Termius SSH 窗口被锁在英文的问题。登录密码框和数字 PIN 继续使用密码输入策略。
- 调整了英文补全、英文句首大写、滑行与角标手势、笔画组词、剪贴板分组排序、候选按钮反馈和布局管理。固定键盘可分横竖屏调整底部留白，悬浮键盘可长按底部短横条一秒锁定或解锁。
