# CyIME 1.15.34

如果键盘显示 `Duplicate key 'engine/translators/+'` 并不断自动重试，请直接覆盖安装本版，再打开输入框。可以保留原有词库和设置，无需卸载或清空数据。

- 修复个人短语和分类词库先后启用时可能写出同名配置项的问题。启动时合并旧文件中的重复翻译器配置，保留用户原有翻译器和个人短语，并为修复过的配置留下原文件备份。
- 「词库 → 导入的词库 → 分类词库英文候选」默认关闭。想按字母找导入词库里的英文词时，可单独打开并点「应用更改」。该功能配置失败时，输入法会尝试恢复中文词库。
- 首次准备被中断后，重新生成损坏的编译缓存。较慢设备等待编译任务完成后再恢复输入。准备仍失败时，引导页和键盘会显示具体原因。
- 修复部分显示缩放下弹出键盘即崩溃，以及 Android 13 长按地球键闪退。
- 长按删除清完拼音或候选后会停住，抬手再按才删正文。修复点按气泡、中文 14 键切换及逐字选人名时收起候选的问题。

两个 ARM64 安装包共用安装序号 `20261386`。

- **轻量版** `CyIME-1.15.34-arm64-v8a.apk`。语音、手写及联想模型可在「扩展 → 模型」按需下载。
- **完整版** `CyIME-1.15.34-full-arm64-v8a.apk`。内置离线语音、手写、声纹、联想及公开九键模型。
