# 手写笔迹与重复返回修复（历史记录）

此修复未覆盖按键触摸问题，已由 [手写交互重做与语音实时上屏恢复](fork-handwriting-voice-rework.md) 替代。下文另名 APK 副本已撤下。

上一版把已识别笔画保留在窗口中，视觉淡出后再次落笔会恢复旧笔迹。本次在默认停笔1秒且识别成功后清空实际笔画和推理缓存。新字起笔时结束旧字的候选替换期，因此新结果追加到之前的文字后，不覆盖旧字。识别完成前继续落笔仍保留当前笔画并重新等待1秒；原市场 ochwpro 模型及停顿设置继续沿用。

手写画布内的额外返回行已移除。返回入口统一在工具栏左侧：有候选时取消本次输入，空闲时返回进入手写前的模式。点击高亮手写图标仍可直接退出手写。

## 验证

14项专用模拟器测试全部通过：
- 真实市场模型停笔测试：识别前画布确有笔迹，识别后像素清空，再次落笔不恢复；连续三轮识别的窗口笔画数分别为2、1、1，覆盖即时续写和长暂停后续写。
- 真实 IME 流程：连续输入两个字，第二字追加；取消只撤销第二字；空闲和候选状态均只有一个左侧返回入口，返回仍恢复原模式。
- 工具栏9项、手写模式切换3项。

构建及 `git diff --check` 通过，arm64 APK 的 v2 签名验证通过。报告与实际截图在 `.gradle/handwriting-fix-20260923/`。测试未操作用户手机。
