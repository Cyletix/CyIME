# 1.2.11 Debug：视觉样式

入口：设置 → 主题与定制 → 视觉样式。

四组预设用于匹配参考图标的材质语言，不替换应用或工具栏图标，也不新增 Rime 主题：

| 视觉样式 | 外观 |
| --- | --- |
| 霓光描边 | 深紫底、清晰的紫白边缘高光 |
| 流光玻璃 | 紫色实体底上的柔和渐变反光 |
| 柔光折面 | 较低反差的紫灰材质 |
| 浅色磨砂 | 浅紫背景、深色文字、白色高光 |

样式作用于键帽、候选栏、工具栏按钮、菜单卡片和设置分组卡片。所有预设使用固定配色和明暗；原有主题与明暗偏好仍然保存。点击“恢复原有外观”恢复旧配置，选择原有配色或显示模式也会退出视觉预设。

材质使用缓存的 Compose 渐变和描边绘制；不是对宿主应用截图或实时背景模糊。键位、触摸范围、输入命令和布局尺寸不由此功能修改。未据此宣称整体输入性能提升。

验证结果：最终 Debug 构建通过，2 项配色单测、2 项样式集成测试、4 项按键回归通过。覆盖预设颜色对比度、选择/保存/恢复、实际键盘组件切换、功能键取色、展开候选/手写长按删除、回车反馈和边缘触摸。四组最终截图已经逐组检查。

验证中 Windows 模拟器进程发生过崩溃，中断记录不算通过。最后使用普通渐变加几何高光的构建，重新独立执行上述测试全部通过；这并不证明此前模拟器崩溃的唯一原因。
