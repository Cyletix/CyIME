# CyIME 1.15.17

这一版一个版本号、一个发布，两个 ARM64 安装包源码相同，只差带不带离线模型：

- **轻量版** `CyIME-1.15.17-arm64-v8a.apk`：不内置语音、手写、联想模型，需要时在「扩展 › 模型」下载；九键词组模型同样在应用内下载。
- **完整版** `CyIME-1.15.17-full-arm64-v8a.apk`：内置 SenseVoice 语音、手写、声纹、联想模型和公开九键词组模型，装上即可离线使用。边说边出字的 Paraformer 不再内置，需要时在应用里下载，完整版因此从约 708 MB 降到约 490 MB。

两个包都可以直接覆盖安装 1.14.156 或更早的版本，保留配置和已下载的模型。上一个公开版是 1.14.156，下面是从那以后的改动（中间的 1.14.157–1.15.16 都是开发包，没有对外发布；1.15.6 的草稿没有公开）。

**从这一版起可以在应用里检查更新**：设置 › 关于 › 检查更新，会找 GitHub 上的最新正式版，下载和你现在同一种（轻量／完整）的安装包交给系统安装。自动检查默认关，可以在同一页打开。

**默认关闭、需要自己打开的新功能**：九键双拼、首道双拼、中英混输、输入成对符号、繁体输出、注音、仓颉、西班牙语、生僻字、模糊音、双拼邻键纠错、中文滑行输入。

## 新功能

**双拼**

- 可以新建、修改、保存自己的双拼方案（语言与方案 › 双拼方案）。
- 内置小鹤、首道、自然码、智能ABC、拼音加加、微软双拼，新装和升级都会显示在方案栏（排在中文 26 键后面，全拼仍是当前方案）；每个方案在双拼方案页可以单独隐藏。
- 每个双拼方案都有 14 键版本；小鹤、首道和自建双拼另有九键版本（默认关）。
- 双拼和五笔、导入的码表都能用 QWJRTK、Colemak 和自己排的字母布局打。
- 双拼 26 键可单独打开按错相邻键的纠错（默认关）。

**更多语言和方案**

- 繁体输出：随包 OpenCC 转换表，按台湾用字；九键、14 键都能用，可以把「简繁」开关放到工具栏一点切换。
- 注音（大千）键盘，台湾词与台湾读音（默认不启用）。
- 仓颉五代和字根键帽 26 键，在输入方式面板的方案行里和拼音、双拼、五笔并列（默认不启用）。
- 西班牙语：26 键带 ñ、长按出重音字母、词表补全（默认不开）。

**打字**

- 中英混输（设置 › 26 键输入，默认关）：nihaohelloshijie 首选「你好hello世界」。
- 中文滑行输入：全拼、双拼 26 键一笔划出一个词的拼音。
- 生僻字（默认关）：打完整拼音时常用字后面补上约 1.8 万个生僻字。
- 模糊音：z/zh、c/ch、s/sh、n/l、f/h 等可逐组打开（默认全关）。
- 英文滑行连着划时前后两个词一起选，缩写上屏带撇号（I'm done）。
- 「那个」排在「哪个」前面，常选「哪个」也不会把它挤下去。
- 快速连打同一个键不再吞键。
- 输入成对符号（默认关）：点开头的引号、括号、书名号时连结尾一起输入。
- 全角只换标点，候选里的英文、数字照原样上屏。
- 手写英文句子按词间空隙分词并自动加空格。

**语音**

- 新装默认用 SenseVoice：带标点、整句定稿，第一次打开自动下载 SenseVoice 而不是 Paraformer；以后下载了 Paraformer 会自动改成边说边出字＋SenseVoice 校正。
- 长按空格改为按住说话，松手结束并上屏。
- 去掉「使用本地模型」开关，一律先用本地；在线接口测试通过才可优先使用。
- 第一次点麦克风授权后直接开始语音；安静环境开语音不再上屏「我。」。
- 移动数据下不再自动下载默认模型，等连上 Wi-Fi 再下，也可以点提示用流量下载。
- 模型下载加上 CyIME 自己的备用地址，原站和镜像都下不来时改用它（文件逐字节相同，按原哈希校验）。

**外观**

- 按键形状：圆角、方形、直角。
- 「用自己的图片」做键盘背景（主题与外观 › 背景图片）。
- 键盘顶部圆角可以关；「填满留空处」开关（默认关）。
- 玻璃效果下候选栏、工具栏的字在深色应用上也看得清。
- 全面屏手势下键盘下面只留手势条。

**剪贴板**

- 自定义分组（常用语、工作等）。
- 短信验证码只在候选栏提示 3 分钟，关掉或已经填进输入框后不再出现。

**设置**

- 按设备推荐配置：看内存、处理器、剩余空间和网络，问语音、九键、字幕怎么用，推荐留哪些模型，点「按推荐设置」才改。
- 新装默认「自动」性能档位；设置搜索认繁体字。
- 自建的双字母布局（自己合并的 14 键等）可以改上下角标；14 键有自己的一套符号角标。
- 实体键盘可选让联想也显示在候选窗。
- 终端（SSH）输入框里方向键、命令历史、粘贴按终端规则走。

## 修正与安全

- 删掉浏览器导入：原来同一 Wi-Fi 下任何人不用密码就能看、下载、删除 CyIME 的数据目录。
- 正式包补签 v1，vivo 不再报「安装包缺乏开发者证书」。
- 小米等机型按键震动不再嗡嗡响，跟随系统时用系统按键触感。
- 横屏新装默认固定、不透明。
- 数字、符号面板回车键图标跟随输入框（换行、搜索等）。

1.14.157–1.15.6 之间更多的改动（编辑面板、九键标点栏、悬浮键盘拖角调大小、剪贴板去重等）见 [1.15.6 说明](https://github.com/Cyletix/CyIME/blob/main/docs/1.15.6.md)。
