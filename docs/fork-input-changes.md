# Cyletix fork：基础输入体验改进

对应上游 issue #931，基于本地 2.8.6 代码。修改保留在工作区，未提交 Git。

本文保留第一轮已验收记录；当前安装包已由第二轮更新，最新行为、测试结果及校验值见 `docs/fork-round2-changes.md`。

## 已实现的行为

| 反馈 | 实现 |
| --- | --- |
| 九键数字上滑缺少提示 | 默认 1–9 使用键面和气泡双提示，补齐 1 键的气泡接线；紧凑布局也可显示预览。 |
| 英文上滑混入普通字符、提前输入 | 字母键共用一个手势处理器，滑动只预览、松手单次提交；取消和滑回不补普通字母，横竖屏一致。 |
| 工具栏对齐及点击反馈 | 按可用宽度均匀分布；溢出可横向滚动；整个圆形触控区显示灰白背景和 ripple。 |
| 辅助手写与编辑图标 | 默认工具组加入辅助手写和编辑；手写沿用当前方案直接提交结果，缺模型时引导下载；编辑使用四向箭头。既有工具栏配置保留，可在定制页添加入口。 |
| 空格精细光标控制 | 默认长按 300ms 后左右滑动；默认 10dp 一字，可调 6–24dp。另可选语音或连续空格；共享组件覆盖各布局。 |
| 定制工具栏截字 | 改为可滚动网格、固定图标尺寸和正常标签行高。 |
| 自定义固定符号 | 布局与显示 → 基础输入：每行一个符号/短语，支持填入常用符号；九键/笔画固定栏和常用符号键盘共用，留空回退方案默认值。 |
| 语言键长按选方案 | 长按打开列表，滑动选择、松手确认；支持长列表边缘滚动，使用方案 ID，避免重名误选。 |
| 编辑方向键失效 | 左右优先操作真实选择区，处理文本片段偏移和 Unicode 码点；宿主不支持时回退按键事件；不经 Rime 处理。上下保留宿主的视觉行移动。 |
| 编辑按键长按 | 方向、删除、回车长按 300ms 后每 70ms 重复；松手、取消、移出和离开面板停止。 |
| 编辑/普通按键图标 | 编辑操作改用图标，常规键盘回车按输入框动作显示发送、搜索、完成等图标，保留无障碍文字。 |
| 按键字母字号 | 布局与显示 → 基础输入：80%–160%，默认 115%；与候选词字号独立。 |
| 悬浮入口整合 | 调节界面增加悬浮开关，确认时应用；悬浮中也可调节，取消保持原模式。旧工具栏入口兼容转到键盘调节。 |
| 悬浮贴边恢复 | 连续贴边满 1 秒显示底部恢复预览，松手后恢复；离边、换边及取消清除或重置计时。 |
| 大小写显示锁住 | Shift 使用单一状态源，取消横屏延迟；键帽、图标、提交一致，单次 Shift 输入后复位，Caps 保持；保留中文和混合自定义标签。 |

## 设置与实现边界

- 新的基础输入设置不绑定具体 Rime 方案。方案仍负责字词转换、候选及自定义映射。
- 工具栏、字号和快捷符号不会覆盖用户的现有方案文件。
- 辅助手写复用项目已有的辅助模式；保留旧手写方案兼容，避免破坏现有配置。
- 横竖屏共用字母、空格和语言键交互，减少多份实现产生的行为差异。

## 本机构建

- 项目需要 JDK 21 运行 Gradle，Android SDK 36、NDK 29。
- 工作区路径含空格，上游 native 构建参数不兼容；本次使用指向同一仓库的无空格盘符构建，不改 native 源码。
- `.gradle/build-local.ps1` 是本机环境辅助脚本，未纳入版本控制；在已映射的 `X:\` 工作目录中运行，例如 `& X:\.gradle\build-local.ps1 assembleDebug --quiet`。
- 检查项目：`assembleDebug`、`testDebugUnitTest`、`compileDebugAndroidTestKotlin` 以及独立模拟器中的新增 Compose 测试。

光标位置实现遵循 [Android ExtractedText 文档](https://developer.android.com/reference/android/view/inputmethod/ExtractedText) 的 `startOffset + selectionStart/End` 规则。
