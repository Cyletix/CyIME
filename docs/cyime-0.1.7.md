# CyIME 0.1.7：拼音编辑、语音标点与按键动画

版本 `0.1.7`，内部版本号 `20261005`，保留应用 ID、覆盖签名与用户设置。

## 按键效果

按用户最新给出的时间替代 0.1.6 的一秒效果：总长 500 ms。整个键帽在 0–50 ms 缩小至 88%，50–100 ms 保持，100–150 ms 恢复；150 ms 之后尺寸不再变化。光晕在前 10 ms 内升至高亮，方块保持大面积至 100 ms，之后按三次衰减缩小、淡出，尾段逐渐放慢，500 ms 消失。具体显示受屏幕帧率和帧调度限制。

随机圆角方块及光晕仍裁剪在键帽内，文字在其上。包含背景与阴影的视觉缩放不改变键盘布局或按键触摸区域；快速连点重启动画，关闭立即移除，默认关闭不变。

## 全角／半角

恢复菜单第一页的「全角／半角」直接开关，显示当前「半角」或「全角」，点击即切换。键盘调节和设置保持第一、第二项；不在输入选项里重复此入口。其他方案选项继续集中显示状态。保持此前对英文意外全角的保护；此开关控制中文方案字符宽度。

## 拼音

- 预览即显示音节分隔符，不再只有进入编辑后才显示。编辑前后共用 18sp 字号、32dp 半透明底框、圆角及内边距，外部含上下留白为 44dp。
- 打开编辑时，把引擎显示的分词符保存在编辑缓冲里。光标可以停在分词符两侧，原键盘删除键可逐个删除；不会因移动光标触发引擎重新分段而让分词符消失，也不在删除后立刻把它补回。
- 仅打开或移动光标不重写原始拼音、不锁定九键候选；实际编辑才将编辑串应用到 Rime。九键新输入仍显示读音而非数字；原键盘、已上屏前文、已选前缀和会话保护保持。
- 仍为键盘上方的非聚焦浮层，不增加编辑操作键排、不压缩键盘；删空关闭。

## 语音文本

修正所有标点一律换空格误删数字含义的问题。保留 `0.05`、负数、百分比及数字算式中的小数点和运算符；覆盖模型先显示汉字、再修订为数字的路径。

普通自动断句标点仍转为空格，不自动加句末句号。识别文本中的口述「逗号」「句号」「问号」「叹号」（含「感叹号」叫法）分别转换为 `，。？！`，其他符号名称不扩展转换。转换只在最终上屏边界执行一次；模型清理、分段拼接保留口述名称，停止/超时提交直接使用已转换预览，避免再次删掉主动口述的标点。此改动修复文本后处理，不改变模型本身的听写准确率。
