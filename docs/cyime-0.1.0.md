# CyIME 0.1.0

正式显示名称为 CyIME，版本独立从 0.1.0 开始。内部版本码为 20260928，继续递增以支持覆盖安装；不继续沿用原项目的 2.8.x。保留原安装标识、签名及配置文件接口，延续现有数据。GPL-3.0、原项目署名和第三方许可保留。品牌迁移边界见 [命名记录](cyime-identity.md)。

## 配色与尺寸

- 首次安装默认“柔和蓝”，手机和平板使用同一固定调色板。旧默认紫色/动态色迁移一次，此后重新选色会保留。
- “跟随系统动态配色”仍可选择。它读取每台设备的系统调色板，因此不同壁纸、系统设定下蓝色和青色不同属于该选项的正常行为。
- 旧深色功能键直接铺满较重的主色；现在改为带主题色的柔和容器，并统一主题预览与实际键盘取色。薰衣草紫仍保留。
- 按键文字、图标和假名浮层按实际键帽尺寸缩放，不按整个屏幕盲目放大。小悬浮窗及较大系统字体有宽高限制；等权分列的像素取整不再导致相邻键字号不同。
- 日语主标签不再误用五笔字根字体，使用与其他文字键相同的主字体。

## 中文、日语和英文

默认中文采用 [雾凇拼音](https://github.com/iDvel/rime-ice) 的词库与对应方案，提供中文九键、中文26键、中文14键、小鹤双拼四种入口。它们是不同键位/编码方式，不再把旧简体拼音与雾凇重复列作两个全拼选择。

离线资源固定在上游提交 `9e66b0729083b37d217312294f6d516c8d7234be`，构建校验下载摘要，随 APK 分发中文词典、英文依赖、Lua 和 OpenCC 文件，无需安装后再下载中文词库。构建说明位于 `app/build-logic/tasks-chinese.gradle.kts`，许可随资源打包。

英文保留一个常驻入口。Easy English Nano（melt_eng）作为中文方案依赖继续存在，但不重复占语言菜单。日语26键、日语九宫格保留各自布局与原有片假名、拂动、转换功能。其他手动安装的独立方案可从“其他已安装方案（高级）”管理。

保留标准 schema ID、市场包格式和个人补丁。安装有共用文件的方案时逐文件备份、替换和登记，不能再先卸载整份 builtin；卸载更新时恢复原文件，保留无关日语资源、个人词库和启用选择。builtin 显示为“CyIME 内置资源”，不提供整包卸载。

## 调节界面与输入手势

- 调节透明度时键盘预览可变透明，滑条卡片、文字和操作按钮保持不透明。背景加深，文字按可用区域放大。
- “悬浮/固定”使用带图标、填充和边框的按钮，和重置、确认同排；点击立即生效并留在调节界面。
- 点按字符气泡默认关闭，保留按键光效。需要气泡时仍可在“布局与显示”手动开启；日语拂动和长按选字提示不受影响。
- 普通键与可滑动文字键共用一次手势的独占提交判定，松手最多提交一个动作。数字等直接输入与 Rime 编码排队处理，避免旧编码在之后的按键中重新出现。

## 验证

本轮 79 项定向 JVM 测试、54 项去重 Android 场景通过。真实输入服务验证了中文26/14键输入并选中“你好”、14键全部10个数字上滑、已有编码时接数字与下一键、英文不重复上屏、日语大写片假名保留，以及九键数字后立即输入下一键不丢失。

截图检查覆盖普通手机、平板、窄悬浮窗、较大系统字号，以及改变透明度时调节按钮保持清晰；模拟器不能替代所有厂商设备的视觉和触觉验收。市场验证覆盖真实雾凇文件的 ZIP 安装、替换、卸载恢复和个人文件保护，不表示所有第三方包已逐个测试。
