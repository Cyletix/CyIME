# CyIME 0.1.11：首次使用、联想队列与编辑面板

## 首次使用

- 内置雾凇词库继续随安装包提供，中文九键、14键、26键和小鹤双拼共享词库，无需额外下载才能输入常见词。
- 部署完成状态必须同时具备已编译方案、有效词典和拼写索引；文件缺失时重新部署，不再仅凭缓存标记判定可用。词库子目录变化也会触发检查。
- 输入法和应用初始化串行复制资源。语音、智能联想独立进程不再重复加载输入法运行时或并发部署同一份词库。
- 首次启用输入法即可准备默认手写 ochwpro 和语音 Zipformer 模型，不必先打开设置主页面。失败可重试，恢复联网后也会重试；用户主动删除的模型不自动补回。下载沿用市场暂存、完整性验证及安装流程。
- 候选取消箭头和智能联想默认关闭，保留用户已有选择。工具栏里的返回导航按钮不属于候选取消箭头。

## 智能联想

- 输入突发结束后延迟160ms再发起模型推理。同一管理器最多一个正在执行的推理，只保留最新待处理上下文。
- 新按键、退格和会话变化取消旧请求；无法中断的原生调用结束前不再堆叠下一批任务，过期结果不得回写。
- 较慢推理结束后增加冷却时间，最长1.5秒。此项限制连续推理负载，不改变词库候选，也不替用户切换模型。
- 已验证队列和取消行为；未用朋友的低端手机进行帧率、温度或耗电测量。

## 编辑面板

- 左列：撤销、重做、剪切。右列：删除、全选、回车。
- 中央保留3×3位置关系：段首／上／段尾，左／选择／右，复制／下／粘贴。全部使用同一组行列边界，四角与两侧顶行、底行对齐。
- 保留圆形方向盘，按中央区域可容纳的最大直径显示。常规宽高比下顶齐上下按键边缘；极高窄尺寸限制直径以保持正圆。
- 圆盘周围四角留等比例间隙，图标上、文字下；中央选择和右侧全选使用不同图标。撤销／重做走宿主键盘快捷键。

## 验证

- 专用模拟器清除本应用数据后，未打开设置主页面、未下载预测模型，四种中文方案均能选出“怎么”，九键与26键能选出“打字”；默认语音、手写模型自动准备完成。
- 联想突发请求、过期结果和不可取消的慢推理覆盖JVM测试；输入、候选选项、编辑几何、长按及真实宿主剪切／撤销／重做覆盖Android测试。
- 未操作用户个人手机。首次启动编译词库与下载模型仍需要时间；网络失败不等于模型已安装。
