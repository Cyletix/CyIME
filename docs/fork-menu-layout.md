# 菜单、方向键边界与设置对齐（2026-09-23）

上一轮统一工具栏返回时漏掉了菜单页：展开后 Logo 仍保留，菜单内部又有独立50dp关闭/设置行。菜单卡片同时按屏幕宽度强制正方形，在键盘调矮后，两排内容超出可用高度，出现文字裁切和卡片相互挤压。

## 本轮修改

- 菜单使用与手写、编辑、方案列表相同的工具栏左侧圆形返回；Logo 原位替换，工具栏坐标不变。删除菜单内部的关闭/设置顶行。
- 设置入口保留为菜单网格项，向左翻页可见；原有菜单项与方案动态开关保留。
- 网格按实际可用高度分配行高，取消宽度决定高度的正方形约束。正常竖屏最多两行四列；矮键盘或大字体使用一行分页，横屏一行八列。卡片之间始终留间距。
- 菜单标签支持两行，竖屏字号12sp、横屏11sp，避免文字被上下裁切。动态方案长标题超宽时省略显示。

## 追加反馈修正

- 左右方向键在文本片段边缘以前会直接发送DPAD事件，文首/文末也会继续发送，宿主可能把焦点移到输入框外。现在通过周围文本计算绝对光标位置并在真实文首/文末截停；长文本片段可继续跨越，反向选区保留锚点，UTF-16代理对保持完整。宿主拒绝setSelection时，事件回退也检查已知边界。
- 内置英文原先单独使用ListItem，其边距、圆角和开关占位与其他方案不同。现在复用同一SchemaToggleItem卡片，开关对齐并始终启用、不可关闭。
- 空格长按行为从两个独立纵向选项改为一行两列、等宽铺满，切换保存行为保持不变。
