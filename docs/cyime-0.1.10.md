# CyIME 0.1.10：标点宽度与柔和光效

版本 `0.1.10`，内部版本号 `20261008`，支持覆盖安装。

## 全角／半角

此前菜单只修改引擎的 full_shape，键盘直接上屏的标点绕过了该选项。现在全角／半角接入统一的标点提交路径，中文九键、14 键、26 键、英文、日语九宫格和日语 26 键共用持久设置，符号页与上滑标点也遵守该设置。菜单显示实际生效状态。

半角输出逗号、句点等 ASCII 标点；全角输出对应全角标点，日语保留顿号、句号。英文全角标点与字母宽度分开，英文字母仍正常输出，避免整串全角英文。拼音内的分词符保留编辑语义；数字面板计算、语音小数、粘贴正文与表情不做标点宽度改写。没有半角对应形式的符号保持原样。

## 按键光效

总时长仍为 500ms，默认关闭。键帽连续下压并回弹，在约 38ms 达到最小，在 150ms 平滑恢复，删除中间停顿。光斑位移和旋转采用快速起步、逐渐减速的曲线；透明度独立淡出至 500ms。

硬边旋转方块替换为缓存的径向渐变光斑，以 Screen 滤色叠加；文字绘制在光效之上。触摸区域不随键帽缩小，未增加实时模糊或每帧位图。实际 Android 渲染帧已检查；未在低端真机测量性能，也不宣称与三星效果完全一致。

## 验证

5 项定向 JVM 测试、28 项 Android 测试通过：12 项实际标点／直接输入、7 项光效、7 项拼音编辑、1 项菜单、1 项日语转换。光效以实际 Android 渲染帧检查。整合测试曾遇到 Windows 模拟器原生崩溃，未完成的运行不计入通过；恢复后标点和共享输入路径分别复测通过。

构建、APK 版本、覆盖签名、中日词典及语音／手写资源校验通过。测试记录与渲染帧位于本地 `.gradle/cyime-0110/`。未操作个人手机；真机观感与低端设备性能仍需用户验收。
