## 开始使用

1. 从 [Releases](https://github.com/Cyletix/CyIME/releases) 下载安装包。轻量版不带模型，用到语音、手写、联想时再在应用里下载；完整版（文件名带 `full`）自带这些模型，装上就能离线用。
2. 打开 CyIME，按设置向导做完三步：在系统里启用 CyIME、准备输入方案（第一次要等几分钟准备词库）、把当前输入法切换成 CyIME。
3. 设置首页最上面的输入框可以直接试打。

升级时直接覆盖安装新版，不要先卸载，卸载会删掉词库和设置。

## 切换语言和键盘

CyIME 把“语言”“输入方案”“键盘布局”分开：语言是中文、日语、英文；方案是拼音、双拼、罗马字这类编码规则；布局是 26 键、九键、14 键这些按键排法。

- **设置 → 语言与方案**：点开一种语言，选它用哪个方案和布局，下次切到这个语言时就用这一套。长按语言可以调顺序。
- 自带的组合：中文拼音（26 键、九键、14 键）、小鹤双拼，共用雾凇词库；日语罗马字 26 键和假名九键，共用日语词库；英文。其他方案在「扩展 → 方案」下载，或导入自己的 Rime 方案。
- **语言键**：点一下切换，按住弹出语言列表。点一下的规则在「语言与方案 → 语言键切换方式」里选：当前语言和英文互切（默认）、按顺序轮换所有语言、或固定某种语言和英文互切。按住多久弹出列表在「按键与手势」里调。
- 进入号码、验证码这类数字框时，会自动换成数字键盘（「键盘布局 → 数字框自动数字键盘」）。数字键盘上可以直接算式子，比如打 `12+30*2`，候选栏会给出结果。

## 打字

中文九键可在「设置 → 输入 → 键盘布局 → 九键与 14 键 → 模糊音」按组开启近音，例如「s 和 sh」或「in 和 ing」。修改后等方案重新部署。平时直接按数字沿用原来的候选顺序；想找近音时，点左栏的读音或带 ≈ 的近音。例如全拼按 `7454` 后点 `si`，能同时找到“司机”和“实际”。这些开关与 26 键共用，双拼九键还需打开「模糊音也用于双拼」。

**候选**

- 空格上屏第一个候选，点哪个候选就上屏哪个。拼音候选和上屏后的多个联想词都用最右侧的向下箭头展开，向上箭头收回列表。联想时，带键盘图案的按钮可以单独收起键盘。选拼音候选时，展开页可以切成“只看单字”。
- 长按某个候选可以“忘掉学习”：词库里本来有的词回到原来的位置，自己打出来的新词会消失。不会把词库里的词永久藏起来。
- 有编码没上屏时按回车，上屏的是打出的字母本身（日语上屏假名读音）；没有编码时按回车，就是输入框自己的发送、搜索、下一项或换行。
- 候选栏可以给候选标注拼音，或者中英释义，在「候选词 → 候选注释」里选。
- 在「语言与方案」开启「时间日期候选」后，输入 `ts`（拼音九键输入 `87`）可选本机当前的 Unix 时间戳。这项默认关闭。
- 中文全拼 26 键有邻键纠错：手指按偏到相邻的键时也会给出对的词，原输入保留。双拼不用。

**九键**

- 1 键是分词，用来手动隔开拼音。
- 全拼和小鹤等双拼九键在组词时，右侧的 0 会变成「下一项」箭头。点一下移到下一个候选，左滑回上一个，按空格确认。空闲时点它输入 0。
- 启用中英释义后，从这个箭头拖到目标候选上松手，可以输入该词的完整英文释义。候选栏滑到后面的词也可以这样选。没有可上屏的完整英文时选中中文。
- 「重输」只清掉正在打的编码，已经上屏的字不动。
- 左侧一列是符号侧栏，没在打字时显示，内容可以在「键盘布局 → 按键符号」里改。
- 开了「拂动选字母」后，在键上往左、上、右、下拂动，依次输入这个键上的第 1～4 个字母；长按改成输入数字。
- 「九键与 14 键」里的「九键滑行输入」默认关闭。开启后，连续划过数字键中心，松手后照常选词。例如划 `5 → 2 → 4` 可以选「来」。需要连续输入两个相同数字时，可以松手再点一次。

**14 键**：每个键两个字母。新装默认提供小鹤双拼和中文 14 键。在键盘菜单选「小鹤双拼」，再选「14 键」即可使用。旧配置里如果找不到，在「设置 → 语言与方案 → 已安装的方案」打开小鹤双拼和中文 14 键，点「应用方案更改」。开启「左右滑动选字母」后，左滑输入左边的字母，右滑输入右边的。

中文 14 键轻点一次 `as`，两种字母的汉字都可以进入候选。想只看其中一个，点候选栏右侧的展开箭头，在左栏点 `a` 或 `s`。点 `s` 后可以直接选「是」，也可以改点 `a` 或继续打后面的字母。小鹤双拼 14 键也支持这样点选，候选按双拼键位产生。左下角的「单字」用于只看单字候选。

**英文**：英文 26 键可以开「滑行输入」，手指一笔划过字母出整个词，候选栏能换成别的词。

**日语**：罗马字 26 键或假名九键。假名九键往四个方向拂动输入同一行的其他假名；「假名方向提示」打开后，键的四周用灰色小字常显这四个假名。

**全角半角、无痕**

- 工具栏菜单里的「全角/半角」切换标点宽度，英文模式固定半角。
- 「无痕」打开后不学新词、不记联想、不记剪贴板、不同步。在密码框里会自动进入无痕。

## 按键与手势

在 **设置 → 按键与手势** 里调，所有布局共用。

- **按键角标**默认显示上、下两行提示，下拉输入上角标，上滑输入下角标。「反转上下滑方向」可对调两者，也可以改用长按输入上角标。
- **按键音色**默认使用实录的 Rain75 紫薇轴。在「按键效果 → 按键音色」可给屏幕键盘选择经典音色。
- **手势预设**：滑动、长按、英文滑行三套，一次切好一整套；单独改过某项后显示为“自定义”。
- **长按字母**：26 键和 14 键长按字母弹出大小写和带声调的字母，九键长按弹出本键的字母，可以关掉。
- **删除键横滑**：从删除键向左滑约 24 dp 删除第一个字，再滑每 14 dp 多删一个；不松手往右滑，刚删的字会逐个回来。手指停住就不再删，抬手确定。拼音还没上屏时只动编码，删空也不会接着删正文。
- **删除键竖滑**：默认下拉清空、上推撤回；「反转上下滑方向」可以对调这两个动作。短按退格、长按连续退格照常使用。
- **移动光标**：默认长按空格后左右滑动移动光标，也可以改成整个键盘滑动来移动；可以调每移一个字需要的距离，以及移动时振动或响声。
- **长按空格**：不用来移光标时，可以设成连续输入空格，或开关语音输入。
- **拂动和滑动的触发距离**：九键拂动、14 键左右滑和日语假名拂动共用一个距离，越大越不容易误触。

## 工具栏和面板

候选栏没在打字时显示工具栏。默认是输入方式、表情、编辑、剪贴板、手写、语音；最右边的菜单里还有设置、键盘调节、拍照识别、声音振动、悬浮、玻璃、无痕、全角/半角、字幕、排列等。

在「编辑」面板点「粘贴」按目标应用的方式粘贴；长按「粘贴」使用系统剪贴板的纯文本。复制的是 HTML 源码时，标签和换行作为文字粘贴；复制的是网页正文时，粘贴的是正文。

- **排列**：长按拖动，决定哪些按钮放在工具栏、哪些放进菜单、哪些不用。菜单超过 8 项会分页。「设置」必须留在工具栏或菜单里。
- 在键盘快捷菜单或设置子页，从菜单右侧向左平滑一段距离，松手返回一级。上下滑动照常翻页，快捷菜单中部仍可左右切页。
- **编辑**：方向键、选择、全选、复制、剪切、粘贴、段首、段尾、撤销、重做。
- **符号**：常用、最近、全部三页。
- **表情**：表情和颜文字，带最近使用。
- **输入方式**：直接切到某个已启用的方案。

## 剪贴板

点工具栏的剪贴板打开。

- 记录按全部、文本、链接、地址、电话、邮箱、图片分类，在记录区左右滑动切换分类。
- 顶上可以搜索，支持文字和拼音首字母。搜索时临时进入无痕，搜的字不会被学进词库。
- 常用的内容可以**固定**，固定的放在最上面，多了可以收起和展开。也可以直接「新增固定内容」手动写一条。
- 长按一条记录打开操作菜单：固定、编辑、分词、删除，还能进入「多选」批量固定或删除。「清空未固定」只删没固定的。
- 「分词」把一条记录按词库拆开，挑其中几段上屏或固定。
- 刚截的图会在候选栏提示，点一下就能粘贴；也可以在菜单里关掉这个提示。
- 「上屏后自动关闭剪贴板」关掉后，可以连续贴多条（设置 → 剪贴板与同步）。
- 剪贴板记录只存在手机上，可以在「剪贴板与同步」里导出成文件。

**验证码**　在「剪贴板与同步」打开「新短信验证码自动复制」，允许 CyIME 接收短信。之后收到的新短信里，识别出的验证码数字会复制到剪贴板。若已在系统设置里授权，返回后看一下这个开关，仍关闭时再点一次。系统没有提供短信权限选项时，可以从短信里手动复制验证码数字。

## 语音、手写和拍照识字

全部在手机上处理，不联网。

**语音**

- 先在 **设置 → 语音转文本** 打开语音输入，并下载语音模型（完整版已自带）。
- 点工具栏的麦克风开始说话，再点一下结束。也可以把「长按空格」设成开关语音。
- Paraformer 边说边出字，SenseVoice 在停顿后整句校正并加标点。
- 模型常驻还是用完就释放，在「性能与省电」里设置。

**手写**

- 点工具栏的「手写」打开手写板，支持中文、英文、日语和数学公式，可以切成全屏手写。
- 写完停顿一会儿开始识别，停顿时长在「按键与手势」里调（默认 0.5 秒）。
- 公式手写要先下载公式手写模型，上屏时两边加不加 `$…$` 或 `\[…\]` 可以选。

**拍照识字**：菜单里的「拍照识别」在键盘里直接开相机，或者从相册选图，把文字放进中间的框里识别后上屏。中文和英文的识别模型随应用自带。

## 字幕模式

给听力不好的人用：打开后把身边人说的话实时显示成大字。

- 从桌面的「字幕」图标、下拉快捷开关，或键盘菜单里的「字幕」进入。桌面图标在「语音转文本」里开关。
- 可以听中文、日语、英语，第一次使用要下载对应的语音模型；声纹模型（27 MB）用来分出是谁在说。
- 点一句话可以标出是谁说的，给这个人起名字，选「记住这个人的声音」后下次自动认出。声音特征只存在这部手机里。
- 有快捷回复和自己写字，点一下大字可以倒过来给对面的人看；有一键拨打 120。
- 字幕可以保存成文件，只记文字，不录音。
- 打电话、微信视频时也能开通话字幕，需要开免提。

## 键盘大小、悬浮和外观

- 菜单里的「键盘调节」：拖边框改大小，拖中间移动位置；可以调透明度、底部留白，切换悬浮和分体，分体时拖内侧两条边调中间的空隙，「重置」恢复默认。
- 想让固定键盘更矮，在「键盘调节」把上边往下拖。想缩小最后一排下面的空白，向下拖「底部留白」或点旁边的「−」，每点一次减少 2 dp。「＋」可以调高。点「确认」保存，点「重置」回到默认位置。「手势导航时键盘贴底」开着时底边从屏幕底边量起，可以一直拖到屏幕底边，拖到哪里确认后就停在哪里；关着时最低到系统按钮或切口上沿。
- 固定键盘向上直拖可以转为悬浮，横向挪动不会轻易切换。悬浮键盘明显向下拖到底，预览框到位即可松手恢复固定。如果本来就在底边附近，短下拖后停约 0.3 秒再松手也可以。
- 如果底边被系统挡住，直接打开 CyIME 应用，进入「设置 → 键盘布局 → 底部留白校准」。选用 CyIME 时会自动显示真实键盘。空白太多点「调低」，底排被挡点「抬高」，每次 2 dp，点按即保存。也可以点「收起键盘」腾出空间，再点页面底部的「显示键盘」查看效果。「手势导航时键盘贴底」（Android 10 及以上）默认打开：手势导航时忽略系统给输入法留的底部边衬区，键盘贴到屏幕底边；打开时「调低」还能从贴底位置继续往下调。想撤销校准就点「恢复系统建议」。三键导航按钮、任务栏、系统画在键盘窗口里的导航按钮和底部缺口占用的空间会保留。固定键盘每次换位置都会自检：输入法窗口没铺到屏幕底边时自己铺到底；贴底时手势导航按系统给的边衬区自己认出来(导航栏比手势区高、又没有占满的按钮)，不靠厂商开关。卡片比屏幕窄时，底下系统按钮那条只和卡片一样宽、颜色接着卡片，两侧透出应用(「填满留空处」开着时整宽)。
- 选用 CyIME 后，主题与外观、键盘布局、按键效果、按键符号、按键与手势、按键技巧、候选词、智能联想、26 键、九键与 14 键、语言与方案和双拼方案页会自动显示只读键盘。普通键、候选和工具栏都不响应输入。布局专项页显示对应的键面，候选和联想页用固定词例，物理键盘页显示工具条和候选。点「收起键盘」可让出屏幕空间，再点「显示键盘」展开。
- 「键盘尺寸与位置」和「工具栏与菜单排列」也先显示普通键盘。点设置页的「调整尺寸」才出现外框和滑条，点「编辑排列」才可以拖动工具栏按钮。点「确认」或勾号，就能看到改完后的普通键盘。
- 候选词太大时，在「设置 → 候选词 → 候选字大小」把滑块往左拖。基础字号可选 12–22 sp，默认 19 sp。候选栏和展开列表共用这个设置。
- 「悬浮」把键盘变成可以拖动的小窗。
- **设置 → 键盘布局**：自定义布局（新建、复制、编辑按键排列）、按键符号（26 键角标、九键和笔画侧栏、手写和常用符号栏）、分体键盘、三行字母的错位方式。
- **设置 → 主题与外观**：跟随系统、浅色或深色，玻璃效果，配色方案，视觉样式，按键字号，角标提示，点按气泡，底部圆角；桌面图标可以跟随主题颜色。
- 在「设置 → 候选词 → 编码显示」选择「显示在输入框」，拼音就只在正文光标处出现，选词后由汉字替换。选「显示在候选栏」可用浮动拼音栏，或打开「拼音放在键盘内」；两种都不往正文插入拼音。终端按键式输入框使用候选栏。候选注释和每页候选数在同一设置页调整。
- **设置 → 按键效果**：按键音、音色、音量，振动的强弱和时长，按键动效和炫光，录屏时是否录进按键音。

## 词库

**设置 → 词库**：

- **自定义短语**：在「我的短语」里保存文字或符号和编码，全拼、双拼都可以用。例如给四个表情都填 `oof`，26 键打 `oof`，九键按 `663`，14 键点两次 **OP** 再点 **DF**，四项都会优先出现。同码可以保存多条，权重越高越靠前。
- **你学到的词**和自定义短语不一样：它是打字时自动记下的，不用手动加；长按候选“忘掉学习”就是删它。
- **分类词库**支持下载搜狗细胞词库，也能导入带拼音的本地词表。在「词库 → 导入词库 → 导入文件」选好文件后，点「应用更改」。已学到的词在关闭词库后仍保留。
- 小鹤九键按 `9577288453` 找不到「形容不上来」时，可以导入这份四条词的词表。同码的「完全不上了」也在表中，两种意思都可以选。[口语短语.txt](config_examples/口语短语.txt)
- 要删除已下载或自己导入的词库，打开「词库 → 导入词库」，关闭该项，点「应用更改」，再从这项的「更多操作」点「删除词库」。安装包自带的词库可以单独关闭。
- **方案词库**：查看当前方案词库里的词。
- **屏蔽的候选**：以前版本长按删除会把候选整条藏起来，这里可以把它们放回去。

## 智能联想

**设置 → 智能联想**：

- 上屏后给出下一个可能要打的词。自带基础联想，下载模型可以联想得更准。

## 扩展：方案、模型、插件

**设置 → 扩展**，分方案、模型、插件三栏，右上角看已安装的。

- **方案**：下载其他输入方案。要导入自己的 Rime 方案，点右上角「已安装 → 导入方案」，选择方案压缩包（`.zip`、`.tar.gz`）、`.schema.yaml` 或 `.dict.yaml`。按页面提示应用方案更改。
  如果提示缺文件，按列出的名字补齐词库或配套方案，保留包内原有子目录。若提示文件名不符，用方案里 `schema_id` 的值命名，例如 `schema_id: sample` 对应 `sample.schema.yaml`。
  - 虎码官方码表的下载包是 `.7z`。解开后选 `publish/rime`，把要用的方案和配套词典压成 ZIP。单字版的方案 ID 是 `tiger`，小词库版是 `tigress`。[虎码官方下载目录](https://huma.ysepan.com/#/)
  - 万象全拼基础版可直接选择官方 `rime-wanxiang-base.zip`。配套语法模型 `wanxiang-lts-zh-hans.gram` 由上游单独提供，也可从文件导入。两者就位后应用方案更改，选择 `wanxiang`。[万象发布页](https://github.com/amzxyz/rime-wanxiang/releases) · [官方安装说明](https://amzxyz.github.io/rime-wanxiang/doc/trime.html)
- **模型**：语音、手写、联想、九键词组、声纹等模型。下载线路会按所在地区自动选，下载后核对文件，失败自动换一条。也可以「从本机导入」模型文件、压缩包或文件夹。
- **插件**：点「获取」看插件说明并安装。工具类插件装好就启用，按钮放在键盘菜单里（可在「排列」里挪到工具栏）；接口地址、模型和 API 密钥在「已安装」› 设置里填，面板里的「设置」也能直接进去。插件管理页也可以从文件安装 `.xipk`。
  - **AI 改写**：选中一段字（不选就是整个输入框），点 AI 改写，选润色、改错字、更正式、更口语、缩短或翻译，点结果替换原文。
  - **AI 回复**：先复制对方的消息，再点 AI 回复，点一条回复发到输入框。
- 市场打开时先显示随包目录，随后从配置的镜像刷新。随包插件可以离线安装，AI 服务在实际使用时需要联网。打字统计在设置首页，不再是插件。

### 五笔拼音四码自动上屏

内置「五笔拼音」默认手动选字。想在输入四个五笔字母、整个候选菜单只有一项时自动上屏，可将下面两项合并到 `wubi86_pinyin.custom.yaml` 的 `patch` 下，然后在「已安装的方案」点「应用方案更改」。已有其他补丁时保留它们。

```yaml
patch:
  "speller/auto_select": true
  "speller/auto_select_pattern": "^[a-y]{4}$"
```

例如 `aaad` 自动上屏「工期」，`aaaa` 有多个候选，仍可手选。这条规则看整个混输候选栏，四码时唯一候选若来自拼音反查，也会自动上屏。不要给混输方案设置四码长度上限，否则会影响长拼音。

## 和电脑同步剪贴板

配合 Windows 上的 [CyIME Windows](https://github.com/Cyletix/CyIME-Windows)：

1. 手机和电脑连同一个 Wi-Fi。
2. **设置 → 剪贴板与同步**，在附近的电脑里点选你的电脑，核对两边显示的连接码一致后确认；也可以扫电脑上的二维码。
3. 之后两边复制的文字自动同步，图片暂不同步。记住的电脑可用时会自动重连。

同步只在你们自己的网络里直接传，不经过别的服务器。

## 物理键盘

接上实体或蓝牙键盘后，屏幕上换成一条小的输入工具条和候选浮条。

- **Ctrl + 空格**按顺序切换语言；单独轻按 **Shift** 在当前语言和英文间切换。
- **Ctrl + .** 切换中英文标点，**Alt + V** 打开剪贴板，**Alt + H** 开关语音。
- 候选翻页键可以多选：`-` `=`、`[` `]`、`,` `.`。
- 候选浮条可以跟随光标、自动避开输入区域、贴边停靠，在 **设置 → 物理键盘** 里调。

## 备份、性能和存储

- **备份与恢复**：把设置、工具栏排列、主题、布局和尺寸、自定义布局导出成一个 zip 文件，可选是否带上你的词库和学习数据。不包括插件、下载的模型、分类词库和剪贴板。备份只存到你选的位置。
- **性能与省电**：高配、中配、低配三档，默认按手机配置自动选；区别在按键动效和语音模型占多久内存。
- **关于 CyIME → 存储空间**：看各类数据占了多少，缓存、日志、模型、剪贴板等可以单独清理。
- **关于 CyIME → 日志查看器**：出问题时看警告和错误日志，可以保存或分享给开发者。

问题和建议请到 [GitHub Issues](https://github.com/Cyletix/CyIME/issues)。
