# CyIME 使用说明

适用版本：**1.2.9 正式版**（2026-09-29）。本文按这个版本的菜单、设置和输入行为编写；上游 Xime 的截图、菜单位置及版本号不一定适用于 CyIME。版本更新后，以本文标明的适用版本为准。

## 安装与启用

1. 从 [CyIME Releases](https://github.com/Cyletix/CyIME/releases) 下载 APK。多数手机、平板选择 `arm64-v8a`；不确定架构时选择 `universal`。系统要求 Android 9.0 或更新版本。
2. 安装并打开 **CyIME**，点击 **启用输入法**，在系统列表中打开 CyIME。
3. 返回应用，点击 **选择输入法**，选择 CyIME。
4. 等待首次词库初始化完成。在设置首页的“点击此处开始输入测试...”区域试打，再到日常应用中使用。

升级同一安装身份、同一签名的 CyIME 时，直接安装新版即可保留数据。**不要为升级先卸载。** CyIME 与上游 Xime 是不同应用；从上游切换过来不会自动继承其设置和学习记录。

## 键盘与输入模式

键盘上方有候选区域和工具栏。默认工具栏包含 **输入模式、表情、编辑、剪贴板、手写、语音**；已经定制过工具栏的用户会保留自己的选择和顺序。

- **打开菜单**：点击键盘上方的 CyIME 图标。菜单内有“键盘调节”“定制工具栏”“设置”和主题切换；“全角／半角”“输入选项”是否出现取决于当前语言及方案。
- **切换语言**：点击键盘语言键切换英文与原语言；长按语言键选择中文、日语或英文。它与切换系统输入法是两件事。
- **切换同一语言的输入方式**：点击工具栏 **输入模式**。中文可选择已启用的“中文26键”“中文九键”“中文14键”、双拼或自定义布局；日语显示对应的日语方案。
- **数字与符号**：点击 `123` 打开数字页，点击 `!@#` 打开符号页。当前页相应位置会变成返回文字键盘的按钮。
- **找不到某个输入模式**：到 **设置 → 输入方案 → 已安装** 查看是否启用；较少用的方案可能在“其他已安装方案（高级）”中。更改启用列表后点击 **应用方案更改**，等处理完成。
- **恢复隐藏的工具按钮**：菜单 → **定制工具栏**，选择需要的按钮并调整顺序。快捷发送也可从剪贴板面板的标签页进入。

中文默认词库随应用提供，不需要先下载语音、手写或联想模型才能打字。

## 输入与编辑

### 候选与九键选词

输入拼音或方案编码后，点击候选词上屏。点击候选栏右侧的展开按钮查看更多候选，再点返回按钮回到键盘；展开区域可滚动。

九键左侧用于选择拼音，右侧用于选字词。一个候选可能只覆盖输入串的前一段：选择后，已选部分保留在预编辑中，继续选择剩余部分才完成上屏。撤销尚未上屏的选择与“删除用户词条”是不同操作。

候选长按后的“删除”确认用于移除候选对应的学习词条，**不是撤销刚才选词**。是否支持删除取决于候选来源和输入方案。

### 空格、回车与退格

| 操作 | 用途与当前边界 |
|---|---|
| 空格 | 有组合输入时用于选词；空闲时输入空格。若打开“空格上屏联想候选”，中文空闲状态有联想词时可提交首个联想。1.2.9 快速连打仍有状态不同步问题，见文末。 |
| 回车 | 有未完成输入时处理当前输入；空闲时按输入框要求执行换行、发送、搜索、下一项或完成。日语按其方案处理。1.2.9 快速“字母 → 回车”存在已知问题。 |
| 退格单击 | 有组合输入时撤销编码或部分选择；空闲时删除输入框中的选区或光标前内容。 |
| 退格长按 | 连续删除，松手停止重复。 |
| 中文26键退格左滑 | 取消当前组合输入。自定义手势配置可能改变行为。 |
| 中文26键退格上滑 | 有组合时清理当前输入；无组合时，1.2.9 实际只清光标前文字，不能当作可靠的“全文清空”。 |
| 中文26键退格下滑 | 请求撤回上次清空；当前版本不应在移动光标或修改正文后用它恢复原位置。 |

1.2.9 普通文字键盘在无组合、但仍显示联想或近期剪贴板候选时，首次退格会先清候选，随后再删正文；这可能表现为第一次退格没有删字。

候选交付被输入框拒绝时，键盘可显示待处理文字的 **重试／取消**。重试针对原输入会话；切换到另一个输入框后，不会把这份旧文字自动补到新输入框。这项恢复目前没有覆盖所有符号、回车和切换模式的提交路径。

### 编辑面板

工具栏 → **编辑**，可使用方向键、选择、段首／段尾以及剪切、复制、粘贴、全选。复制、剪切等作用于输入框当前选区；能否执行还取决于输入框是否支持对应操作。

1.2.9 的上下移动按文本中的换行计算，不能准确跟随屏幕上的自动折行。快速扩选后立即剪切等连续动作也存在顺序问题。处理长段落或重要选区时，暂用宿主应用的光标手柄和原生选择菜单；这属于当前版本缺陷，不是新的操作规则。

## 剪贴板与拆词

1. 点击工具栏 **剪贴板**。点一条记录可输入其内容。
2. 长按记录打开操作菜单，可选择 **拆词、快捷、多选、删除** 等操作。
3. 进入 **拆词** 后，点选或划选需要的词块。选词只修改面板中的选择，**不会逐词上屏**。选中的词块按原文顺序拼接，不按点击先后排序；点击已选词块可取消选择。
4. 点击右上角 **确定**，将选中的内容一次输入当前输入框；返回则不提交。
5. 顶栏 **添加到快捷发送** 用于收藏组合内容，不等同于向输入框发送。
6. 在 **快捷发送** 标签页中使用收藏；可添加、编辑、置顶或删除条目。

“自定义短语”通过编码触发，“快捷发送”通过面板点选，二者的入口和用途不同。

当前版本收到新的剪贴板记录时仍可能打断正在编辑的拼音组合；使用剪贴板同步时也可能触发。详见[已知限制与反馈](#已知限制与反馈)。

## 布局与外观

### 调整键盘大小、位置与形态

1. 点击 CyIME 图标 → **键盘调节**。
2. 拖动边框调节尺寸；拖动移动区域改变位置。固定键盘也可以调节宽度和水平位置。
3. 使用 **悬浮／固定** 切换放置方式；支持的文字键盘可切换 **分体／完整**。按钮显示的是可切换到的形态。
4. 调整透明度或底部留白，点勾号 **确认** 保存；使用系统返回键或返回手势取消，恢复进入调节前的状态。
5. 需要重新开始时使用重置按钮。横屏、竖屏应分别检查布局效果。

“悬浮模式”已归入键盘调节；不用在菜单中寻找上游截图里的独立悬浮入口。

### 自定义按键排列

**设置 → 自定义布局 → 新建布局**。这里基于中文26键编辑：

- 长按按键约 0.3 秒，拖到另一个按键上交换位置。
- 选中一个单键，可点 **合并右侧**；选中合并键可 **拆分**。
- 可设置独立分号键、元音强调和改位字母强调。
- 保存后，从中文 **输入模式** 列表选择该布局。删除布局只移除该布局，不删除词库和学习记录。

### 主题、手势与候选显示

- **设置 → 主题与定制**：外观和配色；键盘菜单也提供浅色、深色、跟随系统切换。
- **设置 → 按键效果**：按键音和振动。
- **设置 → 布局与显示**：候选字号、注释、预编辑显示位置、每页候选数、候选栏取消按钮、按键手势及数字输入框适配。每页候选数更改后，到 **输入方案 → 应用方案更改** 生效。

不要把“只看单字”理解为删除词库中的词组；它只是候选显示筛选。1.2.9 对部分扩展区汉字的筛选仍不一致。

## 词库与升级

### 管理词库与短语

进入 **设置 → 词库管理**，先在右上角选择方案，再选择标签页：

| 标签页 | 可以做什么 |
|---|---|
| 自定义短语 | 添加、修改、删除短语，设置编码和可选权重。 |
| 个人词库 | 查看、搜索当前方案的个人词条；这个页面目前只读。 |
| 方案词库 | 浏览方案词典内容。 |

升级会检查随应用提供的中文、日语词库和方案资源。需要替换的内置文件会先保存备份；用户词频数据、个人词库、自定义短语及 `.custom.yaml` 补丁保留。自定义配置优先放在补丁或个人词库中，直接改内置同名文件可能被后续版本更新。

内置资源的升级备份保存在应用私有数据中，**不等于已导出到手机公共文件夹或云端**；卸载应用可能一并删除。

### 导入其他输入方案

**设置 → 输入方案 → 右上角菜单**，可选择：

- **方案市场**：查看可安装方案。
- **从文件选择**：选择已下载的方案包。
- **网络导入**：填写压缩包下载地址。
- **浏览器导入**：按手机页面给出的地址，在同一局域网的电脑浏览器中上传文件。
- **文件管理器**：查看应用内的 Rime 文件。

导入完成后，在 **已下载/导入** 中确认安装状态，再到 **已安装** 启用需要的方案，点击 **应用方案更改**。这与在键盘上切换已经启用的输入模式不同，不必为每次日常切换重新部署。

## 语音手写与联想

### 语音

1. **设置 → 语音转文本**，打开总开关，进入页面选择本地识别或在线服务。
2. 本地识别：下载所需模型并选用。下载完成后，识别过程可离线运行。
3. 在线识别：先安装对应语音插件，再选择服务并填写它要求的连接配置；在线服务需要网络。
4. 返回键盘，点击工具栏 **语音**，按提示授予麦克风权限。
5. “保持引擎常驻”影响模型是否在语音结束后保留在内存中，不表示持续录音。

### 手写

点击工具栏 **手写**；缺少模型时按页面提示下载。写字后点击识别候选确认；可在手写区域切换普通或全屏模式。手写识别模型与拼音词库是不同资源。

### 智能联想

**设置 → 智能联想**。基础联想和个人学习与可选模型增强分开管理；可选择是否让空格提交首个联想，以及提交后是否继续联想。关闭智能联想后仍可使用输入方案的词库候选。

**设置 → 模型管理** 用于查看和删除已下载的语音、手写、联想模型；选择识别方式或联想模型仍到对应功能页面。下载入口也可从 **扩展商店 → 模型** 进入。模型清单随 CyIME 提供，下载连接到各模型的发布地址，具体许可见模型说明。

## 插件与备份

- **扩展商店 → 插件**：寻找并安装插件。
- **插件管理**：启用、停用、配置或卸载已安装插件，也可导入 `.xipk` 文件。某些插件还需要单独填写账号、服务地址或密钥。
- **云备份**：通过备份插件保存与恢复配置；先安装、配置并启用相应插件，再执行备份。是否成功以页面结果为准。
- **剪贴板同步**：通过同步插件配置远端服务。它不是云备份，也不是默认自动开启的功能。

主应用升级不会自动把已经安装的独立插件替换成源码仓库里的新版。1.2.9 的新打字统计协议需要配套 **typing-stats 0.3.1**；旧插件应另行更新。不要把仓库中已有新版代码当作手机上已经升级。

## 已知限制与反馈

1.2.9 的基础编辑尚未全部验收。已从发布源码确认的缺口包括：快速输入后回车／空格读到旧状态、九键部分选词后切数字页丢失前段、剪贴板刷新打断组合、部分提交失败缺少恢复，以及编辑面板的顺序与光标语义问题。**暂时先完成候选选词，再切换数字页；重要文本的选择、剪切和清空优先使用宿主编辑器。**

这些是待修缺陷，不是要求用户适应的正常行为。细节、触发条件和验证边界见 [1.2.9 正式版复核](development/1.2.9-release-re-audit.md)。

反馈时请提供：CyIME 版本、手机或平板型号、宿主应用、输入模式、输入框原有文字和光标位置，以及实际按键顺序。用无隐私的短句复现最有帮助。能在设置首页测试框复现，也请注明。
