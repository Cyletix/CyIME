# 1.1.6 Debug：首装输入积压与手写整串候选

## 已实施

- [x] 原生 initialize 完成不再等同于输入就绪。资源、部署、session、方案和选项恢复完成后才开放输入；失败和超时不能绕过这个条件。
- [x] Application 和输入法服务共享复制资源、初始化、部署的整段互斥流程，成功后本进程复用，避免复制与编译交错。
- [x] 首次方案加载和选项恢复在 IO 线程执行，等待界面提供“切换输入法”和“收起”。首次部署仍需等待；没有宣称编译时间归零或提前开放未部署的中文方案。
- [x] 普通键、九键、字面输入在入队前校验；部署使旧队列票据失效。重复退格和退格回调也校验票据，不能在部署后补删正文。
- [x] Android 延迟送达的触摸按原始 downTime 判断；就绪前的旧手势整段消费，不把迟到的 UP 当成新按键。
- [x] 手写去掉“第 1/N 字”逐字确认，候选覆盖全部未确认字符，点击一次提交整串。按识别置信度组合，保留最多 20 个候选，避免组合爆炸。
- [x] 取消清除未确认书写；退格先回退最后一个未确认字；选词后清理本轮笔迹和迟到识别。
