# 词组模型补聊天口语重训（LCCC-large，2026-10-18）

任务来源：四款输入法实机对比（`docs/development/pinyin26-word-model-20261018.md` 末尾）显示 CyIME 与搜狗的差距多在词组模型：他/她、么/吗、玩会/晚会、聊天短语首字母直出。训练语料偏字幕和微博，缺聊天口语。用户 10-18 授权“做你觉得正确的事”。

## 结论

- 换语料本身没有带来可测的提升：加权总分 68.4 → 68.3（±0.6），首字母、整句都在噪声范围内；对比题 full26 +4、jp26 −3。能确定的只有体积 213 → 190 MB（加载内存约少 20 MB）和“同质量更小”。
- 之前“首字母明显变好”的结论错了，那是 14:04 接入的聊天词频（另一线程）带来的；以后对比先核对两边 `work*/android/cn_dicts/base.dict.yaml` 一致，再用 `rank_score.py compare` 报加权分。
- 九键（10-18 15:55 JST 补测，win2 引擎 t9_pinyin、同一词典 5a12222d、四款对比的 150 道九键题）：整句首选 v3 100/150 → 候选 105/150（+6/−1），加权 66.7 → 70.0；逐键耗时中位 18.8 → 19.1 ms。九键固定两集（tune/dev）待主机回放排期。结果已登记评估总表（pc9-v3-cmp / pc9-v8-cmp）。
- 建议：默认模型暂不换；候选保留（`D:\CyIME-Data\models	9_ngram-model-v8-lsl-p2e-8.c3.lm`）作“同效果小 23 MB”的备选，等九键回归一起定。他/她、么/吗、玩会/晚会这类差距不是换语料能解决的：同音歧义要靠上文和个人学习，词频类要靠词典词频（已由聊天词频接入）。
- 个人层：用户设备上的 ×4 版若重建，应对个人语料也套用评估句剔除名单（p4 在自建日常集上的优势可能来自用户聊天里出现过测试句）。
