# 物理键盘、调节界面与主题精简（2026-10-11 晚）

以下改动已能编译、相关单元测试通过；模拟器截图核对另行补记。都没有在平板或手机上核对。

## 物理键盘

- **自动收起屏幕键盘**：接着实体键盘后点开过屏幕键盘，再用实体键盘打字（非空格的字符键）时自动收回工具条，不再挡住屏幕（`onKeyDown`，`collapseScreenKeyboardToHardwareToolbar`）。
- **方向键与 Esc**：正在打拼音时，左右键像屏幕键盘一样在拼音里移动光标位置（把 XK_Left / XK_Right 交给 Rime），不上屏、候选不消失；九键编码暂时只吞掉左右键，不上屏。上下键在候选之间移动、翻页。Esc 的处理顺序：剪贴板菜单开着时先关菜单；正在打拼音时清空拼音；都没有时交给应用。原来没有输入时 Esc 也会被输入法吞掉。
- **底边样式**：吸附、悬浮的行为和位置都不变。新增设置 → 物理键盘 → “底边使用三星式通栏”，默认关闭。开启后，吸附到底边时，工具条贴住屏幕最下方，左右通栏、直角；左边是收起按钮，中间是九个带 1–9 编号的候选，右边是展开屏幕键盘和语言键。
- **不挡输入框**：工具条贴在屏幕底边时，它占用的高度会报告给系统，应用会把自己的输入框让到它上方（`onComputeInsets` 的 compact 分支）。
- **悬浮候选展开**：悬浮候选卡片右侧加了展开按钮，像 Gboard 一样把当前页候选展开成每行 5 个的多行网格，每个都带数字编号，可以点选。
- **圆按钮**：只在按下或开启时显示圆底；触摸区域不变，图标 20dp，圆底 36dp，四周留出边距。新增麦克风按钮，复用实体键盘的麦克风快捷键逻辑。

## 剪贴板的实体键盘快捷键

剪贴板打开、处于键盘导航状态时：空格打开当前记录的菜单；方向键在菜单内上下移动，并高亮当前项；回车执行；Delete 键弹出删除确认（同样用方向键和回车操作）；Esc 先关菜单或确认，再按一次才关剪贴板。Android 会先把按键交给输入法，输入法只在剪贴板处于键盘导航状态时消费 Esc，其余情况 Esc 照常交给应用。`ClipboardKeyboardNavigationTest` 新增“第一次 Esc 只关菜单”的测试。

## 调节界面

- 面板、按钮和透明度滑条改用键盘配色（键帽色、文字色、强调色），不再用黑色的 Material 表面色。
- 分体中缝拖动：拖到上下限之后多拖的距离不再累计，往回拖时边框立即跟着动。
- 吸附范围随键盘宽度放大：手机 6dp，平板最大 16dp，中缝吸附和按键正方形吸附都按这个范围。
- 大屏比例和“没有厚度”这两点还没有用截图核对。

## 主题精简

主题列表只保留 iOS 渐变、黑白、薰衣草紫、柔和蓝四个（`OFFERED_THEMES`）。跟随系统动态配色等其他主题不再出现在列表里，代码保留。之前选了动态配色的，自动改为柔和蓝。用户截图中设置页和键盘配色不一致（淡蓝紫与青蓝），是动态配色主题造成的。
