# 雾凇扩展词库补语料词频（2026-10-18）

承接 [26 键简拼纠错修复](abbreviation-correction-20261017.md)。用户决定“补上”。

## 问题

雾凇 `cn_dicts/ext.dict.yaml` 339,177 条全部是占位权重 100。同一编码的扩展词同分，先后由排序算法对同分项的任意次序决定（zdky：这都可以 / 真的可以 / 值得夸耀……）。

## 做法

- `tools/ime_lab/ext_weights.py`：用九键词组模型 v3（`D:/CyIME-Data/models/t9_ngram-model-v3-ls-tri.c3.lm`，语料同九键）给每条扩展词打分：按模型词表做最佳切分，再按解码器同样的一元/二元/三元链求 ln P。
- 换算：扩展词整体保持雾凇原档位（中位数 = 100），只按语料把先后拉开：`weight = 100·exp(0.13·(lnP − 中位 lnP))`，结果 1–629（10% 19，90% 247，99% 349）。
- 产物 `app/data/rime_ice_ext_weights.tsv.gz`（词、编码、权重，339,174 条，4.1 MB）。`prepareChineseDictionaries` 解出上游文件后按词＋编码替换 ext 权重；匹配不到 99% 即构建失败（防上游换版本后静默失效）。上游锁定版本与校验不变。
