# 1.1.8 Debug 修正版（20261019）

## 修复范围

- 恢复原先覆盖整个键盘面板的候选展开页，撤回 20261018 中只替换九键中央数字区的设计。保持原来的左侧拼音/筛选、中间候选、右侧操作布局，只调整字体、圆角和最低高度下的按键分配。
- 右侧四键按可用高度等分，144dp 横竖屏中回车仍可见、可点击。
- 保留整面板向下展开/收起动画、横排候选前缀去重和全局选词索引。动画不改变 IME 外部尺寸或调节机制。

## 切换后只剩英文的根因

`RimeConfigHelper.preparedInProcess` 缓存了一次初始化成功，但 `XimeInputMethodService.onDestroy()` 会销毁进程内 Rime 引擎。系统切换输入法会重建 Service，却可能保留应用进程。旧版再次准备引擎时只检查缓存，返回成功，实际上引擎仍未初始化，中文方案无法加载，模式列表只剩总是附加的英文。

- 缓存现在必须同时满足原生引擎已初始化、会话实际可用；否则重新初始化。
- 部署成功必须同时检查编译文件、有效会话、全部已启用方案以及当前方案，不能只凭文件/hash 宣称完成。
- 设置与键盘重新部署统一走初始化、部署、验证流程。成功后发布刷新标记，当前 IME 重新恢复方案与输入状态；失败明确保留错误状态。
- 初始化重入被同一任务保护，旧超时监测不会误报后来的恢复任务。
