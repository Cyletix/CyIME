# 1.2.9：手动编辑后语音增量恢复

工具栏持续语音使用 `StreamingVoiceText` 直接上屏。手动移动光标、删除或选区操作后，它冻结已经展示的 ASR 前缀，避免覆盖用户编辑。旧实现遇到 ASR 改写该前缀时始终产生空增量；只要后续结果不再包含旧前缀，就持续无法上屏，且可能删掉此前仍由语音管理的尾部。

现在遇到无法可靠划分的前缀修订时，保留编辑器现状，把本次识别结果作为新增量起点，并交还旧尾部的所有权。后续扩展结果可以继续插入当前光标位置。此策略不猜测旧文修订与新增语音的边界；发生重新定位的那次结果不会写入，因此仍可能遗漏该次结果中新说的文字。这是恢复持续输入的保守修复，不是逐词时间戳对齐。
