# 手写与26键间距对齐（2026-10-06）

## 本轮目标与实现

以用户本轮两张截图为准：横向沿用26键底排全部分界，符号、数字入口左右边界重合；高度保留手写五等分，键缝沿用26键，不随高度膨胀。此前文档中的回退草稿和四等分尝试均不是本轮规格。

- 手写使用26键的内容边距、底部8dp内缩、间距设置及宽度增长规则，悬浮与显式宽度采用同一策略。五等分用于实际手写行高，间距以26键四行参考计算，从而保持跨面板键缝一致。
- 底排使用共享 `QwertyBottomRowWeights.Standard`：符号、数字、全屏、空格、语言、回车。全屏按钮占原逗号格，其余对应控件位置不动；右侧四键与回车同宽、同边界。
- 符号／数字改用相同的16sp共享按键，跟随共通字号、字重、按下反馈；图标与标点也使用共享按键及间距。保留删除长按／上滑清空、五行高度、手写识别和工具栏。
- 全屏只扩展画布，沿用普通手写的按钮高度、间距、内容缩放和实际左右边距。

本轮仅修改手写实现及相关既有检查，没有改变26／14／九键、数字、符号或展开候选的实现，也没有运行已暂停的整套尺寸门禁。
