# 自动交付入口修正

`auto.cmd` 继续调用 `scripts/auto-deliver.py`。预检从源码读取版本，查找已安装的 Java 21 和 Android SDK，并向构建子进程传递路径；不要求每次手动填写版本。未初始化子模块使用本次命令范围内的 GitHub HTTPS 地址，不依赖 SSH 主机信任、不改全局 Git 配置。ARM64 正式版参数和当前 Python 路径显式传入现有构建脚本。
