# 字幕模式第一版（2026-10-16）

给听力不好的人看周围人说话：键盘菜单“字幕”按钮 → 整屏字幕页，每个说话人一行、新话从右边流入，自动分声音、点名字改名。设计依据见项目库里的《字幕模式设计 v3》（核实 + 审查后的版本）。本文记录实际做了什么、怎么验证、还缺什么。

## 做了什么

**:asr 进程（复用常驻引擎）**
- `speech/caption/CaptionSpeechSession.kt`：和 `LocalSpeechSession` 并列的会话，复用 `SherpaSpeechEngine` + `SpeechSegmenter`，按句发事件（id、文字、起止毫秒、边界、是否定稿、事件标签），停顿下限 400 ms（键盘路径流式为 1000 ms，不改）。某句二次识别超时（8 s）或队列满（4）只影响那一句（保留预览文字），会话不停。段 PCM 裁掉 VAD 前置缓冲后交给声纹线程 `CyIME-Speaker`（单线程、队列 4，满了丢最旧并标“可能是”）。
- `speech/caption/SpeakerLabeler.kt`：按句余弦比对 + 增量质心聚类。有效语音 < 1 s 继承上一人且不自信；1～2 s 只标不学；≥ 2 s 学习（每人最多 20 条声纹，均值方向）。起过名字的人优先匹配（差距 ≥ 0.05）；标为“电视”的声音吸收相似新声音；上限 6 人。阈值 宽松/标准/严格 = 0.40/0.45/0.50（公开示例 0.31～0.6，**未按家庭录音校准**）。合并、单句改派（改派会把误分的空声音删掉）、重置。
- `speech/caption/CaptionText.kt`：字幕文本保留标点，只去 `<|…|>` 标签、nospeech 和 SenseVoice 的中文 token 空格。
- `SherpaSpeechEngine.refineRich` / `LocalSpeechEngine.refineRich`：第二遍识别返回原始 text/lang/event（键盘路径仍走 `refine`，行为不变）。
- `ResidentSpeechSessionOwner` 的会话类型改成接口 `ResidentSession`（`LocalSpeechSession` 实现它，现有调用与测试不变）。
- `AsrInferenceService`：按 intent action 返回第二个 binder（`ICaptionService` / `ICaptionCallback`）；字幕会话活跃时键盘 `startAsr` 直接返回“字幕模式使用中”；声纹模型 `SpeakerEmbeddingExtractor` 由服务持有，空闲释放时一并释放；说话人聚类状态在服务里跨暂停保留，用户退出时清空。

**主进程**
- `service/CaptionInferenceClient.kt`、`speech/caption/CaptionRecorder.kt`（VOICE_RECOGNITION / 16 kHz / 100 ms 块，振幅回调）、`speech/caption/CaptionTranscript.kt`（ASRInput 的“定稿后拒收迟到结果”状态机）。
- `ui/caption/CaptionActivity.kt`（全屏、隐藏系统栏、常亮、转屏不重建、退到后台自动暂停并释放麦克风、回来自动继续）、`CaptionController.kt`（状态与动作）、`CaptionScreen.kt`（界面）。
- 界面：顶部 字大小（24/32/44 sp 三档）/ 换颜色（浅色黑字米白底、深色米白字深灰底）/ 暂停 / 退出（二次确认）；状态灯 + 音量条 + “麦克风被关了”提示（15 s 无声）；每个说话人一行，左侧名字按钮（颜色点 + 名字，Okabe-Ito 色盲安全色），右侧按时间从左到右的气泡，最新在右边、自动跟随，用户往左翻时出现“回到最新”；底部“正在说”预览条；“我来回话”页（上半屏翻转大字给对方读、下半屏输入框可用 CyIME 手写键盘、常用句）；“请再说一遍”整屏翻转显示。
- 点名字：这是我 / 儿子 / 女儿 / 老伴 / 孙子 / 孙女 / 医生 / 邻居 / 输入名字 / 这是电视（折叠）；点已有名字 = 合并；长按气泡 = 这句改派。
- 模型目录：新分类 `ModelCategory.SPEAKER`，条目 `speaker-campplus-zh`（3D-Speaker CAM++ zh-cn 16k-common，28,281,138 字节，SHA256 `f682b514…fd11`，GitHub Release 直链，无镜像），放在 `BuiltinModelCatalog`（不进 `SpeechModelCatalog`；`AsrModelManager.getAsrModels` 加分类过滤）。字幕页没有模型时显示下载条；下载完成自动重启会话接上声纹。
- 入口：`ToolbarButton.CAPTION`（默认菜单含它；已保存过菜单的用户由 `SettingsPreferences.insertMenuItemOnce` 插入一次）。
- 隐私：`backup_rules.xml` / `data_extraction_rules.xml` 排除 `speaker`、`caption`、`caption_tuning`（本版尚未写这些目录，先把规则放好）；`NOTICE.txt` 补 sherpa-onnx、Silero VAD、Paraformer、SenseVoice、Zipformer、CAM++。
- 版本由打包器 `--bump minor` 升。

## 没做（下一版）
- 声纹和改过名的人不持久化：关掉 :asr 进程（退出字幕或系统回收）后编号重排。
- 没有登记家人、没有阈值自校准、没有撤销（合并/标电视不可撤）、没有“只看家里人”开关、没有 3 天记录保存、没有息屏继续（前台服务）、没有 TTS 朗读、没有字幕调优录音开关。
- “几个人一起说”没有检测，只会标错人或“可能是”。
- 回话页用的是系统键盘（CyIME 自己的手写布局），没有单独的大手写板和 2 s 切字参数。

## 1.13.17 / 20261181（2026-10-16 15:00 JST，已出包，手机断开未安装）
- 用户反馈：两人中间不停顿时被切进同一句，第二个人的第一句仍归到第一个人。
