# 自定义布局强调开关

## 修复

- 原先改位/合并按键底色无条件强调；现在底色及文字都由元音、改位两个开关的并集控制，普通按键不受影响。
- 强调文字与普通字色太接近时，从主题色派生搭配色并校正对比度，避免主题本身使用强调色作字色时无法区分。预览与实际按键复用同一计算，包括合并按键的逐字强调。
- 布局缓存改为 Compose 可观察状态；保存当前方案的颜色选项，即使 ID、按键排列不变，消费者也能收到新布局。
- 编辑页说明改为与实际行为一致。一个字母同时属于元音和改位字母时，任一对应开关开启都会强调。

## 验证

`CustomLayoutEmphasisTest` 在模拟器通过 2 项：各主题深浅模式下四种开关组合及可读性；真实 SwipeableKeyButton 同 ID 下开启/关闭后的像素变化及恢复。日志：`.codex-artifacts/custom-emphasis-device-tests.log`。
