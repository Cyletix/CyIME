# 26 键基础词频加入聊天口语（2026-10-18）

对比线程发现：按出现次数算，大半简拼错题是雾凇 base 词频偏书面语（hx 出“核心”不出“好像”、bg“报告”不出“不过”）。这是之前定下的“口语语料基础词频”一步，不依赖词组模型。

## 做法

- `tools/ime_lab/chat_word_counts.py`：读 LCCC large（MIT，九键线程下载的 `D:/CyIME-Data/corpus/win/lccc-large.txt`）前 800 万行，按雾凇 base + 8105 字的词频做一元最佳切分，统计每个词出现次数。只出计数，不保存或打印任何原句。结果 2,759 万词次、17.9 万个词（`D:/CyIME-Data/lexical-weights/lccc-20261018/counts-8m.tsv`）。
- `tools/ime_lab/chat_base_weights.py`：每个 base 词条新权重 = 原权重^(1−β) × 聊天计数^β（聊天计数换算到 base 总量尺度，多音词按原权重比例分摊，没出现的取 1）。β=0.5。
- 产物 `app/data/rime_ice_base_weights.tsv.gz`（6 MB），`prepareChineseDictionaries` 按词＋编码替换 base 权重，与扩展词频同一机制；匹配不到 99% 即构建失败。表要从上游原始 base 生成（不能拿已改过的再算）。

Windows 端用的是万象词库，这次不跟着改。

## 改用 β=0.3（1.14.16 起）

用户把主指标改为排名加权分（前 4 位 1/0.5/0.25/0.125，`tools/ime_lab/rank_score.py`）。自建集合计（原算法）：现状 75.6，β=0.3 **79.8**，β=0.5 77.9，β=0.7 72.6。β=0.3 的优势主要来自 base 书面词首字母组（84.2 对 74.2）；口语组 β=0.5 略好（语料常用语首字母 92.0 对 90.5，日常短句首字母 37.8 对 36.1，聊天首字母持平）。按统一口径取合计最高的 0.3：书面词少退步，口语收益保留大部分。1.14.15 按 0.5 打包，下一包换 0.3。

### 改用混合计数（2026-10-19）

只用 LCCC 计数时同音近义词经常打平（通话／童话 85866 对 85726，等于抛硬币），所以把聊天计数和 v3 词组模型的一元计数按几何平均混合：混合计数 = LCCC^0.75 × 模型^0.25（`tools/ime_lab/mix_chat_counts.py`），再照旧按 β=0.5 和 base 原权重混合。比例在调参样本上选：γ=0.25 口语各组不变（SMS 首字母 19.2→19.3、LCCC 首字母 18.2→17.9、整句 ±0.2），γ=0.4 口语组开始下降。
