# 1.3.14：全模型内置包与简化设置

普通版保留；`full` 安装包内置当前清单的六个模型（约 708 MB 原始资源）：手写、联想 small/base、Zipformer、Paraformer、SenseVoice。两版包名和签名一致，可覆盖安装，数据保留。内置包不依赖用户联网下载模型；首启后台校验并安装到既有模型目录，完整安装才对外声明可用。

首次使用内置版自动打开智能联想、本地语音，默认轻量联想 + 中文流式语音/SenseVoice 校正。互斥模型不同时启用，麦克风只在用户主动语音输入时使用；后续用户关闭功能或删除模型的选择保留。系统启用输入法、选择输入法、录音授权仍由 Android 管理。

新用户只开启中文。中文26键、九键自动部署，两版均不自动创建双拇指实验布局；老用户保存的自定义布局不删除。设置 → 语言管理可开启英文/日语。日语开启后自动部署，关闭保留词库文件。

词库部署共享串行入口，失败按 3/10/30/60 秒间隔重试，取消任务不会重试；输入门禁持续关闭，准备期间按键不排队。原生调用尚未返回时不并发再次部署。引导仅保留系统启用和选择输入法，部署无需手动确认。

手写笔迹按画布背景选择对比度足够的实色，不再直接沿用可能为白色的键帽文字颜色。

## 构建

- 两个版本：`scripts/build-distribution.ps1 -BuildType Debug -AdbPort 5038 -Serial emulator-5554`
- 仅内置版：`scripts/build-apk.ps1 -BuildType Debug -BundleModels -AdbPort 5038 -Serial emulator-5554`
- Python 路径可经 Gradle 参数 `-PpythonExecutable=...` 指定。首次构建联网取模型，按目录中的固定 SHA256 校验；缓存位于 `.gradle/bundled-model-cache`，后续复用。
- 验收通过的两版分别保留于 `app/build/outputs/apk/editions/<版本>/standard|full/debug|release`。
- Release 工作流构建、验证并上传普通与 full 两套包。本轮不自动发布 Release。

测试包括模型完整性/首次启用/不覆盖后续用户选择、无实验布局的新用户状态、语言菜单与大字体尺寸、白底实际笔迹像素、部署失败重试与取消传播，以及既有键盘尺寸门禁。测试通过与真机验收分开记录。
