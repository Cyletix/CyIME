# 1.3.16 图形工作台与分层材质

问题原因：旧 MaterialPaint 在所有控件上叠加外描边、缩小的内描边以及两层静态辉光，设置卡片和普通键共用相同光学模型。旧参考 PNG 还保留了深色圆角底板，移除外围黑色并不等于移除了图标外框。

本次将图形来源放到 `tools/visual-lab/design.json`。浏览器左侧编辑 JSON 或 SVG，右侧即时预览、错误保留上次有效画面、导出 SVG／PNG；20 个对照样片包含四种样式的图标和明暗键盘／设置卡片。JSON 可直接编译 Android 参数与矢量资源。SVG 自由编辑仅预览与导出，不会执行脚本或写入生产资源。

Android 普通键不再绘制静态辉光和内圈；设置卡片也没有内圈，只有弱边线。候选栏内容为 BASE，空闲工具栏为 FLOATING，功能图标键为 RAISED。底色仍由原主题提供，参数只添加轻微面高光、深度与边线。按压炫光是原先独立功能，没有修改其开关或手势。

桌面、键盘和图标导出共用生成的 VectorDrawable，没有内置背景板或外框；四种样式各自采用同结构色阶。图标几何是可编辑的参考重建，并非原图像素级复刻。浏览器和 Android 使用相同路径和梯度坐标；网页键盘为材质样片，不作为 Android 尺寸验收替身。

新增源一致性、参数字段顺序、禁止普通层内圈／辉光、透明图标无底板检查；设备导出测试检查图标外侧透明及主体非空。现有尺寸门禁继续执行，不改触摸区域、键盘高度或候选流程。

2026-09-30 验证：5 项图形生成器测试、4 项 JVM 材质／主题测试通过；设备门禁登记 22 项，无失败（普通版跳过两项内置模型专属检查）。Chrome 实际验证即时改色、SVG 粘贴、错误输入保留上次画面并禁止编译、PNG 下载、编译资源按钮，390px 窄屏无横向溢出。已查看全部 20 个网页样片及 Android 毛玻璃明暗键盘、透明图标导出截图。
