# 按设备推荐配置（2026-10-30）

用户反馈：安装包太大；语音设置里直接让人选 Paraformer、Zipformer，多数人看不懂。

## 做了什么

- 首次设置向导（启用、准备方案、切换）完成后出现一次「按设备推荐配置」，右上角可「以后再说」。之后从 设置 → 配置选择 → 按设备推荐配置、语音转文本页顶部「不知道怎么选」进入，设置搜索也能找到。
- 页面先列这台手机的情况：内存、核心数、最高主频、处理器型号（Android 12 起 `Build.SOC_*`，更早用 `Build.HARDWARE`）、剩余空间、网络（Wi-Fi／移动数据／未联网）、系统语言。
- 只问三件用法：语音（经常用想边说边看到字／偶尔用说完出字就行／不用语音）、用不用九键、用不用字幕。默认值来自现在的设置（语音开关、中文是否在用流式＋校正、当前布局是不是九键、字幕桌面图标）。
- 按回答和手机情况给出“推荐留下的”（标明已在手机上／从安装包取出／要下载多少）和“可以删掉的”（每项一行开关，默认全开），全部是白话名字和理由，后面附“设置里叫「…」”方便对照。只有点了「按推荐设置」才改设置、删文件。
- 推荐规则（`model/SetupGuidePlan.kt`，纯逻辑，`SetupGuidePlanTest` 12 项）：
  - 性能档沿用 `DeviceModelProfiles.choose`（内存、核心、主频）。
  - 语音默认“说完一句出字”（SenseVoice）；“经常用”且不是入门机型、剩余空间 ≥ 3 GB 时加边说边出字（Paraformer＋SenseVoice 校正）；性能强且剩余 ≥ 6 GB 再加 X-ASR 整句精修。用字幕时也配边说边出字（只说完出字时一整句一下子出现，看的人跟不上）。不用语音会关掉「语音转文本」，字幕要用的模型保留。
  - 智能联想：入门机型或剩余 < 1 GB 用 small，否则 base；联想关着时两个都可删。
  - 九键：手机上已有哪一档就留哪一档；没有时入门机型或空间紧用精简（105 MB），否则完整（203 MB）；九键语法增强在有词组模型后不起作用，可删。不用九键时三者都可删。
  - 字幕：用才留声纹模型。手写模型始终保留（7 MB）。
  - 要下载的放不下（下载后剩余 < 1.5 GB）时依次去掉 X-ASR、边说边出字，九键换精简，联想换 small，并说明原因。
  - 日语已启用且手机上有日语专用模型才保留；SenseVoice 本身能听日语。
- 移动数据下要下载的默认等 Wi-Fi（沿用首次默认模型的等待和重试：`DefaultModelInstaller.requestGuided`），页面有「现在用流量下载」开关。

## 完整版的空间

安装包里的文件由系统管理，应用运行时删不掉。完整版首次启动把内置模型解压到 `files/models/`（九键词组模型放进 `files/rime/`），所以同一个模型手机上占两份：安装包一份、解压一份。向导删的是解压出来的那份：

- `BundledModelInstaller.skip`：被删的内置模型记下来，之后启动和升级都不再解压；正在解压时等它解压完再删。
- 安装包带的九键词组模型被删时关掉它（`CandidateModelAssets.setDisabled`），词库同步不再放回。
- 之后任何地方要这个模型（模型管理点下载、字幕要声纹、语音设置下载），`ModelManager` 先看安装包里有没有同一版本，有就直接从安装包取回、不联网（`BundledModelInstaller.packagedSource`）；取不回才照常下载。

瘦身完整版（不带 Paraformer）新装、性能强的手机、偶尔用语音、不用九键和字幕时，可删联想 small 19 MB、声纹 27 MB、九键词组模型 203 MB，共约 249 MB。

## 检查状态

- `SetupGuidePlanTest`：云端用 Gradle 自带的 Kotlin 2.0.21 编译器单独编译推荐逻辑和测试，12 项全过。
- 其余 Android 代码（读设备信息、整理模型、页面、入口）云端没有 Android SDK，未编译；要在电脑上 `./gradlew test` 和 `assembleDebug`。
- `SetupGuideRenderTest` 出图（设置 `CYIME_RENDER_OUT`）后要看浅色、深色两张。
- 真机未验收。要核对：全新安装完整版走完首次向导后出现本页；按推荐设置后 设置 → 关于 → 存储空间 里模型占用变小；删掉的声纹在字幕里点下载能立即从安装包取回（不联网）；移动数据下要下载的项等 Wi-Fi。
