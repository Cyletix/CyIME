# 候选拼音随可用宽度自动显示（2026-10-04）

## 行为与接线

- 普通候选栏、展开候选中间区域及物理键盘候选行使用同一个宽度策略，按布局测量得到的候选区宽度判断，不用设备类型或整个屏幕宽度代替；平板窄悬浮键盘也按窄区处理。
- 默认候选字号 19 sp、系统字号比例 1 时，可用宽度达到 480 dp 显示拼音/编码注释，低于此宽度隐藏；候选字号或系统字号增大后按实际缩放提高所需宽度，小字号不会将手机窄区判为宽区。横竖屏、分屏及拖动宽度变化后自动重新计算。
- `FixedCandidateStrip` 测量候选宽度和实际渲染使用同一份显示注释，隐藏后候选窗口重新容纳更多词；展开页的行分组也剔除隐藏注释的宽度，而不是只将文字设为透明。
- 展开页用于点击/长按的 `CandidateEntry` 保留原始拼音和全局索引，九键音节栏及输入中的组合拼音不隐藏，候选顺序、引擎内容、编号与选词回调不改。
- 原“编码注释 → 显示/隐藏”改为“候选拼音与编码 → 自动/隐藏”。沿用原布尔存储：默认/原显示为自动，原明确隐藏继续隐藏；偏好变化即时通知候选界面，不重写用户配置。
- 物理键盘浮动与靠底共用 `HardwareCandidateRow → FixedCandidateStrip`，均已接入。无生产调用的旧 `FloatingCandidateBar` 未修改。
