# 26 键默认尺寸按可用空间适配

2026-10-03，已随 1.4.0／20261048 安装平板，旧尺寸覆盖已备份重置，比例和调节手感仍待用户验收。见 [整合交付](glass-integration-delivery.md)。

## 行为

标准 26 键使用一套可用空间公式，不区分手机和平板，也不按横竖屏切换比例规则。空间充足时让普通字母键的可见键帽接近 1:1；窄屏保持便于点击的高度；窗口过宽或高度不足时收窄并居中。按键间隙计入计算，不能只让包含间隙的格子变成正方形。

三排字母使用相同格宽。原窄屏第二排两侧各缩进半格，第三排两侧功能键各占 1.5 格；2026-10-08 标准 QWERTY 的宽屏错位调整见 [物理几何说明](wide-qwerty-physical-geometry-20261008.md)。空格、回车等功能键保留各自宽度。自定义、分体、合并字母键以及九键等布局保留原有默认规则。

已保存的手动宽度或高度继续保留；恢复默认使用新公式。手动越界、渐进阻力、回拉和极端值保护仍沿用现有行为。本次不会迁移或清空旧尺寸，也不修改主题及间隙偏好。

## 计算与接入

`KeyboardDefaultGeometry.kt` 使用实际的 44dp 顶栏、8dp 底部留白及四排按键。正常空间下按键行高不低于 56dp。未获得有效物理显示度量时，可见键帽上限仍为 88dp，默认总高度预算为可用高度的 45%，不足 228dp 时尽量保留 228dp，但不超过窗口。已校准标准 QWERTY 使用下述物理中心距和连续高度预算。以上均是自动默认值，不限制手动调整。显式横纵间距参与方形计算，整数 dp 带来的误差由回归检查控制。

例如可用宽 934dp、高 1493dp 时，当前默认键盘约 934×404dp，普通字母键帽约 79.8×79.75dp；宽 360dp 时默认总高 276dp，保留较高的键帽。横屏、窄窗口和折叠屏仍使用同一公式。手动拉高后的纵缝规则及边界校验见 [2026-10-08 交互与几何核查](interaction-geometry-audit-20261008.md)。

服务主渲染、首帧窗口、模式刷新、进入调节、恢复默认及悬浮停靠共用尺寸计算。进入调节从当前基础键盘尺寸开始，排除展开的剪贴板高度；取消恢复保存尺寸，避免临时预览宽度污染默认值。固定模式使用配置可用高度减底部留白，悬浮模式额外扣除系统栏和拖条。

配置重载及分体开关会触发默认尺寸重算；悬浮偏好重载按实际卡片尺寸限制位置，避免沿用旧百分比高度造成主题刷新时跳动，不写回保存位置。

## 2026-10-08 用户尺寸校准

用户确认以 SM-X800 当前选定的横屏宽度为默认依据，随后明确要求**默认宽度取整为 1000dp**。实际读取的保存值仍是宽 1005dp、高 433dp、横向位置 −244dp，没有改写。读取的逻辑密度为 1.875px/dp、横向物理密度为 266.471dpi；默认宽 1000dp 扣除两侧各 8dp 后，十格主区宽度为 984dp，普通键中心距为 `98.4 × 1.875 × 25.4 / 266.471 ≈ 17.586529115738674mm`。这是从用户基准取整后的换算，不是人体平均手距。横缝仍为原自动计算所得的 12dp，默认可见键帽宽为 86.4dp；没有用中心距替换键缝，也没有写入间距设置。

只有实际 `qwertyuiop / asdfghjkl / zxcvbnm` 三排且非自定义、非分体的自动默认尺寸使用这个中心距上限。逻辑密度变化时，按同一显示器物理密度换算 dp；未知、非有限、非正或不可表示的度量退回原公式。服务与悬浮停靠预览通过同一个 helper 读取当前显示器；Compose 按显示器、配置及逻辑密度缓存，按键重组不重新查询显示器。缓存不保存 Context、View 或用户偏好。

为了不在宽度达到 1000dp 时突然跳变，原 45% 默认高度预算随已有窄／宽区间平滑提高：使用与行错位相同的 `wideQwertyStagger` 进度，逐步允许当前可用宽度对应的原近方形键帽高度，**额外预算最多为可用高度的 50%**，同时受既有固定／悬浮高度上限约束；只保留旧版 228dp 最低预算在很矮窗口超过半屏的例外。预算从可用窗口求解，不从已收窄的返回宽度再次推算，避免重复解析越变越窄。参考平板可用高度 862dp 时目标为 `52 + 4 × (86.4 + 8.25) = 430.6dp`，最后取整为 **1000×431dp**，即约半屏；360dp 窄屏保留原 276dp 默认高。

首轮连续性测试保存了失败反例：393dp 高窗口的可用宽从 832dp 增至 833dp 时，返回宽度从 611dp 跳到 615dp。目标高度在插值之前取整造成台阶；现改用连续浮点高度，仅为最后的整数 dp 取整保留不超过 0.5dp 的容差，并始终夹在上述高度上限内。失败原始报告保存为 `.codex-artifacts/default-physical-calibration-20261008/rounding-before.xml`；后续仍使用原扫描断言，不以放宽断言消除失败。

任何已保存尺寸、位置、正在拖动的预览及手动高度均继续走原 `customSize` 分支，不受校准默认上限限制；本次未迁移、清空或覆盖保存的 1005×433dp／−244dp。物理宽度校准测试已加入 `KeyboardPhysicalMetricsTest` 与 `KeyboardDefaultGeometryTest`，本批运行及设备渲染结果另行记录，以下历史测试数字不代表新增校准已经验收。
