# 悬浮移动条与语音设置开关修正

## 问题与改动

- `FloatingKeyboardContainer` 原来在独立的 28dp 区域居中画移动条，`KeyboardResizeOverlay` 又在区域顶部下方 8dp 处额外画一条；玻璃预览透出真实移动条，因此出现两条，退出后只剩位置较低的一条。
- 删除覆盖层重复绘制，仅由真实卡片渲染移动条。主键区通过现有尺寸度量报告底排键帽下方的留白，加上用户底部留白和原有 28dp，横条居中放在这一完整空白区域。嵌套符号网格不能覆盖主键区数据，离开该布局时清理旧度量。
- 卡片总高度、键区约束、键帽和底排位置不变。调整页的移动命中区与真实移动区共用高度，控件避开该区域；普通主题的预览涂层也不再遮住真实横条。
- 语音设置的“使用本地模型”和“保持引擎常驻”取消低对比度的自定义 `primary / primaryContainer` 覆盖，和“SenseVoice 二次校正”一样使用 Material 主题的完整开关配色，包含开启、关闭和禁用状态。未修改开关行为或模型配置。

- 增加真实 `KeyboardView` 的界面回归用例：覆盖手机宽、平板宽和增高尺寸，检查进入/退出调整时只有一个移动条组件、中心位置不跳动、命中区一致、控件不遮挡。仅编译，未在设备执行。
- 本轮不运行整套尺寸门禁，不打包、不安装；玻璃/非玻璃外观、实际拖动手感和语音开关显示仍未验收。
