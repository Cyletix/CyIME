# 1.3.20 设置优先级与连续排序

## 用户问题与排序依据

新增功能不因“新”而置顶。按实际输入影响、常用程度和装饰性排列；保留原有配置值和功能，不重设用户选择。

- 主题与定制：配色方案第一；缩小配色缩略图；明暗模式收为一行选择；视觉样式、图标设置放入后面的“外观细节”。视觉样式使用独立子页，沿用主题配色和返回导航。
- 按键效果：按键音效、振动反馈、按键光效。炫光为可选装饰，排最后。
- 布局与显示：候选词、按键手势、输入框适配、基础输入、键盘底部样式。已存在的常用显示设置优先，新增大区块不占首屏。
- 键盘菜单：设置、键盘调节、全角/半角（适用时）、定制工具栏、主题与定制、智能联想、语音转文本、输入选项（适用时），最多八项。移除重复的明暗切换和低频模型管理捷径；模型管理仍在智能设置内。
- 常规字号、320×144 dp 菜单八项同屏。极窄屏和大字体仍允许分页，以免文字和按钮被压扁；设置始终在第一页。

## 拖动契约

输入方案设置、语言管理、键盘内顺序编辑共用拖动状态：

1. 长按后卡片在手指下移动，按实际抓取位置穿过其他卡片时插入；中间卡片使用位置动画让位。
2. 实际开始拖动后，靠近上下边缘按距离连续滚动；静止长按不自动滚动。
3. 松手才保存，取消恢复原顺序。结束后的迟到取消不能回滚已保存顺序；其他卡片的取消事件不能取消当前拖动。
4. 输入方案仍通过原持久化接口保存，不改变启用状态，保留未启用方案的原有占位。
