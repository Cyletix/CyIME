# 大写键拖动直线与边界

## 行为

- 按下大写键沿用临时大写；手指真正离开该键的范围后，显示从大写键中心到手指的主题色圆头直线。
- 拖动只预览，目标字母持续高亮；松手才输入一个大写字母。经过多个键、停留超过长按时间、上下移动均不调用目标键的长按、符号上下滑或左右滑回调。
- 回到大写键时隐藏线和目标；已经发生拖动后松手不会补触发点击或锁定。空白、分体中缝、符号键及键盘外没有有效目标；松手前移回字母键可重新选择。
- 连线裁切于实际键区，拖出键盘不绘制到其他应用；系统取消/手势被消费/布局退出均在 `finally` 清理临时大写、连线和高亮。
- 保留原有单击临时大写、双击锁定和双指按住大写输入。26键、自定义字母排列、分体布局按真实键位命中；14键的合并字母按左右半区选择一个大写字母。

## 实现与验证

- 扩展已有 `ShiftSlideTargets`，键盘边界限制命中，只接收字母目标；当前落点从实时注册表重新解析，不使用上次悬停目标提交。
- `ShiftSlideLine` 仅在绘制阶段读取指针状态，无动画循环、无触摸监听；目标不变时不因回调身份更新而重新组合全部字母键。悬停使用已有静态主题高亮。
- 单元测试覆盖键内移动、跨键停留、键盘四边及空白取消、重新进入、回到大写键、系统取消、14键半区及非字母排除；连同原大小写状态和玻璃配色测试共 19 项通过，0 失败、0 跳过。
