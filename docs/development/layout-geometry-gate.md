# 布局尺寸验收门禁（1.3.13）

截图中的确认按钮文字被裁切，原有测试只检查面板外框，未检查文字的实际排版高度。

## 校验规则

`LayoutGeometryAudit.kt` 遍历未合并的语义树，检查每个已渲染文字的行底部是否超出分配高度、非滚动区域内的文字是否被父容器裁切、文字/交互节点是否零尺寸或越界，以及非嵌套操作区域是否互相遮挡。滚动容器允许内容在视口边缘裁切，但不允许单个文字节点自身高度不足。装饰绘制和系统/宿主窗口不在语义树检查范围，需专门的几何测试或实机检查。

两项反例测试故意生成被压扁的文字、重叠的按钮，要求校验器检出，防止检查空跑。

编辑方向盘按实际扇形/切角轮廓检查操作区域，不把相交的外接矩形误判为按钮重叠。确认框先用实际字体和约束测量完整内容是否能放下，不按字号倍率猜高度；本轮最低高度矩阵禁止任何文字视口裁切。矮面板显示完整简短问句，按钮保留至少 48dp 高度，记录数量保留在无障碍说明中。

## 场景

- 确认框：240/360/800dp 宽，104/140/220/360dp 高，1/1.3/2 倍字体，逐一点击取消与确认。
- 实际剪贴板入口：280×140、360×200、800×180，验证确认覆盖范围、取消保留内容。
- 主键盘：中文26键、英文、九键、数字、常用符号、笔画、手写、14键、日语26键和假名，窄屏/手机/平板尺寸及大字体。
- 面板：菜单、输入模式、编辑、表情、剪贴板、快捷发送、工具栏定制、拆词、符号、插件面板；含低高度、横屏和大字体。
- 展开候选：现有窄面板/平板/大字体重排和候选身份测试。

新增页面/弹窗需补入场景；以上矩阵不代表所有设备和任意第三方插件都已验证。

## 强制执行

运行 `scripts/build-apk.ps1 -BuildType Debug -AdbPort 5038 -Serial emulator-5554`（端口/设备按环境设置）。脚本构建真实 APK、安装、执行 `verify-layout.ps1`；失败会隔离本次包至 `app/build/outputs/apk/rejected`，不生成成功包凭据。无设备也不会跳过检查后声称通过。

报告在 `app/build/reports/layout-gate/result.txt`；成功记录绑定 Debug APK 的 SHA256 和版本。正式发布脚本验证安装包 SHA256、源码提交和尺寸验收凭据。GitHub release workflow 在构建、上传正式包前强制运行同一组测试。

已有静态布局规则只是辅助。发包依据是渲染后的尺寸验收，不以编译成功代替。真机验收状态另行记录。

## 本轮检出并修复

- 清空剪贴板确认层受列表剩余空间挤压，按钮文字被裁切。
- 输入模式排序按钮、剪贴板标签继承过高行高，矮容器装不下。
- 拆词页操作标题挤占空间，导致右侧确认按钮宽度变成零。
- 编辑方向盘在矮高度下同时容纳图标与说明，说明被截断。
- 数字/笔画符号行高与实际键高不符，笔画重输说明固定偏移越界。
- 普通按键在低高度下仍有固定文字偏移，导致边缘裁切。

设备边界：本轮使用 Android 模拟器运行实际 Compose 渲染；手机、三星平板以及第三方宿主窗口仍需真机验收。GitHub 工作流的改动本轮未在远端执行。
