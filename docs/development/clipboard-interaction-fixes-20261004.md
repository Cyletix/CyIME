# 剪贴板高亮、粘贴联想、编辑浮窗与图片提示（2026-10-04）

## 本轮改动

1. **关闭后的图标高亮**：工具栏原来用 `collectLatest` 同时处理按下、松开及其他交互事件，焦点/悬停事件可中断松开后的褪色动画并保留中间透明度。改为按压状态驱动动画，选中状态直接取当前页面，不取退场动画保留的页面。剪贴板三个旧入口视为同一个工具，图片分类下再次点图标也直接关闭。工具栏按钮仍为原来的 40 dp，图标和排布不变。代码确认了这些路径的问题；用户描述的复杂操作偶发序列尚未真机复现，不能据此宣称所有偶发情况均已验收。
2. **粘贴不触发联想**：`commitPastedText → commitTextAndPredict` 原先明确允许粘贴触发预测。现在在提交前使旧预测失效并清除联想/英文补全，粘贴不发起新预测、不作为打字学习；保留带 `is_paste` 的文本提交事件和真实编辑上下文。粘贴成功、宿主拒绝、无连接、内部文本框提交都不会触发联想；下一次真实打字仍可触发。图片粘贴、系统图片粘贴与工具栏系统粘贴也取消旧预测。
3. **独立文本编辑浮窗**：长按编辑和新增固定复用现有草稿、保存及键盘输入路由，文本框移入键盘上方独立 Popup；不再增加原来的 200 dp 键盘高度。宽度随当前键盘、上限 640 dp，高度根据屏幕高度收缩，位置限制在可用窗口内。正文可编辑滚动，保留可选编码；取消/关闭不保存，保存失败保留草稿，Back/Esc 取消并返回剪贴板。编辑和新增入口都关闭原工具输入面板。浮窗沿用普通/玻璃主题背景；不新增系统悬浮窗权限，也不请求另一套软键盘。
4. **紧凑图片提示**：用“未能粘贴图片”小条替换原整宽大卡片，最大宽度 480 dp、按内容收窄；窄屏和大字号时操作可换行。保留系统粘贴、分享图片，关闭按钮独立显示并清除图片提示状态，不删剪贴板记录。系统粘贴返回成功后收起提示。
