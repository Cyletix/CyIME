# 键盘调节边框重做（按设计图的选框样式）

2026-10-18。用户看过 1.14.17（平板）和 1.14.22 的调节界面后要求重做：原来是一圈离键盘外沿十几 dp 的细线，四边粗短条、四角粗圆弧，粗细和线条不配，大屏上比例难看。中途改过两版：四角圆点（用户否定："都和边框对不上，为什么角落用圆圈"），以及照三星键盘的贴边实心三角（用户随后发来自己的设计图，要求"参考元素设计，不要改布局"）。最终按设计图的元素做，控件位置和布局不动。

## 现在的样子

`KeyboardResizeOverlay.kt` 的 `drawBehind` 和 `KeyboardResizeRect.kt` 的 `ResizeFrameStyle`：

- 一圈细线像选框一样框住整块键盘：直角矩形，面板的圆角留在框里面；线往里收半个把手厚度（按拖动放大后算），所以括号和短条骑在线上时外沿正好与键盘外沿齐平，固定模式不会被窗口裁掉。
- 四角是 L 形括号：骑在线的角上，角上直角、两端圆头。
- 四边中点是短条，骑在线上。悬浮模式底边中段是移动条，不画底边短条；分体时内侧两条竖边照旧画线，短条骑在线上。
- 正在拖的那个把手放大 1.25 倍。
- 固定模式顶部的"左右拖动移动键盘 / 已居中 · 左右拖动"拖动条位置不变，样子改成设计图里的小标签：圆角、强调色描边、移动图标 + 文字。
- 键盘面板压暗改为面板色 72%（原 88%，键几乎看不见），再罩一层 8% 的主题强调色；玻璃效果下不涂面板，只画边框和把手。
- 透明度滑条改成 20dp 圆形滑块（Material 3 默认竖条滑块和中间的百分比标签撞在一起）。
- 底部"上下拖动调节底部留白"提示上移到底边短条之上，不再压住把手、不再被键盘底沿裁掉。

粗细随屏幕最短边成正比（400dp 为 1 倍，0.85–2 倍）：细线 2dp、短条 5dp 厚 36dp 长、括号线宽 4dp 两臂各 20dp，平板（≥800dp）各翻倍。短条和括号放大后仍在 26dp 边缘命中带内，括号两臂落在 36dp 角区附近。颜色一律用键盘配色的强调色（`LocalKeyboardPalette.accent`），浅色、深色、玻璃、各配色方案跟着变。
