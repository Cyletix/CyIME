# 明日方舟内置词库（2026-10-12）

用户要的效果：打明日方舟、尤其少人/极限圈的说法（无精二、精一1级、四星队、解手流等）时，九键、全拼、双拼都能直接出词；词库可单独关，默认开，不混进主词库。

## 实现

- 词库：`app/src/main/assets/cell_dictionaries/cell_builtin_arknights.dict.yaml`，约 5000 条，182 KB，全拼编码。由 `tools/dictionaries/arknights/build_arknights_dict.py` 生成，人工词表在同目录 `core_terms.txt`（极限圈核心说法）与 `slang.txt`（社区外号）。
- 来源：wiki.arkrec.com 的流派定义与关卡目录（`/v1/api/category-definitions`、`/v1/api/menu`，各抓一次，用完删除）；PRTS 干员/技能/敌人/召唤物（经 ArknightsResearch 的 `data/community/community.sqlite`，只读）；ArknightsResearch 的干员表（gamedata 2026-09-04）；本机 ArknightsGameData（2024-02，用于子职业和材料名）；BWIKI 常见黑话页。读音取自 rime-ice 词表，多音字按 rime-ice 词条优先。
- 权重：三字及以上核心说法排在同码普通词前；两字核心词（如“精一”“棘刺”）和自动生成的专有名词保持中等权重（600～1200），不挤掉日常用词（“几次”不被“棘刺”压掉）。rime-ice 已有且权重不低的词跳过。
- 接入：复用分类词库（`CellDictionaryRime`）的 `translator/packs` 挂载，作用于 rime_ice 系全部中文拼音方案（26 键、九键、小鹤双拼、14 键）。`CellDictionaryCatalog.builtins` 登记内置词库；`CellDictionaryStore.installBuiltin` 在每次初始化时从 APK 刷新词库文件，首次见到时同时设为已选和已应用（默认开），之后用户关掉不会被重新打开（`seeded` 记录）。`RimeConfigHelper.initializeRimeDataAsync` 在 `prepare` 前调用 `syncBuiltins`，失败只记日志不影响启动。设置“分类词库”页顶部显示该词库的开关，分类筛选新增“内置词库”。
- 纯数字简称（180、101、290、1604）直接用数字键打，不进拼音词库；收录了对应的文字说法（精一80级、精二90级等，按“八十级”“九十级”读音）。
