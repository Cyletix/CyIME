# 1.3.20 手写主题配色与内置模型版

## 变更

- 普通、全屏、查字手写统一取键盘主题强调色，不再取按键文字色或固定黑色。
- 在已知背景上，强调色不足 4.5:1 时沿 Oklab 插值向对比更强的黑/白微调；达到目标即停止，不统一退化成黑白。
- 笔迹保留彩色主体，外围为各 0.75dp 的近白与近黑细轮廓，应对透明手写覆盖宿主图像。没有发光、模糊或逐帧背景取样。落笔单点立即可见。
- 删除 858AdvanceColor 目录项和内置配置，过滤旧部署中的同名配置；旧选择迁移到柔和蓝，保留深浅模式设置。
- 修复只覆盖回车颜色时未提供主色却回退默认紫色的问题；部分覆盖现在保留其余原主题颜色。
- 候选翻页恢复最早 CandidatePage（4f671f8c）圆形左右箭头图形；当前右栏布局、等高区域和触摸面积不变。
- 内置版：Zipformer + SenseVoice + predictive-text-base + ochwpro。新安装无需逐个下载，按设备条件启用语音二次校正；已显式选择的语音模式不覆盖。
- 正式交付每个版本固定两个 ARM64 APK。scripts/build-release-editions.ps1 依次构建、验收两版；scripts/publish-release.ps1 要求两份匹配源码提交及包哈希的门禁记录。

## 配色验证

HandwritingInkAppearanceTest 在生产 HandwritingKeyboardLayout 上注入真实 down/move/up 手势书写“中”，保存纯色和高频复杂背景截图，逐像素确认主题笔迹实际出现。不是独立网页预览，也不是把文字贴在图片上。

| 主题 | 背景 | 主体相对背景对比度 |
|---|---|---:|
| 柔和蓝 | 浅 | 5.55:1 |
| 柔和蓝 | 深 | 10.38:1 |
| 薰衣草紫 | 浅 | 4.55:1 |
| 薰衣草紫 | 深 | 8.49:1 |

4.5:1 是本实现选用的工程目标，不是声称自由笔迹必须满足文本 WCAG 条款。图形辨识也依赖边界、笔画宽度和实际抗锯齿。W3C 非文本对比度指南使用 3:1，允许边框帮助分隔形状：https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html 。

自评：主题色一致，深浅背景不依靠同一明度硬撑；复杂背景上能辨识边界。第一版 1dp 双边缘略有描边感，已缩到 0.75dp。不会宣称所有照片上都完美可读；纹理极密、极细笔画及真实屏幕观感仍需真机验收。粗细算法保持原逻辑，本轮不把字形粗细的变化混进配色修复。
