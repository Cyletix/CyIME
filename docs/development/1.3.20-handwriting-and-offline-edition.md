# 1.3.20 手写主题配色与内置模型版

## 变更

- 普通、全屏、查字手写统一取键盘主题强调色，不再取按键文字色或固定黑色。
- 在已知背景上，强调色不足 4.5:1 时沿 Oklab 插值向对比更强的黑/白微调；达到目标即停止，不统一退化成黑白。
- 笔迹改用密度无关的 3.5dp 主线：连续二次曲线、圆头、主题色透明渐变、窄且低透明度的同色边缘，以及轻微内层色差。普通底板没有黑白双描边；全屏透明底板才增加窄的半透明分隔底衬。没有位图放大、模糊或逐帧背景取样。落笔单点立即可见且不会变成大圆点。
- 删除 858AdvanceColor 目录项和内置配置，过滤旧部署中的同名配置；旧选择迁移到柔和蓝，保留深浅模式设置。
- 修复只覆盖回车颜色时未提供主色却回退默认紫色的问题；部分覆盖现在保留其余原主题颜色。
- 候选翻页恢复最早 CandidatePage（4f671f8c）圆形左右箭头图形；当前右栏布局、等高区域和触摸面积不变。
- 内置版：Zipformer + SenseVoice + predictive-text-base + ochwpro。新安装无需逐个下载，按设备条件启用语音二次校正；已显式选择的语音模式不覆盖。
- 正式交付每个版本固定两个 ARM64 APK。scripts/build-release-editions.ps1 依次构建、验收两版；scripts/publish-release.ps1 要求两份匹配源码提交及包哈希的门禁记录。

## 已撤回的视觉验收与修正

用户明确拒绝最初的粗“中”截图，以及随后过细、有明显阶梯感的截图。先前“对比度通过，所以观感合格”的判断撤回。第一版仍沿用按像素变化的粗细和大起笔圆点，并叠加双轮廓；第二版又过度收窄。旧截图、旧测试不能作为新版交付凭据。

当前验证使用生产 HandwritingKeyboardLayout，通过连续 down/move/up 手势书写“手写”，覆盖柔和蓝、薰衣草紫、深浅背景和高频复杂背景。额外在 384dp 宽、2.75 倍像素密度（1056 像素宽）下截取手机比例图片，禁止将低密度截图放大冒充手机观感。

Canvas 的 Paint 默认开启抗锯齿。新增手机密度斜线像素测试，取笔迹外围的多个次像素覆盖级别，检查实际边缘渲染而不仅检查开关。线宽、起笔点和渐变也有单独像素检查；这些检查防止退化，不能替代观感审阅。

主题强调色只在相对已知底板的对比不足时调整。原先 4.5:1 数字仅指不透明基础色，不是透明渐变渲染后的实际对比度。复杂宿主背景无法通过一个固定前景色保证全域对比，采用窄的半透明底衬辅助分隔，实际效果仍须看截图及真机。不得再用不透明色对比计算宣称所有照片均清晰。

- Android Paint 抗锯齿默认值：https://developer.android.com/reference/kotlin/androidx/compose/ui/graphics/AndroidPaint
- Android Ink 渲染将输入轨迹与高质量抗锯齿绘制区分处理：https://developer.android.com/develop/ui/compose/touch-input/stylus-input/ink-api-modules
