# 设置菜单重构方案（2026-10-20，待确认）

只读盘点后写的方案，代码还没改。你点头后按这里动手，动手时不靠加按钮或说明文字补。

## 一、你看到的（现状）

首页一共 21 个入口（另有开发版的「手写训练模式」），分 7 组。下面每页标出可调设置的数量（一个开关、一组单选、一个滑条算 1 项）。

```
首页（搜索 · 试打框 · 「语音转文本」开关直接挂在首页行上）
├ 输入法：启用输入法 · 选择输入法 · 物理键盘(9)
├ 外观与交互：主题与定制(3 + 视觉样式(1) + 图标设置(4) + 透明度与模糊(3))
│             按键效果(10) · 性能与省电(3)
├ 键盘布局：布局与显示(索引页，0 项 + 7 个子页)
│   ├ 26 键(7) · 九键与 14 键(6) → 各自又能进「按键符号」(7 个标签页)
│   └ 候选词(6) · 键盘外观(5) · 角标与长按(3) · 光标与空格(4) · 手写与数字键盘(3)
│           布局管理（独立界面：布局列表 → 编辑布局(5) / 编辑符号(7 个标签页)）
├ 方案与词库：语言管理(5) · 输入资源(2 个标签 + 菜单里 5 个入口) · 词库管理(4 个标签 + 分类词库)
├ 扩展：扩展商店(方案/模型/插件 3 页) · 插件管理(列表，无开关)
├ 智能：智能联想(4，另有一行「模型管理」) · 语音转文本(6) · 模型管理(2)
├ 同步与备份：备份与恢复(1) · 剪贴板同步(7+，验证码藏在折叠里)
└ 关于：使用文档 · 关于(0 项，里面还有存储空间、日志、隐私、许可证)
```

## 二、原因（问题在哪）

**分支不平衡**
- 太浅：备份与恢复只有 1 个开关；视觉样式只有 1 组卡片；「布局与显示」首页本身 0 项，只是 7 个链接；「关于」0 项。
- 太深：按键符号要走 首页 › 布局与显示 › 26 键 › 按键符号 › 标签页，共 4 层；插件设置能从 关于 › 存储空间 › 插件管理 › 插件设置 绕进去。
- 常用的藏得深：候选字大小、按键字号这些天天会调的，都在「布局与显示」的第 2 层。

**分类不合理**
- 「键盘外观」（按键字号、角标提示、气泡、底部圆角）属于外观，却和主题分在两组。
- 「数字框自动数字键盘」和手写没关系，却放在「手写与数字键盘」页里。
- 手写停顿、公式标记和语音一样是输入方式，却在键盘布局下面。
- 「语音转文本」的总开关挂在首页行上，进到语音页里反而没有开关。
- 「输入资源」和「语言管理」都能选当前方案；输入资源的「已下载/导入」和商店里的「本地方案」是同一份内容。

**重复**
- 模型有 4 个入口：商店模型页、模型管理、智能联想里的模型管理、语音页各自下载。
- 插件有 3 处：商店插件页、插件管理，另外「安装插件」只是跳回商店。
- 分体键盘开关在 26 键页和九键页各出现一次；按键符号编辑器有 3 个入口。
- 释义词典能从候选词页下载，商店里也有。

**另一个线程查出来、这次一起处理的**
- 个人词库标签页总是空的，只能搜索不能编辑。
- 词库页顶部的「方案」选择对自定义短语没有作用，有误导；自定义短语为空时的提示文字写错了页面。
- 插件商店是空的：index 里一个插件都没登记，方案只有五笔 86/98。
- 插件显示「未启用」，却没有开关。
- 文件管理器的「导出」和「导出备份」重复。
- 键盘菜单里的「悬浮」和「键盘调节」里的悬浮重复。
- 无痕模式下照样记「最近使用」。
- 不生效的设置照样显示：图标设置在「跟随主题色」打开时，底板和样式两项其实不起作用；部分机型上振动时长不起作用；性能页「自定义」是一个点不动的单选。
- 没人用的死页面：方案词库浏览、商店模型页的单独路由、旧的自定义短语页。

## 三、改法（新的设置树）

首页从 21 个入口收成 15 个，分 5 组。每个入口进去基本是 3～10 项，最多再分一层；常用的放在首页一级。

```
首页（搜索 · 每行右侧显示状态）
├ 输入法
│   ├ 启用输入法［已设置］ · 选择输入法［已设置］ · 试打框
│   └ 语言与方案［中文 · 英文］  语言开关与排序、每种语言的布局和方案、语言键切换方式、
│                              已启用组合的顺序（原「输入资源·已安装」并入）
├ 键盘
│   ├ 主题与外观［当前主题］  显示模式、玻璃、配色、视觉样式（不再单独一页）、按键字号、
│   │                       角标提示、点按气泡、底部圆角；图标设置（4）保留为子页
│   ├ 候选词                 原 6 项，从第 2 层提到首页
│   ├ 键盘布局               26 键、九键与 14 键（各自的手势开关）、自定义布局（原「布局管理」）、
│   │                       按键符号（只留这一个入口）、分体键盘（只在这里出现一次）、数字框自动数字键盘
│   ├ 按键与手势             角标输入方式、反转上下滑、长按语言键、滑动移动光标、长按空格（原两页合并，7 项）
│   ├ 按键效果               声音和振动（原 10 项）
│   └ 物理键盘［已连接］      原 9 项
├ 智能与输入方式
│   ├ 智能联想［已开启］      开关、空格上屏联想、连续/单次、选用模型（下载统一去「扩展›模型」）
│   ├ 语音与手写［已开启］    语音总开关移到页内顶部；本地/在线、二次校正、字幕图标；
│   │                       手写停顿、公式标记；手写训练（开发版）
│   └ 词库                   自定义短语、方案词库、分类词库、恢复屏蔽的候选；
│                           去掉空的「个人词库」标签；「方案」选择只在方案词库标签出现
├ 扩展［n 个可更新］         一个入口，左右滑动三页：方案 / 模型 / 插件；
│                           每页上面是已安装（就地启用、切换、删除），下面是可安装；可安装为空时那一段不显示
│                           （替代 扩展商店、插件管理、模型管理、本地方案、输入资源·已下载/导入）
└ 系统
    ├ 剪贴板与同步            我的设备、同步开关、短信验证码直接显示（不再折叠）
    ├ 备份与恢复              1 个开关 + 导出/恢复，两个动作就是这页的主体，保留
    ├ 性能与省电              档位改成卡片，「自定义」只在手动改过时显示为当前状态，不再是一个点不动的单选
    └ 关于                   版本、存储空间、日志、隐私、许可证、使用文档
```

**不生效的就不显示**（规则「一页只放真正生效的」）
- 图标设置：「跟随主题色」打开时，隐藏底板和样式。
- 按键效果：机型不支持调时长时，不显示时长滑条。
- 剪贴板同步的两个同名开关，按作用改名：一个控制「同步本机剪贴板」，一个控制「允许别的设备连接」。

**删除**：方案词库浏览、商店模型页的单独路由、旧自定义短语页、首页上的语音开关（移进页内）、智能联想里的「模型管理」行、商店顶部的「本地管理」按钮、插件页的「安装插件」跳转按钮。

### 要你决定的

1. ~~物理键盘放哪组~~：已定（10-20）留在「键盘」组。
2. ~~插件上架~~：已定（10-20）不上架。打字统计、WebDAV 备份、WebDAV 剪贴板同步是原 Xime 作者写的插件，不需要云同步；小功能直接内置。插件页只显示已装的插件，可安装为空时那一段不显示。

## 四、怎么检查

- **单测**：
  - 设置搜索的索引按新位置更新，并检查每个页面都能被搜到。
  - SettingsRoundTripTest 照旧检查每个设置写入后读回一致。
  - 新加一个结构测试：除「备份与恢复」「关于」外，每个设置页至少 2 项；首页每组 2～6 个入口；任何设置只出现在一处。
- **界面**：上平板或模拟器时截首页和每个新页面；旧入口逐条按对照表点一遍，确认能到新位置，返回能回到来的地方。
- **不丢设置**：只搬位置，不改存储键，升级后原来的选择全部保留（由读回测试守着）。
- **分批做**：每批单独出补丁，一批能单独编译和回退。顺序：先合并「键盘」组，再「智能与输入方式」，再「扩展」，最后「系统」和删除。「扩展」三页左右滑动另一个线程已在改，这里接着它做。

## 五、实际改法与方案的差别（10-20 改完后补记）

- 「语言与方案」没有把原「输入资源·已安装」的列表直接塞进来，而是在页底放一个「已安装的方案」入口（原输入资源页改名）。那一页的启停、排序、应用更改逻辑较重，硬合并风险大。
- 「扩展」是唯一入口，三页左右滑动，每页右上角「已安装」进对应的已安装管理（方案→已安装的方案，模型→模型管理，插件→插件管理）；「每页上面已安装、下面可安装」的合并版没做，属于商店页内部的大改，另排。
- 按键效果在点击触感机型上隐藏时长滑条：没改，判断条件要先查清（目前时长不为 0 时仍按时长振动）。
- 键盘菜单「悬浮」重复、无痕模式记最近使用、文件管理器两个导出：不属于设置树，未在本次处理。
- 顺带修了：冷启动时从键盘「缺手写模型」进来落到首页的问题；删掉 schema_local、schema_dict_browser、market_model 三个没人用的路由。
