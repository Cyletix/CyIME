# 键内滑动预览、方向反转与玻璃大写状态（2026-10-04）

## 依据与实现边界

先核对了 Apple 的 iPad Key Flicks，而非根据“iOS 风格”推测：

- [Apple 使用说明](https://support.apple.com/en-ie/119889)：下拉按键，抬手输入数字或符号。
- [Apple WWDC 2017 官方演示，约 1:48:11–1:48:16](https://www.youtube.com/watch?v=oaqHdULqet0&t=6491s)：实际查看按键特写，上方的小号符号在原键内成为主字符，键帽不扩大，不另弹浮窗。

这是 iPad 功能的参考，不声称所有 iPhone/iOS 键盘均使用此行为。Apple 演示没有给出精确距离、插值曲线或完整回滑取消规则；CyIME 保留自己的提交/取消机制，并按用户要求扩展为上下双向和可反转方向。

## 最终行为

26/14 键字母区以及对应标点键，共用「布局与显示 → 共通输入 → 反转上下滑方向」。普通、紧凑横屏、分体使用相同规则。

| 设置 | 下拉 | 上拉 |
| --- | --- | --- |
| 默认，反转关闭 | 上方角标 | 下方角标 |
| 反转开启，原习惯 | 下方角标 | 上方角标 |

角标仍在右上/左下，用户配置的内容不交换、不重写。旧配置字段 `up`/`down` 在这个适配边界继续承载上方/下方槽位，运行时统一交换动作、提交参数、预览来源和禁用方向。自定义符号编辑页按实际设置标出操作方向，旧 `SWIPE_UP` 存储值保持兼容，界面名称改为“滑动输入”。

长按模式仍在 300 ms 输入上方符号，禁止它对应的物理滑动方向，另一方向仍可输入下方符号；反转不会产生额外点击。删除、空格、语言键、九键/笔画和日语四向滑动的方向契约没有套用这个字母键方向设置。共用字符组件的纵向预览改为键内显示；专用功能键的反馈仍使用各自组件。

符号的移动和放大连续跟随位移，原主字符渐隐，已移动的角标不会重复绘制。预览只绘制在原键帽裁切区，沿用实际宽高、字号、主题色，不更改键帽、行高、工具栏或触摸区域。到达原滑动距离后预览居中，只有松手才提交；越过阈值后回滑或取消不补出普通字母，未越过阈值仍保留原点按行为。按键长按菜单、14 键左右选字母与按键音/振动调用不变。

顺带修正同一调用链的两个冲突：`display:key` 的符号也能提供键内预览，显示标签不冒充实际提交值；隐藏下方角标不再同时解绑其输入动作。`display:bubble` 不再意外印出上方常驻角标，纵滑时则用键内反馈取代原浮窗。

透明玻璃 Shift 使用当前主题强调色：临时大写轻染色，锁定大写加强染色和不透明度并保留锁定点；图标根据合成面板色选择可读颜色。普通/分体调用同一配色策略。非玻璃配色不变，用户明确设为全透明时背景仍透明，状态由图标表现。颜色对比测试以主题面板色为背景，不代表任意壁纸上的实机可读性均已验收。
