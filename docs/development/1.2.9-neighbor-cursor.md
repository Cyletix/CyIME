# 1.2.9 Debug：邻键纠错、中英混输与光标手势

对应 2026-09-29 的反馈。旧输入质量计划里的邻键工具确实一直未接入键盘；本轮补上生产路径，不把离线工具算作功能完成。

## 实现

- 26 键实测键帽矩形 → 字母邻接表 → 原有串行输入队列 → Rime 原生纠错候选。自定义顺序、缩放及分体间隙按实际几何处理。缺少完整 26 字母、合并键或关闭开关时传空邻接表，不套用固定 QWERTY。
- 中文全拼使用原生拼音词典和候选身份/选择接口；保留原输入，用户选择纠错候选后才上屏。近邻搜索限制每音节一次替换、每键最多六个邻居、待搜索后缀最多 32 字符；没有穷举整句排列。九键、14 键、双拼及日语不启用这条纠错路径。
- 全拼方案随包升级；已有自定义方案只补 translator 的纠错开关，原文件先备份，不删除个人学习词库。
- 中文 26 键原本已挂载 `melt_eng` 英文词典和 `cn_en` 混合词表，本轮用真实引擎核验。按词选词混输不等于保证任意连续拼音/英文串能自动识别全部词界。

## 设置及互斥契约

入口：布局与显示 → 基础输入。

| 光标方式 | 键盘滑动 | 空格长按 |
|---|---|---|
| 长按空格（默认） | 关闭 | 100ms 进入光标控制，松手不输入空格 |
| 键盘滑动 | 开启 | 使用保存的连续空格或语音开关，300ms 触发 |
| 关闭 | 关闭 | 使用保存的连续空格或语音开关，300ms 触发 |

空格用于光标时，保存的另一动作暂停而不被改写。语音开关复用工具栏麦克风的开始/结束路径，不进入会卸载空格键的旧语音面板。旧 `VOICE` 设置继续按先前迁移规则映射到光标；新动作使用 `VOICE_TOGGLE` 保存，防止升级后意外恢复录音。连续空格的重复间隔与松手停止语义保留。
