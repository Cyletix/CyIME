# 1.3.15：精简老人版与材质独立

老人版内置手写、预测 base、Paraformer、SenseVoice，共四个模型；不再打包预测 small 或 Zipformer。构建器会移除生成目录中旧版遗留的这两个模型，运行时不会删除用户已经安装的模型。两份语音资源合计 476,752,236 字节，因此即使精简，离线包仍会明显大于普通版。

首次配置的保守分档：系统未标记低内存设备、物理 RAM 至少 6 GiB、可用 CPU 核数至少 4 时，开启 Paraformer + SenseVoice 二次校正及键内炫光；否则只使用 Paraformer，关闭炫光。预测统一默认 base。该规则是配置建议，不是性能测量；不每次启动重写用户设置。现有语音设置和按键效果设置仍可手动调整。升级旧内置版时，只对旧版默认模型组合做一次迁移，后续用户选择不重置。

视觉样式不再覆盖明暗、键盘主题颜色或背景；切换主题也不会清除视觉样式。磨砂更名毛玻璃，材质高光、阴影与当前主题主色一起计算，采用缓存的静态渐变层，未增加逐帧背景模糊。

桌面及键盘标志使用经用户参考图处理的透明 PNG，毛玻璃使用同构紫色磨砂版本；不再绘制先前不匹配的几何图案，也不再使用白底磨砂图标。当前霓光、玻璃、折面共用参考图标主体；它们的区别体现在界面材质。图标导出接口复用同一资源。

图像使用内置 imagegen 工具处理。输入为用户提供的 `codex-clipboard-aac27129-72aa-48d7-84b5-f67de664d5ec.png`。

- 基础图提示：保留四个紫色折叠箭头、深色圆角底板及渐变，只移除外部黑底为透明，保留少量光晕安全边距，不加文字。
- 毛玻璃提示：保留同一形状、排列和紫色深底，将主体调整为柔和磨砂玻璃，透明外部，禁止白底变体。
- 生产资源：`app/src/main/res/drawable-nodpi/cyime_reference.png`、`cyime_reference_frost.png`。两者均 RGBA，透明通道覆盖 0–255。

验收包括硬件分档边界、效果与明暗/配色独立、实际按键操作与对比度、图标绑定与单桌面入口、设置页尺寸，以及既有输入面板尺寸门禁。模拟器验证不等于手机和平板真机验收。

2026-09-30 验证结果：设备分档及材质独立共 4 项 JVM 测试通过；内置版 22 项设备测试通过。已查看毛玻璃明暗键盘截图，按键与功能图标完整可见。首次对比度检查误用了主题强调色，而生产深色功能键使用白色；测试改为与生产一致的前景色，仍保持 4.5:1 阈值，并增加全部四种材质的明暗覆盖。

内置版 ARM64 Release 为 494,654,635 字节，Debug 为 597,111,785 字节。安装包资产清单仅含上述四个模型。产物及校验记录保存于 `app/build/outputs/apk/editions/1.3.15/full/`。当前仅连接模拟器，尚未手机／平板真机验收。

普通版也完成同一套设备门禁（22 项登记，2 项内置模型专属检查按条件跳过，无失败）；ARM64 Release 为 82,047,819 字节。普通版产物保存在 `app/build/outputs/apk/editions/1.3.15/standard/release/`。两版均保留独立校验记录，未发布 GitHub Release。
