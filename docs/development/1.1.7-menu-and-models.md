# 1.1.7 Debug：菜单、模型与插件入口

## 修改清单

- [x] 键盘菜单移除“部署方案”和“快捷发送”；快捷发送仍在剪贴板中使用。
- [x] 输入方案设置保留应用能力，按钮更名“应用方案更改”，明确日常输入不需要定期部署。
- [x] 模型管理归入“智能”，说明涵盖语音、手写与联想；修正语音入口仅介绍在线插件的旧描述，关闭语音时也可进入配置页。
- [x] Zipformer · 中文、Paraformer · 中英、SenseVoice · 多语言统一为三个主模型单选项。
- [x] 单独的 SenseVoice 二次校正开关可搭配 Zipformer 或 Paraformer；SenseVoice 作为主模型时禁用自我校正。
- [x] 移除将独立 SenseVoice 偏好自动改成双模型的迁移；保留原有双模型 ID 和已下载文件。
- [x] 在线语音、剪贴板同步、云备份提供明确的安装与管理入口。安装直达扩展商店“插件”页，插件管理页也提供安装入口。
- [x] 同步服务选择不再要求先启用同步或提前启动插件；配置服务后再开同步。备份连接配置排在备份操作之前。
- [x] 插件服务使用单选控件，启动过程中阻止重复切换，显示启动失败原因。
- [x] 菜单不再为四个项目强占两行；窄面板与大字号减少列数并分页，避免文字裁切。
- [x] 返回功能页或插件管理时重新读取安装和启用状态，避免商店安装后的旧列表。
- [x] 版本 1.1.7 / 20261017，应用 ID 不变；仅 Debug，不发布 Release。
