# 符号和数字：上滑或长按输入

2026-10-02。已随 **1.4.0／20261041** 覆盖安装平板 SM-X800；实测按住期间已输入、松手不重复，精确 300ms 边界未测量，用户验收待确认。本轮未更新手机，最近确认手机版本为 20261039，不包含本项。交付见 [界面整理与平板复测](clipboard-expression-refresh.md)。

## 行为

设置入口：**布局与显示 → 基础输入 → 按键角标的符号和数字**。默认上滑，保留已有输入习惯；选择保存后通过偏好监听即时生效，未知设置值回退上滑。

- 上滑输入：沿用上滑松手确认与原长按菜单。
- 长按输入：按住满 300ms 立即输入原上滑输入的数字或符号一次，不等松手、不弹出选项；继续按住、滑动或松手都不追加输入。到时前取消不输入，到时后的取消不撤回已输入内容。原九键字母菜单仅在上滑模式保留。
- 长按模式中快速上滑及上滑后回原位均不补发普通字符；下滑编辑动作、0 键左滑上一候选保持原行为。按下时固定本次动作，设置变化影响下一次手势。
- 只有配置中的文字上屏动作参与切换；复制、撤回、切面板等命令保留原手势。空格、删除、语言键及专用图标菜单不参与。

覆盖普通、紧凑横屏、分体及自定义 26 键，以及九键和笔画布局。实际输入值独立于提示文字，关闭角标提示不会禁用输入，也不会把九键数字重新送入拼音编码路径。

## 实现与检查

`KeyboardInputPreferences.symbolInputMode` 保存模式；`SymbolInputMode.kt` 为明确传入文字值的按键设置 300ms 计时动作，并清除松手选择菜单；复用 `ExclusiveKeyGesture` 已有的到时执行分支，后续松手不触发普通按键或菜单输入。没有新增 schema 判断，也没有改变键盘高度、键位和触摸区域。

设置选项使用 FlowRow，窄屏可换行；说明文本不设固定高度。原有自定义长按菜单仍限制在键盘两侧边距内；本次长按直接输入不弹菜单。实际大字体渲染与裁切尚未验收，未运行整套尺寸门禁。

本次纠正为到时直接输入后，**20 项相关 JVM 检查通过，零失败、错误或跳过**：输入偏好 14、符号模式及菜单宽度 6。覆盖默认兼容、双向保存、隐藏提示、计时动作与松手菜单互斥、上滑模式保留原字母菜单、命令排除及菜单宽度约束。

应用及 Android 设备测试代码编译通过。设备用例更新为检查 299ms 未输入、满 300ms 未松手已输入、持续按住不重复、松手不追加、计时前后取消、输入后四向滑动不触发第二动作；保留上滑模式字母选择、禁用上滑不误出字、下滑与左滑测试。**这些设备用例仅编译，未执行，准确时序和真机手感尚未验收。**
