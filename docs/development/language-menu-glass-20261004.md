# 语言菜单玻璃配色（2026-10-04）

## 修改

透明玻璃深色主题的主色接近白色，语言菜单原来将该颜色不透明地填满选中项，并在已有玻璃背景上再次叠加浮层亮面，导致选中项发白、菜单与键盘质感不一致。

`LanguageKeyButton` 的玻璃菜单现在读取当前键盘调色板：

- 背景使用键盘背景色和相同玻璃参数，移除额外的白色亮面，保留轻微外缘及阴影以区分浮层。
- 选中项复用功能键玻璃填色，混入少量主题强调色，并小幅增加不透明度；使用细主题色边缘与勾号标记选中。完全透明键帽设置仍保持填色透明，边缘与勾号保留。
- 选中与未选中项均沿用键盘文字色，副标题降低不透明度，避免沿用白底对应的反色文字。浅色、深色随当前调色板及各自玻璃参数切换。
- 非玻璃菜单仍使用原 Material 配色和材质。菜单尺寸、定位、滚动、长按拖选与语言切换逻辑未改变；全键盘和物理键盘共用该菜单。
