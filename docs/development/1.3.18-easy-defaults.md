# 1.3.18：普通版与内置版共用易用默认设置

此前普通版智能提示、本地语音开关的缺省值仍为关闭，自动开启只存在于内置版安装流程，导致普通版仍需逐项开启。本轮统一缺省值：

- 智能提示开启，Base，单次联想；空格不上屏提示词。
- 语音入口开启，默认本地识别；已有在线语音选择保留。默认不启用语音模型常驻，不会因此开启麦克风录音。
- 炫光在未保存该设置时按设备配置初始化，高配置开启、低配置关闭。
- 普通版原有手写／语音自动准备之外，加入 Base 自动准备；已关闭提示、选用其他预测模型或主动删除该模型时不补装 Base。
- 内置版不再在模型安装结束时强制覆盖智能提示和语音开关，避免覆盖安装期间用户的选择。

已有的中文语言默认、中文26键和九键、后台部署失败重试、不自动创建实验布局保持生效。

`OfflineEditionTest.freshLanguageSettingsOfferChineseOnly` 同时检查缺省开关、Base、单次联想、常驻关闭，以及显式关闭／连续联想／反向炫光选择在重新初始化后保留。设备配置边界沿用 DeviceDefaultsTest。Debug 通过 build-apk.ps1 的完整门禁后交付；真机未验收。
