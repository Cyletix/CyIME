# 词库/排序固定回归用例（2026-10-18）

用户指出：报过的问题不知道有没有进测试集，测试流程混乱；26 键很多人只打 2–4 个首字母的常用语，经常不能直出。

## 文件

- 用例：`tools/ime_lab/fixtures/lexicon_regression.tsv`，一行一条：id、键盘（26 / 14 / 9 / win26）、输入、期望（`!X` 表示首选不能是 X）、名次上限、来源、日期、备注。**以后每个新报告先加一行再修。**
- 运行：`python tools/ime_lab/lexicon_regression.py --dll <rime.dll 目录> --work D:/CyIME-Data/tmp/lexicon-regression --output <结果.json> [--baseline <旧结果.json>]`。26/14 键用上次构建生成的雾凇数据（含扩展词频）和 14 键方案，26 键带 QWERTY 邻键表（模拟触屏纠错）；win26 用 CyIME-Windows 的 data/rime。九键行要词组模型和联合解码器，只能用 `t9_replay.py`，这里列为未运行。给 `--baseline` 时逐条列出改对/改错。
- 首字母常用语：`tools/ime_lab/initials_phrases.py` 从雾凇 base 词库取 2–4 字词，用九键词组模型（公开语料）打分，每个首字母组合取语料最常用的词作期望；最常用词领先第二名不到 0.7 nats 的组合不收（语料自己也分不清）。每种长度 150 条。不读任何聊天记录。
