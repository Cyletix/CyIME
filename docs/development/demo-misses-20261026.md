# 演示打字错词（2026-10-26）

平板 1.14.119–121 无痕模式录演示时，空格取首选打错或打不出的约 90 处（清单在 `D:/CyIME-Data/demo-video/typing-misses-20261026.md`，私有，不进仓库）。电脑引擎（当前源码＋词组模型 t9_ngram.lm）复测：26 键 81 条连打输入只有 25 条首选正确。

## 原因与处理

1. **输入法自己的用词在词频里接近 0**（上屏 43、出词 11、声纹 29、实机 820；每个键、键全拼、声纹模型、加权分不在词库）。雾凇词频按书面＋聊天语料估，输入法话题几乎没有出现。新增 `app/data/cyime_domain_terms.tsv`（67 个输入法、键盘、演示用词），构建时给 base/ext/tencent 里已有的同码词条把权重抬到不低于 5000，缺的加进 `cyime_terms`（已有的不重复加）。
2. **整句里同音字选错**（这片笔记、连这些、跳的一样大、把证据在校正一边）：Rime 组出的四条整句里没有正确的那条，词组模型只能在四条里挑。试过：备选 8 条，无改善；联合解码（joint_decoder）演示错词 25→30、个人整句 +26，但个人首字母 316→278、用户报过的 10→8、逐键 p95 +27%，不采用。这一类留给整句模型。
3. **单字/单词本身就有歧义**（他/它、提/题、无比/五笔、证据/整句、给予/基于），没有上下文时按常用程度排，不改。
4. **缺词**：明日方舟词库补「克莱门莎」，大模型英文词表补「Latent Space」。
