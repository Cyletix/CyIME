# 键盘调节控件宽度

2026-10-02。修复平板横屏固定键盘调节时，透明度条很短、四个按钮却横向拉满的问题。已随 1.4.0／20261042 覆盖安装平板，截图确认滑条和按钮组等宽、四个按钮限长，无明显裁切；用户验收待确认，后续比例修正见 [平板交付记录](keyboard-aspect-protection.md)。

原透明度面板先限宽 300dp，再取 78%，实际最多 234dp；操作按钮则各占整个控件区域的四分之一，两者使用了不同的宽度规则。

现在滑条和按钮共用居中的内容宽度：外层最多 560dp，左右各留 12dp，面板最多 536dp；按钮间距 8dp，各等宽且最多 128dp。窄面板按真实键盘框收缩，不使用屏幕方向猜测宽度；例如 280dp 键盘内，面板为 216dp，按钮各 48dp。叠加原控件区边距后，两侧至少保留 32dp，避开边框拖动热区。

控件高度、上下分布及固定／悬浮拖条位置沿用原实现。按钮文字是否显示同时考虑内容宽度和系统字号，空间不足只留图标及原无障碍描述。透明度范围、预览、确认／取消、恢复固定时归零等行为不变。

验证：26 项 `KeyboardResizeGeometryTest` 通过；应用及 Android 设备测试代码编译通过。现有控件布局检查增加平板全宽、半宽和两倍字体场景，检查滑条与按钮组等宽、按钮长度上限、边缘热区及上下裁切；这些设备用例仅编译、未运行，未执行整套尺寸门禁。日志：`.codex-artifacts/resize-controls-width-check.log`。
