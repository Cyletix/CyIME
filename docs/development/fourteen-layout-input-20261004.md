# 14 键底排与布局专属设置（2026-10-04）

## 范围与实现

用户要求 14 键的符号、数字、逗号和空格底排跟上 26 键，并支持左右滑动输入组内字母、开关及触发距离；布局专属设置应分层管理。

- 底排原先沿用 Legacy 权重；14 键与 26 键的外部留白和键缝还来自不同的参考列宽。现在内置拼音、小鹤双拼 14 键共用 26 键的物理框架、十单位参考列宽与 Standard 底排权重。字母仍按原 14 键分组排列，工具栏尺寸不变。文字、按压和玻璃外观沿用现有主题组件。
- 双字母键左滑输入左侧字母、右滑输入右侧字母，松手提交。点按保留合并键行为，单字母和功能键不参与。输入走实际 onKeyPress 编码回调，不把滑选当作符号直接上屏；Rime 仍使用当前 14 键方案，不切换语言或方案。该改动没有增加新的解码过滤器，也没有更改词库和排序规则。
- 左右滑选默认开启，触发距离默认 24 dp，可在 12–72 dp 间每档 2 dp 调整。存储值有限性、范围与档位统一校正。预览不提前输入；跨过阈值后回到原位或取消不补点按字符。上下滑动符号与长按菜单继续使用原分支。
- 开启时，双字母键在横向移动超过触摸容差后保留这次手势，防止较大的触发距离被整键盘光标手势提前接走；关闭后恢复既有处理。其他布局不启用此分支。

## 设置位置与兼容性

`布局与显示 → 各布局设置` 新增三个入口：

| 入口 | 项目 |
| --- | --- |
| 26 键 | 中文全拼邻键纠错、现有分体键盘开关、自定义布局的滑动符号编辑入口 |
| 14 键 | 左右滑动选字母、触发距离 |
| 九键与笔画 | 固定栏快捷符号，明确与常用符号键盘共享 |

空格、光标、符号输入方式、字号等保留在共通输入中。迁移设置位置不改既有存储键，不重置用户值。新增键为 `fourteen_letter_swipe` 和 `fourteen_letter_swipe_dp`，已接入设置变化监听。
