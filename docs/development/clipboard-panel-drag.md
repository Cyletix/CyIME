# 剪贴板跟手展开

2026-10-02。修复 TODO 中“任意工具栏上拉误开剪贴板、展开不跟手”。已随 **20261041** 覆盖安装平板，展开按钮已在当前半屏布局实测；拖动中间帧仍待核对。本轮未更新手机，最近确认手机版本为 20261039。交付见 [界面整理与平板复测](clipboard-expression-refresh.md)。

原实现把超过 32dp 的上拉绑定在整个候选／工具栏，直接打开图片页并切到最大高度。现在只有已经打开剪贴板时，标题和分类栏接受竖向拖动；快捷发送标题亦支持拖动。普通候选栏、图片预览和其他工具页不响应；图片预览的“更多图片”按钮打开统一剪贴板的图片筛选。

超过系统触摸容差后，面板按手指的屏幕坐标等距增减高度，避免 IME 窗口上移导致本地坐标反馈；松手按最近端点在 200ms 内展开或收起，取消回到原端点，动画可被后续拖动打断。离开剪贴板即还原高度；重新进入不沿用旧展开状态。列表本身仍负责滚动，页签仍可横向滚动和点击。

高度上限沿用可用空间的 72%，至少保留正常高度，并扣除系统栏、底部留白；悬浮时还扣除当前位置的底部距离及拖动条，维持底边和宽度，避免扩展时顶端裁切或左右一起变宽。平板当前横屏右侧半屏布局的展开按钮已实测，展开后保持原宽度，未见裁切；其他尺寸、竖屏、大字体及拖动中间帧仍待核对，未执行整套尺寸门禁。

验证：`ClipboardPanelExpansionTest` 9 项 JVM 检查通过，覆盖页面限定、固定／悬浮预留空间、双向跟手、越界返回、端点选择、取消、动画插值、动画中接手及清理。应用及 Android 设备测试代码编译通过；新增 `ClipboardPanelDragTest` 3 项设备用例只编译、未执行，覆盖移动工具栏、普通页禁用、列表滚动区域隔离、取消／重开和点击。原图片预览、网格、粘贴兼容测试保留，删除旧的“全局上拉打开图片”错误预期。
