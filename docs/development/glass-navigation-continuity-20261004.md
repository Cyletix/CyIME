# 玻璃键盘与系统导航区背景连续性（2026-10-04）

## 原因与修复

固定键盘主体与底部系统导航区原本分别调用 `keyboardBackground`，玻璃绘制各自根据局部宽高裁切背景并模糊。两处即使使用相同主题图片、模糊强度和透明度，也会取得不同的图像区域，接缝不能连续。

新增 `KeyboardBackdropHost`，在输入法窗口内为键盘内容、底部留白和系统导航区创建一份共同的背景缓存。各区域根据实际窗口位置绘制同一图像的对应部分，统一缩放、模糊和深浅色遮罩。背景范围以键盘底部为基准，不把调整尺寸时的全屏空白纳入取景。

根容器仅提供图像，不额外绘制背景，因此窄键盘两侧仍透明，原有键盘尺寸、底部留白、触摸区域和透明度处理不变。内嵌面板可使用相同取景；独立弹出窗口通过窗口根视图区分，避免使用错误坐标。

此修复接入固定、非物理键盘浮条、非圆角底部的玻璃键盘。悬浮键盘、物理键盘浮条及圆角底部模式原有的独立背景/导航区透明策略保留；非玻璃主题不受影响。本次统一的是已有主题背景的取景，不增加跨应用实时背景模糊。
