# 长按时长拆分与词库加载页（2026-10-12）

## 长按时长

- 原状态：本来就是两个设置，语言键 `language_menu_hold_seconds` 默认 0.2 秒；空格“移动光标”用 `cursor_hold_seconds` 默认 0.2 秒，空格的连续空格/语音固定 0.3 秒。
- 现在：语言键默认 0.1 秒（存储键改为 `language_key_hold_seconds`，旧值不沿用）；空格三种长按（移动光标、连续空格、语音）都按“空格长按触发”时长，默认 0.2 秒；设置页说明两者分开。
- 2026-10-13 调整：语言键默认改为 0.15 秒；读取新键 `language_key_hold_seconds_v2`，没有时沿用旧键，旧键等于旧默认 0.1 秒视为未改、换成 0.15 秒，其他值保留（旧 `save()` 会顺带写入全部字段，无法区分“存着的默认”和“手动选的 0.1”）。空格默认本就是 0.2 秒，未改。`HoldTimingSplitTest` 改为 0.12 秒未弹出、0.18 秒弹出；单元测试加迁移用例。未编译、未运行测试（等协调放行）。
- 验证：单元测试（默认值、保存读取）；模拟器 `HoldTimingSplitTest`：语言键 0.07 秒未弹出、0.13 秒弹出；空格 0.17 秒未触发、0.23 秒开始连续空格。

## 词库加载页

- 原因：键盘里本来有加载遮罩，但服务构建 `KeyboardUiState` 时从未传入 `isDeploying` / `deploymentMessage`，遮罩永远不出现；部署期间键盘照常显示、按键被丢弃，看起来像卡住。实体键盘浮条也没有提示。
- 慢在哪里：Rime 首次全量部署（日志 “Build directory missing or empty, running full deploy”）。模拟器全新安装两次分别约 21 秒、43 秒；与九键模型无关。加载逻辑未改。
- 现在：键盘区显示不透明加载页（“正在加载词库”、进度条、当前步骤、说明、切换输入法/收起）；实体键盘浮条候选区显示“词库加载中，完成后即可输入中文”。加载完成自动恢复。
- 验证：`DeployOverlaySurveyTest` 4 主题 × 深浅 × 玻璃 16 张截图；模拟器全新安装：浮条提示 → 打开屏幕键盘显示加载页 → 43 秒后自动恢复，nihao 可出中文候选。截图在 `.codex-artifacts/deploy-overlay-20261012/`。
