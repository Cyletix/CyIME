# 26 键展开候选侧栏自适应（2026-10-04）

## 修改

26 键展开候选仍走旧的固定尺寸分支：左栏 40–48 dp、右栏按钮 46 dp，没有使用主键盘的尺寸策略；九键已使用主键盘行列比例。

- 为实际使用的中英文 26 键及合并键布局接入主键盘的宽度、行高、间距和高度增长策略。左侧整栏及底部“候选”键对齐符号键；删除和回车分别使用主键盘对应按键的宽度，右栏四个按钮使用同样的行高。
- 根据当前实际键盘状态选择九键或字母键尺寸，避免英文键盘沿用所绑定中文九键布局的尺寸。读取实际按键行及分体状态；分体保留面板内边距、删除键错位和底行权重。
- 九键及字母键展开页的翻页按钮采用参考图中的圆角方块、上下箭头，随当前行高缩放，保留禁用状态及主题/玻璃底色。九键侧栏宽度、四行占位及现有选词行为保持不变。
- 未改变主键盘本身的尺寸、候选顺序、拼音显示策略及工具栏尺寸；主键盘仅补充分体删除/回车的测试标识。
