# 粘贴关面板、全角/半角文字（2026-10-12）

## 粘贴关掉方向盘（编辑）面板

- 原因 1（短信等应用）：有的应用粘贴后会重启输入会话（日志：`onStartInput restarting=true sameField=true page=Overlay`）。键盘收到“新会话开始”时一律把页面重置为主键盘，面板被关。现在会话开始时若仍开着面板就保留：真正换输入框或收起键盘时 `onFinishInput`/`onWindowHidden` 已先关掉面板，所以还开着说明是同一输入框重启（`KeyboardViewModel` 的 InputSessionStarted）。
- 原因 2（从面板打开剪贴板）：在编辑面板里点工具栏剪贴板，剪贴板替换了编辑面板；点条目粘贴后回到主键盘。现在从编辑面板打开剪贴板时记住它，粘贴、返回键或再点剪贴板图标都回到编辑面板（`leaveClipboard`，实体键盘的剪贴板操作也走它）。
- 验证（模拟器）：WebView 输入框与短信：面板粘贴按钮（短文本、多行长文本各数次）、剪贴板条目粘贴、应用自己的长按“粘贴”，面板都保持打开。修复前短信里第一次面板粘贴就回到主键盘，剪贴板粘贴在两处都回到主键盘。
- 另加两条调试日志：`onStartInput ... restarting= sameField= page=`、`onFinishInput page=`。

## 全角/半角显示

- 原因：菜单里这一项的文字用的是按钮固定名称“全角”，只有图标和高亮跟状态。现在按状态显示“全角”/“半角”（`stateLabel`）；按钮在自定义列表里的名称改为“全角/半角”。
- 验证：模拟器中文 26 键：菜单显示半角时逗号键输出半角“,”，切到全角后显示“全角”、输出“，”。日语键盘未在模拟器上验证（模拟器只启用了中文和英文）。
