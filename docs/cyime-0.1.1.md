# CyIME 0.1.1

本轮针对候选操作、拼音编辑、低性能设备和平板调节交互；沿用既有包标识和签名，可覆盖安装。内部版本码 20260929。

## 候选与拼音编辑

- “布局与显示 → 候选栏取消按钮”默认关闭；关闭后候选从左侧开始，不为箭头留空。开启可恢复原取消输入行为；剪贴板返回不受影响。
- 展开和收起候选采用同一圆形上箭头按钮，屏幕阅读器分别读出展开/返回动作。
- 拼音预编辑加大并提供真实点击区域；点击后可以在键盘内修改未上屏编码。完成应用到引擎，取消保留原输入，不写入宿主正文。九键、全拼、14键、小鹤保持各自编码语义。

## 默认性能与开销

气泡和键内炫光默认关闭，手动开启仍可用。不根据 CPU 型号猜测性能，也不运行启动基准测试。关闭气泡后普通按压不再更新全键盘预览状态或创建延迟清理协程；拂动和长按的必要选择提示仍保留。

开启光效时复用渐变着色器，动画仍在 480ms 内消失。详细调试日志默认关闭，关闭时不写 logcat/文件，九键每键日志不再构造诊断字符串；警告和错误仍记录。没有追加联想时跳过整页候选文本测量。未启用松手震动时提前返回，减少无效系统设置查询。

## 配色与空格

空格恢复普通按键颜色。新增可选固定主题 `858AdvanceColor`：普通键 `#525252`，Shift、符号、数字模式、语言、删除键 `#6D717C`，回车 `#3F4E68`，键盘背景 `#292929`，文字使用白色和灰色。该主题在浅色/深色系统中保持指定配色；默认主题仍为柔和蓝。回车使用独立颜色角色，主题预览和实际键盘共用。

## 平板和键盘调节

按键间隙按键盘实际宽高分别缩放，平板和宽屏不再沿用手机固定间距；同一键盘的普通键、宽空格和双格回车共用间距规则，触摸区域保留完整键位。悬浮键盘按实际卡片尺寸计算，不按整块屏幕放大。

26键默认完整；分体改为手动选择并保存。修复悬浮键盘在真实键帽缩放之后又按屏幕比例缩小字体的问题。主题取色统一完整调色板，避免旧全局颜色盖过所选主题；薰衣草紫补齐不透明的深色键帽配色。

调节时通过明确手柄区分高度与位置，中央区域不再拖出底部空白，尺寸与位置随手指连续预览。悬浮和分体按钮即时生效，确认保存，取消恢复。

- JVM 定向测试 31/31 通过：输入偏好、气泡、日志、拼音编辑缓冲、调色板、悬浮位移精度和间距规则。
- 原生九键测试 82/82 通过：既有撤回/缓冲，以及编辑后续输入和删除。
- 专用 Android API 36 模拟器去重 58/58 通过：真实输入法的拼音编辑、宿主文字保护、九键已选词、14键拂动、候选设置、主题升级、完整/分体/悬浮布局、调节保存/取消、底部恢复与导航栏避让。
- 像素与几何验证覆盖 1 倍/2 倍键盘尺寸、手机/平板、窄宽度和大字体；确认间隙比例、完整触摸区、不同键盘颜色角色，以及浅/深色系统中的 858 配色。截图已逐张检查。
- `assembleDebug` 与测试 APK 构建通过，`git diff --check` 通过。安装包保持既有覆盖签名；最终包的版本、提交号和内置词典校验记录保存在 `.gradle/cyime-011/final-artifact.json`。

这是定向回归结果，不是全部测试套件或低端真机性能基准；本轮只操作专用模拟器，没有操作用户手机。测试日志与截图保存在 `.gradle/cyime-011/`。
