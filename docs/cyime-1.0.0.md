# CyIME 1.0.0

CyIME 是基于 [Xime](https://github.com/ximeiorg/Xime) fork 的 Android 输入法，采用 Rime 输入引擎，由 Cyletix 维护开发，遵循 [GNU GPLv3](../LICENSE)。保留 Kor1（kingzcheung）、上游贡献者与第三方版权和许可声明。

[下载 1.0.0 安装包](https://github.com/Cyletix/CyIME/releases/tag/1.0.0) · [对应源代码](https://github.com/Cyletix/CyIME/tree/1.0.0)

## 本次更新

- 关于页将 Cyletix 维护者卡片放在链接区首位，与源代码、上游作者卡片保持一致的布局和点击区域。
- 首次使用校验内置中文词库部署产物；输入法独立启动即可准备默认模型，支持联网重试。
- 联想请求防抖、串行处理与过期结果丢弃，减轻连续输入时的推理负担。
- 编辑面板按最低高度固定圆盘与中央方键尺寸，四角文字保留安全边距；表情页去掉无插件时多余的顶部分类行。
- 全角／半角同步改变标点键帽、上滑提示和实际输出。
- 按视频恢复圆角方块光效、连续回弹与500ms淡出，光效仍默认关闭。

## 安装与兼容

版本名1.0.0，内部版本号20261010。保留应用包名和此前安装包的签名，支持已有 CyIME 用户覆盖升级。常见安卓手机和平板使用arm64-v8a；其他架构按设备选择。升级不要求卸载或清除词库与设置。

APK、SHA256校验文件及对应源码在同一个Release提供。离线语音、手写模型首次使用仍需下载；基础中文词库随包提供。

## 验证与边界

此前已完成首次安装词库与默认模型、联想队列、编辑布局、表情和全半角真实输入验证；方块光效3项JVM和9项Android定向检查通过。1.0.0额外检查关于页、版本号、签名、内置资源及发布产物。

低端手机的实际速度与手写、语音识别准确率仍受设备和模型影响，不将本次发布描述为这些问题全部解决。
