# CyIME 1.5.0

本批增加物理键盘交互能力，版本由未发布的 1.4.1 调整为 1.5.0，versionCode 20261057。普通版与内置模型版使用同一源码、应用身份和签名，支持保留数据覆盖升级。

## 更新

- 物理键盘浮条支持整块拖动、侧边竖条、底部候选长条与蓝色吸附提示；松手平滑过渡，浮窗跟随主题及玻璃透明度。
- 拼音框独立并随内容宽度伸缩，候选保持单行；支持 −/=、[/]、逗号/句号（含 </>）翻页，回车提交原始编码、空格确认候选。
- 地球键点按切换语言、长按选择；物理键盘设置支持 Ctrl+空格、轻按 Shift 独立开关及跟随、避让、停靠选项。
- Ctrl+. 切换中英文标点；Alt+V 开关剪贴板，首项高亮、方向键选择、回车粘贴关闭、Esc 取消；Alt+H 开关语音。英文模式沿用固定半角标点。
- 输入方案菜单按当前语言展示左侧布局、右侧实际方案，跟随当前组合；语言管理继续保留独立的语言、方案与布局概念。
- 修复剪贴板打开时工具栏不可见的问题。
- 全屏手写仅扩大书写区，底部候选、标点及功能键保留用户设定的键盘宽度和左右位置。

## 安装包

- 普通版 `CyIME-1.5.0-arm64-v8a.apk`：模型按需准备。
- 老人包 `CyIME-1.5.0-full-arm64-v8a.apk`：内置中文手写、small/base 联想、Zipformer 中文语音和 SenseVoice 多语语音，首次使用仍需解包初始化。

两版均为 ARM64，覆盖升级保留设置、词库及剪贴板数据。不会替用户重置全部配置。

## 已知限制

三星笔记的物理键盘光标跟随仍未解决，应用没有提供有效位置时会回退定位；不宣称所有应用均可跟随。玻璃使用主题背景模糊和透明材质，不是其他应用画面的实时模糊。实际外接键盘、录音及图片粘贴仍需按设备验收；完整尺寸门禁按项目约定暂停。
