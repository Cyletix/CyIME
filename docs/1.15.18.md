# CyIME 1.15.18

两个 ARM64 安装包源码相同，只差带不带离线模型：

- **轻量版** `CyIME-1.15.18-arm64-v8a.apk`：不内置语音、手写、联想模型，需要时在「扩展 › 模型」下载。
- **完整版** `CyIME-1.15.18-full-arm64-v8a.apk`：内置 SenseVoice 语音、手写、声纹、联想模型和公开九键词组模型，装上即可离线使用。

可以直接覆盖安装 1.15.17 或更早的版本，保留配置和已下载的模型。装了 1.15.17 的可以在「设置 › 关于 › 检查更新」里直接更新。

**默认关闭、需要自己打开的新功能**：仓颉速成、开车连续语音。

## 新功能

- **按设备推荐配置**：先问你怎么打中文（全拼、哪一种双拼、五笔）和分不清的读音（平翘舌、n/l、前后鼻音、f/h），按回答切方案、把用不到的双拼从方案栏藏起来、下载五笔、打开对应的模糊音；字幕一题写清它是什么、会在桌面加「字幕」图标。
- **性能与省电**：档位上方加 0～100 分的刻度条，标出低配、中配、高配和你现在的位置；「自定义」一直列在档位里。和「按设备推荐配置」用同一套高配／中配／低配叫法，两页互相有入口。
- **我的图片**：选图后先调整位置和大小（拖动、双指缩放、四边吸附，铺满或上下、左右对齐留白），之后还能再调整或删除。
- **手写**：中文手写候选旁显示读音（带声调）。
- **仓颉速成**（默认不启用），仓颉繁简转成同一个字时不再出两次。
- **开车连续语音**（默认关）：悬浮条发送或离开输入框后，回到同一个应用自动接着听。
- **长句纠错**：长句开头也做邻键纠错，夹在中间按错的单个字母当打错处理（正确拼写的结果不变）。
- **日语九键**：左右键在读音里移光标，候选只给光标前那段，选完剩下的接着打。
- **九键**：「上一项」「下一项」到头就停，不再从首选跳到队尾；拼音注释下也能从「下一项」拖到候选选词，拖动距离可以调。
- **候选栏取消按钮**默认打开，设置里有图例说明它在哪。
- **关于 › 鸣谢**：列出上游、引擎、词库、模型和设计参考，点一项打开主页。
- 智能联想模型改叫「完整」「轻量」，写清该选哪个；九键语法增强不再提供下载（九键词组模型更准更小，已下载的照旧可用）。
- 布局栏默认顺序：假名九键紧跟 26 键，Colemak、Typewise 等字母排列排到最后。

## 修正

- 固定键盘左边那条 1px 的缝没了（屏幕宽度不是整数 dp 的机型才有）。
- 「填满留空处」两侧和键盘拼成一整条，同色、没有圆角台阶。
- 玻璃效果下候选字不再描一圈边，需要托底时是每个词后面一块软边的底。
- 设置已经打开时，输入方式面板的「方案管理」、缺手写模型时的跳转、插件联网授权都能跳到对应页面。
- 「语音转文本」关掉后，屏幕键盘的麦克风和按住空格说话也不再开麦。
- 语言键「指定语言与英文切换」能选西班牙语等所有已装语言。
- 西班牙语开着「长按输入」角标时，长按元音和 n 仍能打出 á é í ó ú ü ñ。
- 仓颉下工具栏和菜单里的「繁体」按钮也在。
- 设置各入口的说明和页里实际内容对齐；暂时不起作用的设置写明原因；智能联想关着时不显示「选择模型」。
- 用户自己切成悬浮键盘后，横竖屏各自记住，不会被默认的固定改回去。
