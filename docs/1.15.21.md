# CyIME 1.15.21

两个 ARM64 安装包源码相同，只差带不带离线模型：

- **轻量版** `CyIME-1.15.21-arm64-v8a.apk`：不内置语音、手写、联想模型，需要时在「扩展 › 模型」下载。
- **完整版** `CyIME-1.15.21-full-arm64-v8a.apk`：内置 SenseVoice 语音、手写、声纹、联想模型和公开九键词组模型，装上即可离线使用。

可以直接覆盖安装 1.15.17 或更早的版本，保留配置和已下载的模型。装了 1.15.17 的可以在「设置 › 关于 › 检查更新」里直接更新。

**这一版加的新开关全部默认关，更新后键盘的样子和用法不变**，想用的到设置里打开：时间日期候选、候选里显示表情、英文选词后自动加空格、字母键显示大写、加宽按键、分体键盘右半边也放 G、Z X C V 角标做撤销/剪切/复制/粘贴、底部留白滑动移光标、打字中清空整个输入框、退格直接删（不先关联想）、联想关闭键放右边、候选间距加宽、模糊音也用于双拼、双拼键位提示、仓颉速成、开车连续语音、中文滑行输入。

## 修正

- **上下角标回来了**：1.15.17 里开着滑行输入（英文）的人，中文 26 键的上下角标会消失、中文也跟着滑行。现在角标照常显示，中文滑行是单独的开关，默认关。
- **打字更跟手**：长按空格滑动移光标不再越拖越慢；九键在 B 站这类忙的应用里打字，不再每个词等宿主应用三次。
- vivo 等机型手势导航下，键盘底部不再盖住系统的切换输入法按钮。
- 固定键盘左边那条 1px 的缝没了。
- 上滑清空超过 26 万字的长文也能一次清完，撤回原样放回。
- 设置已经打开时，输入方式面板的「方案管理」等跳转能到对应页面。
- 「语音转文本」关掉后，屏幕键盘的麦克风和按住空格说话也不再开麦。
- 西班牙语开着「长按输入」角标时，长按元音和 n 仍能打出 á é í ó ú ü ñ；语言键「指定语言与英文切换」能选西班牙语。
- 玻璃效果下候选字不再描一圈边，需要时是每个词后面一块软边的底。
- 长句开头也做邻键纠错。
- 导入较新的搜狗细胞词库（.scel）不再失败。

## 新功能

- **按设备推荐配置**：先问你怎么打中文（全拼、双拼哪一种、五笔）和分不清的读音，按回答设好方案和模糊音；字幕一题写清它是什么。vivo / OriginOS 上第 3 步直接去系统设置选默认输入法。
- **性能与省电**：0～100 分的刻度条标出低配、中配、高配和你现在的位置。
- **我的图片**：选图后能调整位置和大小，之后还能再调整或删除。
- **无痕模式**：从键盘上打开前先确认；开着时剪贴板顶上写明新复制的内容不会记进来。
- **手写**：中文手写候选旁显示读音。
- **日语九键**：左右键在读音里移光标，选完剩下的接着打。
- **九键**：「上一项」「下一项」到头就停；拼音注释下也能从「下一项」拖到候选选词，拖动距离可调。
- 候选栏取消按钮默认显示，设置里有图例。
- 设置 › 按键与手势 最下面加「按键技巧」页，讲 Shift、!@#（当 Ctrl 用）、九键、空格和删除键的隐藏操作。
- 关于 › 鸣谢：列出上游、引擎、词库、模型和设计参考。
- 编码显示在输入框时，候选栏上方不再另起一个拼音气泡。
