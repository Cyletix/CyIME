# CyIME 1.6.1

修正物理键盘候选与智能联想的选词状态，保留正常空格和回车输入。

- 智能联想使用数字键或点击选择；空格正常输入，回车执行原有动作，删除先关闭联想，继续输入会清除旧提示。
- 回车提交原始编码时不再带入拼音显示用的分词空格。
- 触屏和物理键盘共用联想提交逻辑，宿主拒绝提交时保留状态，取消后的迟到结果不再回填。
- 修正模型候选分数换算，并优先使用更完整的上下文；不承诺 Android 与 Windows 候选一致。

轻量版通过现有入口下载模型；内置模型版包含手写、两份联想模型及 Paraformer＋SenseVoice。两版沿用发布签名，支持保留数据覆盖安装。

相关 68 项单元测试通过；实际输入交互未验收。
