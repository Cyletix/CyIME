# 工具栏位置、返回入口与方案排序（2026-09-23）

## 原因与修正

- 手写使工具栏移动：原来的 Logo 占32dp，手写返回占40dp。现在左侧 Logo/返回与右侧收起统一占40dp，圆形底板32dp，切换内容不改变各工具按钮的坐标。收起键增加始终可见的底板和描边。
- 返回重复：方案选择既在工具栏放返回，又在面板内部放返回；编辑还保留独立顶行和左下返回。现在方案、表情、编辑、剪贴板只使用工具栏左侧的返回。点击选中的工具图标同样关闭面板；从工具栏直接打开方案选择后，返回直接回键盘。
- 编辑布局保留中央九宫格的功能位置、四方向键和四角按键样式，右侧上方仍是退格，其下是回车。删除的是重复返回入口，不重新安排编辑功能。
- 符号保持原底栏顺序，左侧返回和“最近使用”等分类统一为40dp高、8dp圆角。符号页没有再增加工具栏返回，因此也没有两个返回箭头。
- 表情与调节重叠：工具栏调节入口以前直接打开调节层，未关闭当前覆盖面板。现在视图和服务入口都会先关闭面板，再打开调节；正常键盘作为调节预览。
- 语言键长按从0.3秒改为0.2秒，上滑仍禁用。

## 调整顺序

输入模式：工具栏“方案选择” → “调整顺序” → 长按拖动方案行 → “完成”。也可使用每行上下按钮。松手即保存，重新打开和重启输入法后沿用；工具栏方案选择与语言键长按菜单使用同一顺序。英文可以调整位置，始终可用，不会被删除或禁用。排序独立于市场方案的启用、下载和部署。

工具栏图标本身仍为长按2秒后拖动，松手保存。
