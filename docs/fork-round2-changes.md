# 第二轮：手机验收反馈与日语输入

基于第一轮已验收版本继续修改，保留插件市场、模型中心和 Rime 方案机制。

## 本轮行为

| 项目 | 修改 |
| --- | --- |
| 悬浮键盘高度 | 浮动内容不再重复缩放行高，不套用普通模式底部留白；数字角标限制在键面内，修复未指定字号导致“符号”极小。 |
| 悬浮拖动 | 拖条改为底部 28dp 的一行，并加长；恢复普通模式后清除浮动窗体残留高度。横竖屏高度读写一致，拖动范围与实际窗口尺寸一致。 |
| 贴边预览 | 边框在约 0.5 秒内渐显并扩展到恢复位置，松手确认；离边立即取消，重新贴边重新计时，取消拖动不恢复。 |
| 键盘调节 | 中间增加透明度，底部左重置、右确认；返回退出取消未保存预览。 |
| 工具栏 | 默认依次为方案选择、表情、编辑、剪贴板、手写、语音；点击沿用按键音效/震动开关，圆形按压背景释放后约 0.3 秒渐退。 |
| 编辑选择 | 保留锚点与活动端，兼容宿主返回正序范围；反向连续扩选、段首尾扩选、取消后折叠选区。不支持标准折叠接口的宿主，在确认存在选区后使用方向键取消。 |
| 编辑布局 | 正方形九宫格：首/上/尾、左/选择/右、复制/下/粘贴，其余动作沿两侧排列。 |
| 手写 | 工具栏切入真正的手写方案；右侧自上而下为删除、逗号、句号、回车，共用原版 ochwpro 模型。 |
| 空格与语言 | 删除“长按滑动光标”文字，居中空格图标；拼音九键简称拼音；语言菜单长按改 300ms，并删去提示标题。 |
| 剪贴板预览 | 左侧返回工具栏，中间胶囊包裹复制内容，右侧列表入口；关闭预览不删除剪贴板数据。 |
| 符号导航 | 按提供截图的现有入口统一在左下返回，“最近使用”紧接其右，常用符号页右下保留回车。 |
| 默认主题 | 动态配色 + 深色模式，保留用户显式保存的主题选择。 |
| 默认模型 | 首次打开应用后自动准备 ochwpro 和 Zipformer；与原版模型中心共用索引、文件目录、版本和进度。已安装的不重复下载，完成后由用户删除的模型不自动补回。 |
| 日语 | 内置“日语26键”和“日语九宫格”，使用同一套成熟的 jaroomaji 罗马音转换与词库，接入原有候选、选词与 Rime 学习；回车沿用日语方案的假名读音提交规则。 |

符号方向说明：原描述同时要求“右下”和“最近使用向右排列”，与截图中的左下入口不同。本轮暂按截图实现左下对齐；如后续确认右下，再同步移动入口及返回。

## 模型与原版兼容

模型来源仍为配置中的 Xime 市场索引，默认 ID 为 `ochwpro`、`zipformer-zh-int8`。
下载在临时目录进行，并使用索引提供的大小及 SHA-256 校验；完整后才替换目标目录，下载失败不覆盖正在使用的旧模型。
已有语音插件和明确设置的语音后端保留；尚未选择后端的新用户在默认语音模型准备完成后启用本地识别。

日语资产独立于原版 `assets/rime` 子模块分发，不修改该子模块。首次升级仅追加两个日语方案一次；之后可自行禁用，市场更新的同名 jaroomaji 文件保留。

## 上游来源

- [rime-jaroomaji](https://github.com/lazyfoxchan/rime-jaroomaji/tree/3e14573828668721ec1eabdc56546ddcca8277e2)：固定提交，原始文件和独立词典许可均保留在 `app/src/main/assets/rime_japanese/`。两个 Xime 方案修改名称、ID 和默认日语状态，并补充九宫格滑动需要的日文括号映射。
- [Xime 模型索引](https://github.com/ximeiorg/xime-index/blob/main/models/index.yaml)：复用原版模型中心的兼容元数据。
