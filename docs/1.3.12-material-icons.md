# 1.3.12：共享材质与图标

本轮范围：四组视觉样式的材质重做、确定性的图标生成器、键盘标志和桌面图标、图标设置与同步开关。不变更 Rime 主题含义，不改输入行为和触摸布局。

## 使用

设置 → 主题与定制 → 图标设置。

- 默认开启“同步图标与视觉样式”，在任一入口选择即同步另一处。
- 关闭同步，保留当前显示的图标，之后图标和键盘可独立选择。
- 再次开启同步，以当前键盘视觉样式为准。
- 原有图标可随时恢复。同步开启时恢复原图标也恢复原有外观；关闭时仅恢复图标。
- 图标设置同时作用于键盘左上角标志与桌面应用入口。

## 实现

`CyMaterials` 定义本体色、反射、厚度、内亮边、镜面边、静态柔光和环境光。`MaterialPaint` 用缓存的路径与画刷渲染，图标生成器和组件共用它。玻璃键帽使用半透明底色；键盘整体背景保持不透明。按压动画与静态材质分开，不捕获宿主背景，不使用实时模糊。

`CyimeIconGenerator.render(style, pixels, adaptiveForeground)` 是可调用的生成入口。几何固定为四个开放折叠单元，材质来自同一份配方。桌面资源通过测试导出器从此生产代码生成，不能另外手调 PNG 冒充同源。

桌面采用 Android 的 [activity-alias](https://developer.android.com/guide/topics/manifest/activity-alias-element)。主 Activity 始终启用；Android 13 及以上使用批量切换，较早版本先启用目标图标再关闭其余图标。系统设置里的应用图标和启动器已有缓存由系统管理，并非任意运行时位图替换。
