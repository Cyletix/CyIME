# 1.2.10 Debug：回车与编辑方向盘

- 回车在输入队列执行时读取引擎原始编码，不再仅凭候选 UI 的 isComposing 决定是否换行。存在编码时只提交编码；宿主拒绝提交时保留组合状态。中文模式下尚在确认的直接英文输入只结束确认，不额外换行。空闲回车仍执行宿主声明的动作。
- 编辑方向盘按实际面板宽高计算直径，移除最低键盘高度的固定上限。保留圆形、中心选择键、扇形点击区域和四角辅助按钮的避让。
- 回归覆盖真实 IME 中字母确认、再次回车换行、引擎输入先于 UI 更新，以及三组面板尺寸下方向盘缩放和按钮避让。

用户报告的偶发原现场尚未复现；回归通过不能代替原宿主和实体平板验收。本轮不发布正式 Release。

验证：Debug 与 AndroidTest APK 构建成功；模拟器 5 项仪器测试通过（4 项编辑面板、1 项真实 IME 输入流程）。后者验证首次回车仅提交 hello、第二次换行、未发布候选 UI 的 world 正确提交，以及普通/展开态退格和上滑清空不删正文。已覆盖安装模拟器，实体设备未连接、未验收。

## 展开候选的回车、删除一致性

展开页回车原先使用自定义 RailKey，缺少普通按键的按下/松开反馈，删除也只有提交时的通用震动。现在回车复用 ActionKeyButton、删除复用 SwipeableIconKeyButton，接入相同的 onKeyPressDown/onKeyRelease，并使用相同的主题颜色、圆角、阴影和内边距；取消重复的通用震动。回车图标跟随宿主动作，删除支持连续退格与清空/撤回手势。

本轮 5 项设备回归通过：反馈入口计数、最小高度等高可见、展开与手写长按删除、字母边缘热区，以及真实 IME 展开回车只提交原始字母的流程。仅验证反馈回调连通，实际硬件声音和震感未验收。
