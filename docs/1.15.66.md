# CyIME 1.15.66

从 1.15.63、1.15.65 直接覆盖安装即可，词库和设置都会保留。

**回车发送**

- 新增「回车发送」开关，位置：设置 › 键盘布局 › 布局与符号 ›「回车发送」，默认关闭。
  - 打开后，应用自己把回车设成发送的输入框（比如微信开了「回车键发送消息」），按回车直接发送，回车键面也显示「发送」。
  - 关着时回车换行，发送用 Ctrl+回车。
  - 应用没设回车发送的输入框，开关开不开都换行。Shift+回车总是换行，终端和搜索框不受影响。
- Ctrl+回车在 Claude 这类没接「发送」动作的输入框里也能发出去：先执行发送，应用没反应时补一次回车键；应用把回车当成换行的，多出来的换行会自动删掉。

**注音**

- 切到注音时始终出正体字，國 不再出成 国（#182）。
