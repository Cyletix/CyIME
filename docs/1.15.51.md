# CyIME 1.15.51

从 1.15.47 直接覆盖安装即可，词库和设置都会保留。

**修复**

- 开着语音时点输入框以外的地方，不会再把焦点拉回输入框。
- 在「语言与方案」里关掉一种语言，或在「已安装的方案」里关掉一个方案，设置页不再闪退。
- 剪贴板「添加图片」选完回到原来的输入框，不再跳到设置页。在短信里点链接、电话的「复制」也能进剪贴板。
- 装回旧版本时不再闪退。本地备份会带上导入的词库。
- 编辑面板的回车键跟着输入框变：搜索框里显示搜索，发送框里显示发送。
- 「已经用得很爽了」不再打成「用的很」。

**日语**

- 新增长音键 ー。默认就在 L 键上，也可以设成 L 右边单独一个键，或者放在 Shift 键上（按住仍是 Shift）。
- 词典加入更多人名、地名，比如「暁山」。

**语音和插件**

- 在线语音改回内置：在「设置 › 语音转文本」里直接填接口和密钥，不用再装插件。装过插件的，接口会自动搬过来。
- AI 改写、AI 回复装好就出现在键盘菜单里。AI 翻译已经合进 AI 改写。插件面板里的「设置」直接打开设置页。
- 插件市场不再列出已经内置的插件。
- 日语语音模型国内可以从魔搭下载。

**键盘和设置**

- 候选栏：最右边只留展开按钮，联想时关闭键在左边，只有空闲时才显示收起键盘。
- 液态玻璃在「我的图片」背景下也会折射图片（Android 13 及以上，默认关）。浅色玻璃自己拖过透明度后，工具栏和面板会跟着滑条变。
- 调节键盘时，描边和滑条带主题颜色；拖透明度时只留滑条；按返回就取消这次调节。
- 设置页的图例按真实键盘配色画，浅色主题下不再是白底白键。
- 开关下面的「性能代价」改叫「性能开销」，开销小到可以忽略的开关不再显示这一行。说明文字统一用英文括号。
- 新增「数字出短语」（默认关）：打的数字和「我的短语」的编码对上时，候选里给出短语。
- 设置 › 手写 › 改进手写里可以贡献手写样本，帮助改进手写识别。

两个 ARM64 安装包共用安装序号 `20261403`。

- **轻量版** `CyIME-1.15.51-arm64-v8a.apk`。语音、手写和联想模型可以在「扩展 › 模型」里按需下载。
- **完整版** `CyIME-1.15.51-full-arm64-v8a.apk`。内置离线语音、手写、声纹、基础联想和公开九键模型。
