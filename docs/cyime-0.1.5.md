# CyIME 0.1.5

版本号 0.1.5，内部版本号 20261003。可覆盖现有 CyIME 安装。

## 本次修复

- 菜单第一项为键盘调节，第二项为设置。删除剪贴板、表情、输入方案的重复入口；方案开关集中在输入选项，显示当前状态，切换后不退出。
- 键盘背景、按键、工具栏合成后统一应用透明度。固定模式不再叠画一整层背景，调节按钮不受透明度影响。
- 切换方案后对新建的实际 Rime Schema 重新应用每页候选数，避免弱缓存中的设置丢失后退回五候选。
- 对照原 Xime 提交 9452b161：恢复 4dp 圆角、62% 不透明度、12sp、8dp/3dp 内边距的拼音浮层；背景取当前主题普通键色。
- 点击后仍在原键盘上方编辑，编辑条总高 44dp，与工具栏相同；不新增字母面板或操作键。编辑条使用相同的半透明主题背景，文字 18sp，上下各留 6dp。
- 编辑时长按空格滑动移动拼音光标，不移动宿主光标；上下移动至单行拼音首尾。删空编码或上屏后关闭编辑条。
- 图标按键在重组后使用当前手势回调；九键输入/删除在后台等待引擎锁并原子刷新，避免竞争时丢键。
- 九键编辑保留原数字键歧义，通过引擎解析出的读音显示字母和分词；显示偏移映射回实际编码，不把选定字母改成猜测的其他字母。
- 候选箭头从向上逆时针旋转至向下，收起时原路返回，保留动画。
- 26/14 键底行缩窄符号和数字入口、扩大空格，使空格居中；数字和符号页的返回槽位同步。日语九宫格、笔画、手写、分体保留原比例。
- 上滑数字和符号移到键帽右上角，主字母略向下移。
- 英文强制半角，返回中文时恢复用户明确保存的中文字符宽度。菜单将该设置标明为中文字符宽度。
- 标点直接上屏，不弹标点候选；在途联想在标点/空白后失效，不再填回候选栏。保留拼音内部单引号分词及数字面板计算器行为。

## 验证

- `assembleDebug` 与 Android 测试 APK 构建通过。
- 定向 JVM 测试 7/7 通过：拼音显示偏移与标点/联想边界。
- 最终 Android 回归 43/43 通过：真实 IME 6、引擎 10、图标手势 2、菜单 1、候选栏 6、编辑条 1、布局切换 12、透明度与调节 5。日志位于 `.gradle/cyime-015/final-input.log` 和 `final-ui.log`。
- 透明度回归对整幅键盘逐像素校验合成结果，并检查调节控件保持不透明。真实 IME 检查宿主文字与光标不被拼音编辑改动、删空关闭、标点立即提交、九键修改后继续输入与删除。
- 全量 JVM 首轮 798 项中 796 项通过；`InputModesTest` 自定义排序、`KeyboardMergedLayoutTest` 方案识别两项既有失败仍在，未计入通过。两项在 0.1.2 已记录。
- 九键“打开后原样赋值”属于未修改，保留原撤回规则；编辑回归使用实际修改后再继续输入/删除，不把只移动光标当作重建编码。
- 使用专用 Android 模拟器；恢复触屏测试配置后验证通过，未操作个人手机。

本次没有对词库或语音模型再次改动。需要继续用用户设备检查低端性能及具体系统窗口合成效果。
