# CyIME 1.3.12

## 视觉样式与图标

- 重做霓光描边、流光玻璃、柔光折面和浅色磨砂四组材质，加入厚度、反射、内亮边和静态柔光；保留原有外观入口。
- 新增“图标设置”，同时适配键盘左上角标志和桌面应用图标。
- 默认同步图标与视觉样式；关闭后可分别设置，再开启时采用当前键盘样式。
- 图标和键盘组件共用材质参数及渲染器；提供可调用的图标生成入口和资源导出脚本。
- 视觉样式与原有 Rime 主题保持不同含义；材质不使用实时背景模糊，不改变按键触摸区域。

## 安装

使用原应用 ID 与正式签名，支持覆盖升级，请勿卸载旧版。一般手机和平板选择 `arm64-v8a`，不确定架构可选择 `universal`。

设置入口：**设置 → 主题与定制 → 图标设置**。桌面图标由系统启动器刷新，切换后可能稍有延迟。

## 验证范围

2 项视觉配色单测、6 项模拟器测试通过，覆盖绑定、桌面入口、设置导航、图标资源和键盘操作。五个 Release 包的版本、签名及非 Debug 标记核验通过，模拟器覆盖安装与冷启动通过。手机、平板真机效果未验收；本次不宣称整体输入性能提升。
