# CyIME 1.1.5

正式版，versionCode 20261015。保持 com.cyletix.cyime 及原发布签名，可覆盖安装并保留数据。

- 菜单切换项统一显示当前状态：浅色模式、深色模式、跟随系统；全角/半角改用同风格宽度图标，文字仍明确标识当前状态。
- 菜单按常用调节、状态切换、工具和维护排序。
- 悬浮宽度下限按可用宽度调整：手机通常约260dp，大屏保留400dp基准；放宽高度调节上限，保留边框分方向调节、默认尺寸算法和高宽比保护。
- 上下光标操作统一使用当前输入框内的选区移动，避免系统方向键导致焦点跳到其他控件。宿主不支持文本读取或选区调整时停止移动；不暴露视觉折行信息时按显式换行/段首段尾移动，无法保证逐视觉行定位。
- 语言菜单拖动越界保留选择，上下停在边缘选项，横向移出保留最后选择。
- 新增底部圆角与透明导航栏设置；默认直角和键盘同色导航栏。导航图标仅按系统能力匹配深浅，圆角模式跟随系统明暗及对比度保护。
- 打包脚本归档历史包、区分debug文件名；安装脚本覆盖当前版本，取消自动卸载。

版本规则：本地小改递增末位PATCH；对外正式发包递增中间位MINOR，保留末位；versionCode独立递增。

验证：完整JVM单元测试912项通过，仪器测试源码编译通过。

验证限制：本次未对第三方应用进行完整真机验收，导航栏外观受系统实现影响。
