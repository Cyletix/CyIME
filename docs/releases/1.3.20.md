# CyIME 1.3.20

本版汇总 1.3.12 之后的界面、语言与初始设置改动，并补齐键盘菜单的常用设置入口。

## 界面与操作

- 剪贴板提示胶囊按内容长度布局，长内容可滚动；清空确认操作适配低高度和大字号。
- 语言管理与键盘布局排序共享保存结果，支持长按拖动，并保留未启用项目的位置。
- 图标设置使用与其他设置页一致的分区结构；键盘工具栏标志跟随键盘字色，视觉材质不再覆盖用户主题颜色。
- 手写从剪贴板、编辑等工具页进入后，关闭时回到原来的键盘，不再意外重开工具页。
- 语音转文本统一模型选择和下载卡片；设置页在窄屏、大字号下保持可滚动和可操作。
- 方向盘随实际面板尺寸调整；四角文字保留最小边距，空间不足时缩小圆盘，避免挤到边缘。
- 尺寸调节的透明度滑条、控件与确认按钮保持对比度和边界；窄键盘两侧保持透明。
- 键盘菜单增加“主题与定制、智能联想、语音转文本、模型管理”直达入口。低高度下分页显示，所有设置仍可从完整设置页访问。

## 初始设置与安装包

- 默认启用智能联想、本地语音和单次联想；已保存的个人设置不被覆盖。
- 基础中文输入方案自动准备，实验布局按需启用；语言管理支持添加其他语言。
- 普通版与内置模型版分别提供。内置模型版包含 Paraformer、SenseVoice、Base 联想及手写模型；是否默认启用语音二次修正依据设备配置判断，不含 Zipformer 和 Small 联想模型。
- 保持原应用 ID 和签名，可覆盖安装；一般手机、平板选择 `arm64-v8a`。

## 验证边界

发包门禁覆盖胶囊、候选、菜单、语言排序、语音与图标设置、手写返回、方向盘和尺寸调节。普通版与内置模型版分别执行检查。测试结果随构建保存；手机、平板真机效果仍需验收，不将模拟器检查当作全部使用场景的保证。
