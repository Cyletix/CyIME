# CyIME 1.2.9

## 输入与性能

- 修复输入任务顺序、跨输入框旧任务和过期候选选择问题；提交被宿主拒绝时保留待处理文字。
- 修复九键部分选词撤销误操作用户词库、退格及长按删除的顺序和停止行为。
- 优化九键长串输入的词典搜索、前缀复用和组句搜索，关闭默认原生逐键诊断日志。
- 改善26键边缘触摸，接入按实际布局计算的相邻键纠错、中英文混输和光标手势选项。

## 语音、布局与剪贴板

- 修复持续语音在手动编辑后因旧前缀修订而持续不上屏的问题；保留手动编辑内容。
- 自定义布局的元音、改位字母强调开关同时控制文字和底色，保存后刷新；强调配色跟随主题。
- 剪贴板拆词使用已安装中文词库及词频；选词和取消仅修改面板，右上角“确定”才一次上屏。
- 扩大拆词内容区域和词块，将“添加到快捷发送”放在顶栏中部。

## 插件

- 修复插件启停状态、执行超时、事件顺序与故障状态处理，并更新打字统计事件协议。

## 安装与验证说明

- 使用原应用 ID 和发布签名，支持覆盖升级，保留已有数据；不要卸载旧版。
- 一般手机、平板选 `arm64-v8a`，不确定架构可选 `universal`。
- 开发阶段已完成 JVM 和模拟器的针对性回归；模拟器引擎延迟不等于真机整体帧率。当前未连接物理设备，手机、平板上的交互和语音尚未全面验收。
- 语音发生无法可靠划分的新旧前缀修订时，该次结果保守跳过，后续继续追加；不以覆盖手动文字的方式猜测修订。
