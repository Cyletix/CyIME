# CyIME 1.0.4

正式版，版本号 1.0.4，版本代码 20261013。沿用 com.cyletix.cyime 和既有发布签名，可保留词库、设置及用户数据覆盖升级，无需卸载。

## 输入与符号

- 日语全角状态下，空格输出全角空格 U+3000，数字及数字面板小数点同步使用全角；半角状态恢复半角输出。
- 符号页“英”分类保留所选符号原样显示、原样输入，不再被中文全角设置改写。
- 自定义符号在九键侧栏、笔画侧栏和自定义符号栏保持原字符：半角 `-` 不再变成全角 `－`，自定义全角字符也不被改成半角。
- 九键拼音侧栏统一单字母与多字母音节的行高和字号，并按实际面板尺寸适配。
- 日语26键替换重复的上滑符号。

## 布局与导航

- 固定和悬浮键盘共用228dp最低面板高度；修正窄键盘的尺寸、圆角和透明侧边，补齐底部导航区域背景。
- 修正工具栏占用高度的计算及设置页输入框避让，减少工具栏遮挡和侧边黑块。
- 工具栏两端对齐，移除横屏额外缩进；菜单和输入模式卡片限制宽高，避免拉成长条。
- 语言菜单文字居中，右边缘优先对齐语言键，并限制在实际键盘面板内；空间不足时内部滚动。
- 调整符号面板底栏高度、手写功能键比例和编辑方向盘光效。
- 支持语言排序；默认中文26键在九键之前，保留用户已有排序。

## 首次使用

- 默认启用并自动部署中文26键和九键，其他方案由用户选择。
- 修正初始化过程中方案列表提前读取导致只剩英文的问题；升级时保留用户自定义配置。

## 安装

一般手机和平板下载 arm64-v8a；不确定架构时下载 universal。另提供 armeabi-v7a、x86 和 x86_64，以及 SHA256SUMS.txt。

## 验证范围与待办

- 已进行相关单元测试、连接平板上的语言菜单与尺寸回归，以及日语空格/数字的实际输入连接测试；自定义半角横线已在原应用全角状态下核对为 U+002D。
- 手机尺寸使用渲染测试，未覆盖所有手机真机及银行等第三方网页。
- 中文9键/14键和“英”符号分类的完整组合自动验收仍有测试切换/服务生命周期阻塞，不能据此声称所有组合已验收。
- 数字0键扩展常用符号仍待规划，本版未实现。
