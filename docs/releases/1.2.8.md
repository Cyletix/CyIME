# CyIME 1.2.8

本次正式版包含 1.1.x 开发期间的自定义布局、手写布局、候选列表与输入稳定性修复。

- 修复切换到其他输入法再切回后只剩英文：重新确认引擎、会话和中文方案可用。
- 重新部署只有在实际会话和已启用方案验证通过后才显示完成，并刷新当前键盘。
- 候选恢复整面板展开；横排已显示的候选不再重复；修复低高度下回车被挤出的问题。
- 自定义字母布局支持命名、拖动、合并和主题配色，保留标准布局切回。
- 调整手机/平板手写界面、菜单和语言选择，统一模型管理入口与语音模型命名。
- 加入独立的基础联想语料，保留个人学习数据；修复启动部署时积压按键和语音录音资源释放问题。

## 安装

通常选择 `arm64-v8a`。`universal` 包包含全部架构、体积较大；其余包用于对应设备。此版本与已有 CyIME 使用相同应用 ID 和签名，可覆盖安装，请勿先卸载。

## 验证范围

发布前已完成相关原生引擎、候选界面及输入队列回归。1.1.8 修复的 12 项相关 Android 测试通过，模拟器同进程输入法往返切换三次后中文候选正常。Debug 修复包已在三星 SM-S9180 覆盖安装并确认中文方案初始化。全设备、全部场景尚未验收；不宣称没有剩余问题。正式包还会核对签名、版本与非 Debug 标记。
