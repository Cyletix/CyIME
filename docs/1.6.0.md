# CyIME 1.6.0

本轮提供同源、同签名、同版本号的两个 ARM64 正式安装包，可覆盖升级并保留个人数据。

- **轻量版**：保留基础中、日、英词库，语音、手写、联想和候选增强模型可从应用内模型管理下载。
- **老人版（文件名含 full）**：内置 Paraformer、SenseVoice、手写及两份智能联想模型，另含九键长句增强，首次启动解压准备后即可离线使用；体积很大的九键语法增强仍可按需下载。

## 主要变化

- 默认语音改为 **Paraformer＋SenseVoice**：Paraformer 实时识别，SenseVoice 二次校正；保留用户手动选过的模型，Zipformer 仍可自行选择。
- 改善语音模型常驻与快速重开，录音和后端初始化分开处理；中英切换不中断支持该语言的语音或手写会话。
- 修正物理键盘方向键选择候选、候选翻页与语言快捷键，稳定浮窗在等待联想时的尺寸；物理键盘设置支持分别勾选三组翻页键。
- 中文与英文26键提供上下滑符号预设及编辑预览；增加空格滑动光标等待时间设置。
- 分体、九键尺寸调整使用各自比例，手动宽度可拉满，接近方形键帽时轻吸附；符号、表情和九键展开页调整大屏尺寸与边栏比例。
- 剪贴板压缩内部导航占用，置顶内容前排小锁标记，分类支持以横向角度约束切换；保留原工具栏尺寸。
- 统一键盘内玻璃面板、全屏手写和长按菜单；输入方案即时选择，移除无效组合顺序入口。
- 桌面图标增加带底板／无底板预览选择，默认系统适配底板，透明图标裁去多余留白。
- 日语数字页与九键位置一致，14键增加小鹤双拼，恢复五笔下载入口，修正中文九键单键3的候选召回。

两版 Android versionCode：20261071。完整尺寸门禁仍按项目规则暂停；安装与包身份验证不代表全部交互已验收。
