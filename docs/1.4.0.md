# CyIME 1.4.0

已于 2026-10-03 正式发布：[GitHub Release](https://github.com/Cyletix/CyIME/releases/tag/1.4.0)。标签指向 `dd342aa1c3b29044c798bec468be3d55f4f756c5`，普通版与老人包均已上传并核对 GitHub 返回的 SHA-256。

本批首次正式发布包含 1.3.20 后的累计开发内容，普通版与内置模型版使用同一主分支源码、版本名 1.4.0、versionCode 20261049。用户于 2026-10-03 明确授权合并 main、推送 GitHub 和发布两种安装包；未授权自动勾选验收项。

## 安装包

- 普通版：`CyIME-1.4.0-arm64-v8a.apk`，模型按需准备。
- 内置模型版（老人包）：`CyIME-1.4.0-full-arm64-v8a.apk`，随包提供中文手写、small／base 联想、Zipformer 中文语音、SenseVoice 多语语音，首次启动仍需解包初始化。无需另下这些模型，但空间占用更大。
- 两版应用身份及发布签名一致，可以覆盖切换并保留个人数据；升级不会自动重置所有人的自定义设置。此前平板外观重置是用户单独授权的维护操作，不是通用升级行为。

## 本批变化

- 透明玻璃作为主题首项，参数在主题预览中调整；黑白、薰衣草紫、柔和蓝等配色继续保留。
- 设备首次初始化按硬件能力选择模型；炫光与按键动效独立。
- 九键候选前后切换、长按符号即时输入、平板尺寸适配、调节边角与渐进阻力。
- 剪贴板图文合流、图片单次提示、顔文字、语言名称及设置页面复用。
- 物理键盘候选定位、可拖动浮条与屏幕键盘切换。
- 语音静音处理、输入语言边界、分类词库与离线采词工具；T9 性能及会话修复并入同一源码。
- Windows 剪贴板同步等插件源码保留；滑行输入目前仅研究原型，没有对外宣称已提供键盘功能。

## 验证范围

前次 20261048 平板包已验证玻璃主题与候选／浮条界面，详见 [整合报告](development/glass-integration-delivery.md)。已在 main 发布提交上生成两种 Release，应用 1,252 项、插件 210 项单元检查全部通过；两包签名、版本、架构及老人包全部模型哈希核对通过；回执保存在 `D:/CyIME-Data/diagnostics/main-integration-20261003/`，发布资产包含校验文件。

整套尺寸门禁按用户要求暂停，不写成通过。真实外接键盘跨应用、新尺寸手感、日英手写模型和部分录音／图片粘贴场景仍未验收；T9 候选质量已知问题见专题报告，不把本次发布写成全部问题已解决。Git 签名可选，APK 发布签名仍强制验证。
