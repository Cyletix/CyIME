# 安装默认值与中文键盘（2.8.9）

安装包包含程序和默认资源，不包含某台手机后来保存的个人设置。动态配色使用当前手机的系统/壁纸调色板，因此两台设备选择相同主题时，颜色也可能不同。

## 本轮修改

- 首次启动明确保存“动态配色 + 深色模式”。旧默认薰衣草紫一次性迁移为动态配色；其它已选主题与已有深浅色选择保留。完成迁移后，用户仍可自行选择紫色或其它主题，不会在下次启动时再次被重置。
- Android 12 以下仍保留相同主题入口，使用深灰/蓝色兼容配色，避免回退到薰衣草紫。
- 原内置 `pinyin_simp` 是完整中文26键全拼，本轮将设置、输入模式列表及键盘中的名称统一显示为“中文26键”，保留原方案 ID 和词典兼容性。
- 将仓库已有的 `pinyin_14jian` 方案直接打包为“中文14键”，与26键共用内置拼音词典，无需从市场下载。真实14键布局与原有合并键映射保持。
- 新安装默认包含26/14键；已有安装升级时将缺失的这两个模式补入启用列表一次，保留已有顺序和其它方案状态。后续自行关闭仍然有效。
- 已安装的市场同名14键方案不会被内置副本覆盖。日语、英文、手写、语音模型接口不变。

## 验证

主题的新安装/迁移/个人选择保留、旧Android兼容色，以及中文键盘的原生引擎、真实语言切换与输入上屏，均使用专用模拟器验证；全新安装流程先清空专用测试应用数据，避免个人配置掩盖问题。日志及截图保存在 `.gradle/defaults-20260923/`。

本轮定向 JVM 30/30 通过（合并键映射18项、启用列表12项）。设备场景去重7项通过（主题4项、方案迁移/市场兼容2项、真实全新安装输入1项）；首轮迁移测试缺少临时 rime 目录，补齐测试夹具后2项复测通过。全新部署在此模拟器约7分钟，主要耗时为原有日语大词库；中文26/14键无需联网下载，部署后均实际输入并选中“你好”。
