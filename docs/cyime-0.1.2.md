# CyIME 0.1.2

版本码 20260930，保持现有包名与覆盖安装签名。

## 拼音与候选

保留原来的分词预览。点击后，在候选栏上方显示一行可定位光标的拼音编辑框；下方继续使用当前九键、26键、14键或小鹤键盘与原删除键。编辑实时作用于未上屏编码，关闭编辑框保留修改，已上屏正文与九键已选前缀保持不变。不再替换成另一套键盘，也不添加左右、删除、完成操作栏。

引擎显示的分词边界与实际编码单独映射，自动分隔符不会作为多余字符写入原始输入。候选按钮收起时朝上，展开后旋转朝下，双向过渡为 200ms，保持原有按钮尺寸、背景和图标。

## 间距与调节

中文九键、日语九键、数字和笔画布局增大基础键帽间隔，再按键盘实际尺寸同比例缩放；触摸区域仍覆盖完整键位。移除中文九键侧栏和中间区重复叠加的间距。

调节界面移除额外的高度/位置按钮，改用可见边框、边缘握柄和角标。拖边缘调整大小、拖空白区移动，按下位置决定本次手势，移动中实时预览。透明度控制卡、悬浮/固定和手动分体入口继续保留。

## 引擎稳定性

真实输入回归暴露了候选数量设置路径与后台方案切换并发访问原生配置的问题。该路径加入引擎互斥，并跳过数值未变时的方案重建，避免输入框重启时重复加载词典、清空组合或崩溃。

## 词库后续

本版先交付界面修正，不混入尚未验证的词库排序实验。现有完整雾凇词典中包含“怎么”“打字”“都不会”；复现问题还涉及末音节简拼、九键歧义路径和整句候选排序，不能只靠添加这几个词解决。`zenm`、`dazil`、`doubuhuidazile` 已列为后续优化的回归样例。
