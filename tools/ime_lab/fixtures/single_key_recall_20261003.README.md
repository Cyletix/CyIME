# 九键首个数字召回

`single_key_recall_20261003.json` 固定 20 段、22 字，覆盖 2–9 八个起始数字、a/e/o 完整元音、常用声母缩写，以及继续输入“觉得”“你的”。原文和逐字读音均保存在夹具中。

使用固定本机入口和空个人词库，先保存修前证据，再以相同夹具回放修后引擎：

```powershell
python tools/ime_lab/t9_replay.py run --fixture tools/ime_lab/fixtures/single_key_recall_20261003.json --output <新结果目录> --baseline <修前结果目录>
python tools/ime_lab/check_t9_single_key_recall.py <新结果目录>
```

正向检查要求单按 `3` 的默认首选为“的”，保留“额”在前十及 d/e/f 三支候选，同时保留 `2` 的“啊”和 `6` 的“哦”首选；连续输入与逐字停顿的每次对应观测均检查。检查器先复核原始回放和夹具哈希、空用户状态及采样完整性，不读取 APK、不修改词库，也不向引擎传入答案。个人学习和主动隐藏候选不属于此空状态默认值断言。

通用名次对比仍会如实记录完整元音目标的名次变化，不能为了常用声母词首选将已有完整元音挤出前部。其他完整输入及现有聊天语料继续分别检查，不用本断言替代句子质量回归。
